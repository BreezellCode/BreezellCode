# 桌面寵物

一位日本二次元風格的小風精靈，坐在聊天框上，在 AI 工作時陪著你。

它從不讀取你的訊息。Breezell 只告訴它聊天正在做什麼（思考、撰寫、執行工具、等你回應）以及這一輪是否順利，不會給它任何文字。

## 它會做什麼

- **跟著聊天動。** AI 思考時冒出思考泡泡；AI 等你回應時舉起牌子；一輪完成時灑彩帶，失敗時說一句話。眼角瞄一下就知道現在的狀況。
- **陪你一起長大。** 每完成一輪都會獲得經驗。十二個等級依蒲福風級排列，從軟風到颶風。
- **喜歡被關注。** 點它、摸它，在卡片上餵食和陪它玩。按右鍵就能看到卡片。
- **放哪裡都行。** 可以沿著聊天框拖到任何位置，也能拖到聊天內容上方，放開後它會飄回來。它偶爾會自己走動，沒事時會打瞌睡。頭髮會隨風擺動，也會眨眼。

## 它需要的權限

- **修改 Breezell 的畫面**（`ui.modify`）：它浮在聊天框上方。安裝時 Breezell 會詢問你。
- **知道一輪何時開始和結束**（`chat.events`）：只有聊天的狀態，沒有內容。

它畫的一切都留在一個小框框內。有事情等你處理時，它會縮小並讓開。

## 設定

| 設定 | 作用 |
|---|---|
| `deskPet.visible` | 顯示寵物。卡片上的**隱藏**會關閉這一項 |
| `deskPet.size` | `small`、`medium` 或 `large` |
| `deskPet.speech` | 讓它用對話氣泡說話 |

這些設定也在 Box > 功能選項裡。隱藏之後，在命令選擇區執行**桌面寵物: 顯示或隱藏**就能叫它回來。

需要支援聊天框夥伴的 Breezell 版本。在舊版上可以安裝，但不會有任何動作。
