# デスクペット

チャット欄に座って、AI が働くあいだそばにいてくれる、アニメ調の小さな風の精です。

メッセージを読むことはありません。Breezell が伝えるのはチャットの状態（考え中、執筆中、ツール実行中、あなたの応答待ち）とターンの結果だけで、テキストは一切渡しません。

## できること

- **チャットについていく。** AI が考えている間は思考の泡、あなたを待っているときは札、ターンが終われば紙吹雪、失敗すればひとことが出ます。視界の端で状況がわかります。
- **一緒に成長する。** ターンを終えるたびに経験値がたまります。12 のレベルはビューフォート風力階級に沿って至軽風から台風まで進みます。
- **かまってもらうのが好き。** クリックしたりなでたり、カードからごはんをあげたり遊んだりできます。カードは右クリックで開きます。
- **好きな場所に置ける。** チャット欄に沿ってどこへでも、チャットの上まで運べて、放すとふわりと戻ってきます。ときどき歩き回り、何もなければ居眠りします。髪は風に揺れ、まばたきもします。

## 必要な権限

- **Breezell の画面を変更する**（`ui.modify`）：チャット欄の上に浮かびます。追加時に Breezell が確認します。
- **ターンの開始と終了を知る**（`chat.events`）：チャットの状態のみで、内容は含みません。

描くものはすべて小さな枠の中に収まります。あなたの対応を待っているものがあるときは、小さくなって場所を空けます。

## 設定

| 設定 | 内容 |
|---|---|
| `deskPet.visible` | ペットを表示します。カードの**隠す**でオフになります |
| `deskPet.size` | `small`、`medium`、`large` |
| `deskPet.speech` | 吹き出しで話します |

これらの設定は Box > 機能オプションにもあります。隠したあとは、コマンドパレットの**デスクペット: 表示/非表示**で呼び戻せます。

チャット欄のコンパニオンに対応した Breezell が必要です。古いバージョンではインストールできますが、何も動きません。
