# 활동 아일랜드

Breezell 제목 표시줄에 AI가 하는 일을 모양이 바뀌는 캡슐로 보여 줍니다. 진행 중인 일이 있을 때 Breezell을 벗어나거나 최소화하면 캡슐이 화면 상단으로 날아가 모든 앱 위에 떠 있습니다. 클릭하면 패널로 펼쳐져 대화와 각 답변의 마지막 몇 마디를 보여 줍니다. 돌아오거나 일이 끝나면 다시 제목 표시줄로 날아 들어옵니다.

## 하는 일

- **제목 표시줄 가운데를 차지합니다.** 평소에는 작업 영역 이름을 보여 주고, 클릭하면 검색이 열립니다. 기존 검색 표시줄과 같습니다. 알림 종과 업데이트 버튼은 그 옆에 남습니다.
- **Breezell이 작업할 때 모양이 바뀝니다.** 캡슐이 넓어지며 AI의 단계, 모델 마크, 파형, 경과 시간을 보여 줍니다. 대화가 확인을 기다릴 때, 턴이 끝났을 때(걸린 시간 포함), 문제가 생겼을 때도 알려 주며 대화를 여는 **보기** 버튼을 보여 줍니다.
- **작업을 보여 줍니다.** AI가 쉬고 있으면 빌드나 테스트 작업이 캡슐에, AI가 바쁘면 캡슐 옆 작은 거품에 표시됩니다. 실패한 작업의 **보기**는 해당 터미널을 엽니다.
- **진행 중인 일이 있으면 창 밖에 떠 있습니다.** AI가 작업 중이거나 확인을 기다릴 때, 방금 끝났거나 문제가 생겼을 때, 또는 빌드나 테스트 작업이 실행 중일 때 다른 앱으로 가거나 Breezell을 최소화하면 캡슐이 제목 표시줄에서 화면 상단으로 날아가 모든 것 위에 떠 있는 어두운 알약이 됩니다. 아무 일도 없을 때는 제목 표시줄에 머물고, 조용해지면 제목 표시줄로 날아 돌아옵니다.
- **패널로 펼쳐집니다.** 알약을 클릭하면 펼쳐진 아일랜드처럼 열립니다. 진행 중이거나 확인을 기다리는 대화 수, 각 대화가 하는 일, 경과 시간과 답변의 마지막 몇 마디, 그리고 작업이 보입니다. 대화를 클릭하면 바로 그 대화로 이동하고, **편집기로 돌아가기**도 있습니다. 패널 밖을 클릭하거나 Esc를 누르면 닫힙니다.
- **모든 Breezell 창을 한 번에.** 창을 여러 개 열어도 밖에 나오는 아일랜드는 하나이며 모든 창을 모아 가장 급한 것을 먼저 보여 줍니다. 패널은 창별로 나뉘고 **이동**으로 전환합니다.

읽는 내용: AI가 하고 있는 단계, 작업 중인 모델, 빌드나 테스트 작업의 진행 상황, 그리고 **대화 읽기**를 허용하면 대화 제목과 각 답변의 마지막 몇 마디를 패널에 보여 주기 위해서만 읽습니다. 어떤 내용도 컴퓨터 밖으로 나가지 않습니다.

## 필요한 권한

- **Breezell 화면 변경**(`ui.modify`): 페이지가 제목 표시줄 가운데를 차지합니다. 플러그인이 설치되면 Breezell이 묻습니다.
- **Breezell 활동 표시**(`activity.read`): AI의 단계, 모델, 작업만 해당하며 메시지 내용은 절대 포함하지 않습니다. 끄지 않는 한 켜져 있습니다.
- **다른 앱 위에 작은 창 띄우기**(`ui.overlay`): 창 밖의 아일랜드입니다. Breezell을 사용하는 동안 묻습니다. 거부하면 아일랜드는 제목 표시줄에 머뭅니다.
- **대화 읽기**(`chat.read`, 선택): 패널의 대화 제목과 답변의 마지막 몇 마디입니다. Breezell을 사용하는 동안 묻습니다. 거부하면 패널에는 각 창의 AI가 하는 일이 표시됩니다.
- **기능 옵션에 추가**(`ui.contribute`): Box > 기능 옵션에 있는 설정입니다.

## 설정

| 설정 | 하는 일 |
|---|---|
| `activityIsland.floatOutside` | 진행 중인 일이 있을 때 Breezell을 벗어나면 아일랜드를 화면 상단에 띄웁니다. 끄면 제목 표시줄에 머뭅니다 |

Box > 기능 옵션에도 있습니다. Breezell의 **동작 줄이기**를 켜면 애니메이션 없이 바로 이동합니다.

## Windows, macOS, Linux

Windows, macOS(전체 화면 앱 위 포함), X11의 Linux에서 떠 있습니다.

**Wayland 세션에서는 제목 표시줄에 머뭅니다.** Wayland는 앱이 자신의 창 위치를 정하거나 창을 다른 창 위에 두지 못하게 하므로 아일랜드가 갈 곳이 없습니다. 플러그인이 한 번 알려 줍니다. X11에서, 또는 `--ozone-platform=x11`로 시작한 Breezell에서는 떠 있습니다.

Breezell 1.4.53 이상이 필요합니다. 이전 버전에는 설치되지 않습니다.
