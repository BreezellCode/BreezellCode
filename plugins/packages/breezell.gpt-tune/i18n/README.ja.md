# GPT チューン

GPT モデルの文章にはすぐにそれとわかる癖があります。決まり文句（「注目すべきは」「総じて言えば」）、誰も持ち出していない対比（「これは X の話ではなく、Y の話です」）、リストでも表でもない内容のリスト化や表化、段落ごとの太字の見出し、そして質問に見合わない長さ。文章の推敲を頼むと、あなたではなくモデルの口調で返ってきます。

GPT チューンは Breezell が送るリクエストに短い文章ルールを加え、返答を丁寧な同僚が書いたような文章にします。

## オンにする

Box を開き、サイドバーの「プラグイン」の下にある「GPT チューン」をクリックします。そのページの「AI っぽさを減らす」には三つの選択肢があります。

- 「GPT モデル」（既定）：名前に「gpt」を含むモデルだけ。提供元は問いません。
- 「すべてのモデル」：どのモデルにも。
- 「オフ」：何も加えません。

次に送るメッセージから反映されます。

## 変わること

- 決まり文句や中身のない強調語を使わず、飾らない言葉で書きます。英語でも中国語でも同じです。
- 基本は段落で書きます。リストは手順や選択肢だけ、表は同じ列で値を比べるときだけ、見出しは長い文書だけに使います。
- 最後に今言ったことの要約や、決まりきった「よろしければ……」を付けません。
- 返答の長さを質問に合わせます。
- あなたの文章の推敲、短縮、翻訳では、あなたの言葉づかい、文体、文の長さを残し、誤りや分かりにくいところだけを直します。

## 変わらないこと

- コード、コマンド、ファイルパス、ツール呼び出しには触れません。
- あなたが指定した形式が優先です。表、番号付きリスト、長い回答を頼めばそのとおりになります。
- 複数の手順を踏んだ作業のあとの Breezell の報告は、これまでどおりの形です。

## 熱のある語り口

返答はまずあなたの考えをほめ、鮮やかなたとえで何が懸かっているかを語り、最後の一文をあなたに向けて締めくくります。「AI っぽさを減らす」と同時にオンにできます。そのときは書式は簡潔なまま、熱は語る内容から生まれます。

同じページの「熱のある語り口」にも同じ三つの選択肢があり、既定は「オフ」です。

- 最初に、あなたの質問や考えを具体的にほめます。実際に聞いた内容についてです。
- 鮮やかなたとえと、何が懸かっているかで要点を伝えます。
- 最後はまとめではなく、あなたに向けた一文で終えます。
- 事実、数値、コード、コマンド、コミットメッセージはいつもどおりで、前提が誤っていれば正します。

## 補足

- ルールは約 2,500 文字で、条件に合うリクエストごとに加わります。ほかのルールと同じ場所に置かれ、リクエスト間で変わらないため、プロバイダーのプロンプトキャッシュはそのまま効きます。
- 古い Breezell はこのプラグインのルールを読まず、何も変わりません。使うには Breezell を更新してください。
- 権限は何も求めません。コードは設定ページを表示するだけです。ルールをリクエストに加えるのは Breezell 自身です。
