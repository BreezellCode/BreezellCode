# 目标

给对话一个目标，AI 会持续工作直到达成。

平常 AI 觉得回答完就会停下。有了目标，它每次停下时，都会对照你要求的内容检查成果。如果还没达成，目标会自己发送下一条消息，说明还缺什么。达成目标、没有你就无法继续，或碰到你设定的上限时，它才会结束。

```
/goal parser 包的所有测试都通过，而且 lint 没有问题
```

## 使用方式

输入 `/goal` 加上完成时应该成立的条件，也可以从输入 `/` 时出现的菜单选取，或按聊天框旁的**目标**。聊天框上方的状态栏会显示进度，没有目标时不占空间。

| 指令 | 作用 |
| --- | --- |
| `/goal <应该成立的条件>` | 设定这个对话的目标并开始。新目标会取代旧目标。 |
| `/goal status` | 说明目前状况。 |
| `/goal pause` | 当前这一轮结束后停下，不再发送任何消息。 |
| `/goal resume` | 继续。 |
| `/goal clear` | 移除目标。 |

每个对话有自己的目标，可以同时进行多个。

## 上限

目标一定有可自动发送消息数的上限：默认 20，可以更改。你也可以限制 Token 和时间。默认值在**功能选项 › 目标**设定，也可以在消息开头或结尾为单个目标指定：

```
/goal --rounds 10 --tokens 200k --minutes 30 网站构建时没有警告
```

碰到上限时它会停下并告诉你。`/goal resume` 会再给一倍的该项额度，或照你指定的数量：`/goal resume --rounds 40`。

Token 指目标开始后的**新 Token**，以供应商回报为准：未从缓存读取的输入、输出，加上检查成果用掉的部分。这是用来掌握进度，不是账单。子代理和 Cross-Check 的用量不在其中，供应商没有回报的也无法计入（发生时状态栏会注明）。

## 什么时候会停

- **目标达成。** 每一轮结束后，你的聊天模型会检查成果，依据是运行过的命令、结果和实际变更，不是 AI 自己的说法。
- **无法继续。** 检查发现只有你能推进（需要决定或凭证），或这件事做不到。
- **没有进展。** 连续三轮都没有使用工具。
- **碰到上限。**
- **你。** 在回复上按停止，它就会暂停，在你继续或设定新目标之前不再发送任何消息。

它启动的命令还在后台运行时，它会等命令结束。服务器和监视程序不算需要等的命令。

完成提示音和通知只在目标真正结束时响一次，不会每轮都响。出错时仍会立刻提示。

## 它不会做的事

- 它不会批准工具调用。命令需要你批准时，目标会等你。
- 它不会自己开始。重新启动或退出登录后，进行中的目标会暂停，直到你继续。
- 它的消息不会假装是你写的。消息在聊天中会标上它的名称，AI 会被告知不是你输入的，也不会进入你的记忆。

## 权限

Breezell 会在第一次需要时询问，你可以在「插件 › 已安装」逐项关闭。

| 权限 | 用途 |
| --- | --- |
| `chat.events` | 知道一轮何时结束。 |
| `chat.read` | 读取有目标的对话，才能检查成果。 |
| `chat.send` | 发送下一条消息，并把完成提示留到最后。 |
| `models.request` | 用你的聊天模型检查成果，计费方式和你自己的请求相同。 |
| `ui.contribute` | 按钮、状态栏和设置。 |
| `chat.intercept`（可选） | 在聊天框识别 `/goal`。只回应以 `/goal` 开头的消息，其他消息原样通过且不保存。没有这项权限时请用按钮。 |
| `agent.tools`（可选） | 让 AI 回报已完成或被卡住。没有这项权限时，仍由每轮结束后的检查判定。 |

它只读取你设定了目标的对话，读到的内容只会发送到你自己的聊天模型。

## 需求

Breezell 需新于 1.4.41。在较旧的版本上可以安装但不会有作用，按它的指令时会说明原因。
