# Цель

Задайте разговору цель, и ИИ будет работать, пока не достигнет её.

Обычно ИИ останавливается, когда считает, что ответил. С целью при каждой остановке работа сверяется с тем, что вы просили. Если цель ещё не достигнута, плагин сам отправляет следующее сообщение и говорит, чего не хватает. Работа заканчивается, когда цель достигнута, когда без вас не продвинуться или когда исчерпан заданный лимит.

```
/goal все тесты пакета parser проходят, и lint чист
```

## Как пользоваться

Введите `/goal` и условие, которое должно выполняться в конце, выберите её в меню, открывающемся по `/`, или нажмите **Цель** рядом с полем чата. Полоса над полем показывает состояние и не занимает места, когда цели нет.

| Команда | Что делает |
| --- | --- |
| `/goal <что должно выполняться>` | Задаёт цель разговора и начинает работу. Новая цель заменяет старую. |
| `/goal status` | Показывает состояние. |
| `/goal pause` | Останавливается после текущего хода и больше ничего не отправляет. |
| `/goal resume` | Продолжает. |
| `/goal clear` | Убирает цель. |

У каждого разговора своя цель, и несколько могут работать одновременно.

## Лимиты

Число сообщений, которые цель может отправить сама, ограничено всегда: 20, если не изменить. Можно также ограничить токены и время. Значения по умолчанию задаются в **Функции › Цель**, а для отдельной цели в начале или конце сообщения:

```
/goal --rounds 10 --tokens 200k --minutes 30 сборка сайта проходит без предупреждений
```

На лимите работа останавливается, и вам об этом сообщают. `/goal resume` добавляет столько же этого лимита или столько, сколько укажете: `/goal resume --rounds 40`.

Токены это **новые токены** с начала цели по данным провайдера: ввод не из кэша, вывод и то, что ушло на проверку работы. Это для наблюдения за ходом работы, а не счёт. Субагенты и Cross-Check сюда не входят, а провайдер без данных не учитывается (полоса об этом сообщит).

## Что её останавливает

- **Цель достигнута.** После каждого хода чат-модель проверяет работу по выполненным командам, их результатам и изменениям, а не по словам ИИ.
- **Дальше нельзя.** Продвинуть можете только вы (решение, учётные данные), или это невозможно.
- **Нет движения.** Три хода подряд без инструментов.
- **Лимит.**
- **Вы.** Нажмите «Стоп» на ответе, и цель встанет на паузу. Ничего не будет отправлено, пока вы не возобновите её или не зададите новую.

Пока запущенная команда работает в фоне, цель ждёт её завершения. Серверы и наблюдатели ожидания не требуют.

Звук и уведомление о завершении приходят один раз, когда цель действительно закончена. Об ошибках сообщается сразу.

## Чего она не делает

- Не одобряет вызовы инструментов. Если команде нужно ваше одобрение, цель ждёт вас.
- Не начинает сама. После перезапуска или выхода из аккаунта работающая цель стоит на паузе, пока вы её не возобновите.
- Не выдаёт свои сообщения за ваши. В чате они подписаны её именем, ИИ сообщается, что вы их не вводили, и в вашу память они не попадают.

## Разрешения

Breezell спрашивает при первой необходимости. Каждое можно отключить в «Плагины › Установленные».

| Разрешение | Зачем |
| --- | --- |
| `chat.events` | Знать, когда закончился ход. |
| `chat.read` | Читать разговор с целью, чтобы проверять работу. |
| `chat.send` | Отправлять следующее сообщение и придерживать звук завершения до конца. |
| `models.request` | Проверять работу вашей чат-моделью. Оплачивается как обычный ваш запрос. |
| `ui.contribute` | Кнопка, полоса и настройки. |
| `chat.intercept` (необязательно) | Распознавать `/goal` в поле чата. Реагирует только на сообщения, начинающиеся с `/goal`; остальные проходят без изменений и не сохраняются. Без него используйте кнопку. |
| `agent.tools` (необязательно) | Чтобы ИИ мог сообщить о завершении или тупике. Без него всё решает проверка после каждого хода. |

Читаются только разговоры, которым вы задали цель, и прочитанное отправляется только вашей чат-модели.

## Требования

Breezell новее 1.4.41. В более старой версии плагин устанавливается, но не работает, и команда объясняет почему.
