# 目標

給對話一個目標，AI 會持續工作直到達成。

平常 AI 覺得回答完就會停下。有了目標，它每次停下時，都會對照你要求的內容檢查成果。如果還沒達成，目標會自己傳送下一則訊息，說明還缺什麼。達成目標、沒有你就無法繼續，或碰到你設定的上限時，它才會結束。

```
/goal parser 套件的所有測試都通過，而且 lint 沒有問題
```

## 使用方式

輸入 `/goal` 加上完成時應該成立的條件，也可以從輸入 `/` 時出現的選單選取，或按聊天框旁的**目標**。聊天框上方的狀態列會顯示進度，沒有目標時不佔空間。

| 指令 | 作用 |
| --- | --- |
| `/goal <應該成立的條件>` | 設定這個對話的目標並開始。新目標會取代舊目標。 |
| `/goal status` | 說明目前狀況。 |
| `/goal pause` | 目前這一輪結束後停下，不再傳送任何訊息。 |
| `/goal resume` | 繼續。 |
| `/goal clear` | 移除目標。 |

每個對話有自己的目標，可以同時進行多個。

## 上限

目標一定有可自動傳送訊息數的上限：預設 20，可以更改。你也可以限制 Token 和時間。預設值在**功能選項 › 目標**設定，也可以在訊息開頭或結尾為單一目標指定：

```
/goal --rounds 10 --tokens 200k --minutes 30 網站建置時沒有警告
```

碰到上限時它會停下並告訴你。`/goal resume` 會再給一倍的該項額度，或照你指定的數量：`/goal resume --rounds 40`。

Token 指目標開始後的**新 Token**，以供應商回報為準：未從快取讀取的輸入、輸出，加上檢查成果用掉的部分。這是用來掌握進度，不是帳單。子代理和 Cross-Check 的用量不在其中，供應商沒有回報的也無法計入（發生時狀態列會註明）。

## 什麼時候會停

- **目標達成。** 每一輪結束後，你的聊天模型會檢查成果，依據是執行過的命令、結果和實際變更，不是 AI 自己的說法。
- **無法繼續。** 檢查發現只有你能推進（需要決定或憑證），或這件事做不到。
- **沒有進展。** 連續三輪都沒有使用工具。
- **碰到上限。**
- **你。** 在回覆上按停止，它就會暫停，在你繼續或設定新目標之前不再傳送任何訊息。

它啟動的命令還在背景執行時，它會等命令結束。伺服器和監看程序不算需要等的命令。

完成提示音和通知只在目標真正結束時響一次，不會每輪都響。出錯時仍會立刻提示。

## 它不會做的事

- 它不會核准工具呼叫。命令需要你核准時，目標會等你。
- 它不會自己開始。重新啟動或登出後，進行中的目標會暫停，直到你繼續。
- 它的訊息不會假裝是你寫的。訊息在聊天中會標上它的名稱，AI 會被告知不是你輸入的，也不會進入你的記憶。

## 權限

Breezell 會在第一次需要時詢問，你可以在「插件 › 已安裝」逐項關閉。

| 權限 | 用途 |
| --- | --- |
| `chat.events` | 知道一輪何時結束。 |
| `chat.read` | 讀取有目標的對話，才能檢查成果。 |
| `chat.send` | 傳送下一則訊息，並把完成提示留到最後。 |
| `models.request` | 用你的聊天模型檢查成果，計費方式和你自己的請求相同。 |
| `ui.contribute` | 按鈕、狀態列和設定。 |
| `chat.intercept`（選用） | 在聊天框辨識 `/goal`。只回應以 `/goal` 開頭的訊息，其他訊息原樣通過且不保存。沒有這項權限時請用按鈕。 |
| `agent.tools`（選用） | 讓 AI 回報已完成或被卡住。沒有這項權限時，仍由每輪結束後的檢查判定。 |

它只讀取你設定了目標的對話，讀到的內容只會送到你自己的聊天模型。

## 需求

Breezell 需新於 1.4.41。在較舊的版本上可以安裝但不會有作用，按它的指令時會說明原因。
