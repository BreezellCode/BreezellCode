# Focus Player

Фоновые звуки для концентрации и ваша музыка в такт с Breezell: сигнал, когда ИИ заканчивает ход.

Официальный пример панельного плагина Breezell. Исходники: [`plugins/examples/focus-player`](https://github.com/BreezellCode/BreezellCode/tree/main/plugins/examples/focus-player).

## Возможности

- **Фоновый звук**: дождь, глубокая концентрация (коричневый шум и низкий гул) и мягкие аккорды — всё синтезируется на лету через Web Audio, аудиофайлов в плагине нет.
- **Моя музыка**: выберите папку (mp3, ogg, wav, flac, m4a, opus, webm) и слушайте по порядку.
- **Вместе с Breezell** (разрешение `chat.events`: только режим, результат и длительность, без содержимого):
  - сигнал, когда ход беседы завершён, и другой — если он завершился ошибкой или был остановлен;
  - по желанию: играть, пока работает агент, и ставить на паузу, когда он закончил;
  - недавняя активность в панели.

## Как пользоваться

- Откройте его из раздела **Плагины** на боковой панели Box или кнопкой **Открыть** в Breezell Console › Плагины.
- Элемент **▶ Focus** в строке состояния включает и ставит на паузу.
- Панель — это вкладка редактора: перетащите её наружу или выполните «Move Editor into New Window», чтобы открыть в отдельном окне.
- Настройки: `focusPlayer.chimeWhenTurnFinishes`, `focusPlayer.playWhileAgentWorks`, `focusPlayer.musicFolder`.

Как и любой плагин Breezell, он работает, пока вы вошли в Breezell.

## Разработка

```bash
npm install
npm run typecheck
npm run package:open      # пакет с открытым кодом
npm run package:closed    # пакет с закрытым кодом
```

Откройте эту папку в Breezell и нажмите F5, чтобы запустить плагин в окне разработки.
