# Breezell 입력기

내 코드와 대화를 아는 입력기: 병음, 주음, 쌍병음, Wubi 86, 일본어, 한국어를 Breezell의 편집기와 채팅에서, Windows에서는 모든 프로그램에서 사용할 수 있습니다.

## 기능

- **문장을 통째로 입력합니다.** 한 구절을 한 번에 입력하면 언어 모델이 문맥 속에서 읽어, 사전만 쓸 때보다 훨씬 자주 맞는 글자를 첫 후보로 냅니다.
- **코드와 주석을 구분합니다.** 코드에서는 영어를 입력합니다. 주석과 문자열 안이나 줄의 `///` 뒤에서는 전환하지 않아도 내 언어를 입력합니다.
- **커서 주변을 활용합니다.** 편집 중인 코드와 채팅의 대화가 단어 선택을 돕고, `useState` 같은 이름은 거기 쓰인 그대로 후보가 됩니다.
- **오타를 너그럽게 받아 줍니다.** 병음에서 키 순서가 틀리거나, 옆 키를 누르거나, 키를 하나 더 또는 덜 눌러도 단어를 찾습니다(`jain`으로 简을 찾습니다).
- **영어를 섞어 쓸 수 있습니다.** 병음에서 `hello`를 입력하면 후보에 나옵니다.
- **다음 단어를 제안합니다.** 중국어를 확정한 뒤에 제안합니다. 몇 초가 지나거나 다른 곳을 클릭하면 사라지고, 설정 페이지의 **단어 예측**으로 끌 수 있습니다.
- **나에게서 학습합니다.** 한 번 고른 선택이 다른 모든 곳으로 번지지는 않습니다.

## 시작하기

**Breezell Console › 플러그인**에서 **설치**를 누르면 끝입니다. 나머지는 저절로 설정됩니다:

- 입력기를 추가하기 위해 Windows가 관리자 권한을 한 번 묻습니다.
- Breezell 표시 언어에 맞는 언어를 내려받습니다(일본어나 한국어 표시면 그 언어, 그 외에는 중국어).
- 끝나면 저절로 켜집니다. 진행 상황은 페이지에 표시됩니다.

Windows의 질문에 아니요를 눌러도 Breezell 편집기에서는 사용할 수 있으며, 페이지의 **Windows에 설치…**로 다시 설치할 수 있습니다. 다른 언어를 추가하거나 입력 방식을 바꾸려면 사이드바의 **플러그인**에서 **Breezell 입력기**를 여세요:

| 언어 | 입력 방식 | 다운로드 |
|---|---|---|
| 중국어 | 병음, 주음, 쌍병음(Flypy, Microsoft, Ziranma, Sogou, ABC, Ziguang, Pinyin Jiajia), Wubi 86 | 374 MB |
| 일본어 | 로마자를 가나와 한자로 | 189 MB |
| 한국어 | 단어 추천을 제공하는 두벌식 한글 | 128 MB |

언어는 이 플러그인의 GitHub 릴리스에서 받으며, 연결이 끊겨도 다운로드는 중단된 곳부터 이어집니다. 모든 파일은 사용하기 전에 SHA-256으로 확인합니다. 입력에 쓰는 언어마다 모델이 메모리에 유지됩니다: 중국어는 약 400 MB입니다.

## 키

| 키 | 기능 |
|---|---|
| **Ctrl+Alt+Space**(macOS: **Ctrl+Option+Shift+Space**) | 켜기 또는 끄기 |
| **Ctrl+Alt+K** 또는 상태 표시줄 | 입력 방식 선택 |
| **Space** 또는 숫자(주음: **Shift+숫자**) | 후보 고르기 |
| 화살표, **Page Up**, **Page Down** | 후보 사이 이동 |
| **Enter** | 입력한 그대로 확정 |
| **Esc** | 버리기 |
| **Backspace** | 키 하나 되돌리기 |
| **Tab** | 다음으로 제안된 첫 단어 고르기 |
| **Shift** 단독(Windows 입력기에서) | 내 언어와 영어 사이 전환 |

## Windows의 모든 프로그램에서

처음 시작할 때 Windows 입력기로 자신을 추가하며, Breezell과 같은 엔진과 같은 학습 단어를 사용합니다. 기본 입력기가 되고, **Win+Space**로 다른 입력기로 전환할 수 있습니다. 이미 열려 있는 프로그램에서도 바로 전환되므로 다시 시작할 필요가 없습니다.

`Program Files\BreezellIME`에 텍스트 서비스를, `%LOCALAPPDATA%\BreezellIME`에 엔진 호스트를 설치합니다. 모두 이 플러그인 패키지에 들어 있으며 코드를 내려받지 않습니다.

**플러그인을 제거하면** 입력기 목록에서 빼고, 엔진을 멈추고, 기본 입력기를 되돌리고, 기본 폴더의 언어를 삭제합니다. 학습한 내용은 남습니다. 텍스트 서비스 파일은 사용되지 않은 채 Program Files에 남습니다. 이것까지 지우려면 먼저 페이지의 **Windows에서 제거…**를 사용하세요.

Linux와 macOS에서는 Breezell 편집기에서 사용할 수 있으며, 시스템 입력기는 아직 없습니다.

## 이전 버전의 Breezell에서

편집기의 후보 패널과 채팅창 입력에는 최신 Breezell이 필요합니다. 이전 버전에서는 후보가 편집기의 커서 뒤에 텍스트로 표시되고, 채팅창은 시스템 입력기를 사용합니다.

## 내 데이터

- **입력한 내용은 컴퓨터 밖으로 나가지 않습니다.** 조합 중인 내용, 커서 주변의 문맥, 학습한 내용은 모두 컴퓨터에 남습니다. 플러그인은 선택한 언어를 다운로드할 때만 연결합니다.
- **권한:** Breezell의 플러그인 권한을 하나도 요청하지 않습니다. 입력기로서 단어를 고르기 위해 Breezell 채팅창에서 누른 키와 최근 대화를 받습니다. Breezell은 이것을 이 플러그인에만 전달합니다.
- 학습한 내용은 `%APPDATA%\BreezellIME`(Windows), `~/Library/Application Support/BreezellIME`(macOS) 또는 `~/.config/breezell-ime`(Linux)에 있습니다. 페이지의 **학습한 단어 지우기**로 잊게 할 수 있습니다.
- 다른 Breezell 플러그인과 마찬가지로 로그인이 필요합니다. Windows 입력기는 설치한 뒤에는 로그아웃해도 계속 동작하므로 입력을 못 하게 되는 일은 없습니다.

## 정확도

첫 후보가 정확히 맞은 구절의 비율입니다. 학습에 쓰지 않은 세트별 1,000개 구절로 측정했으며 학습 기능은 껐습니다. 매개변수는 별도의 문장으로 조정했고, 이 세트들은 마지막에 실행했습니다.

| 입력 방식 | 텍스트 | Breezell 입력기 | 기타 |
|---|---|---|---|
| 병음 | 위키백과 | 66.4 | Rime 33.1, CyIME 38.2 |
| 병음 | 자막 | 85.1 | Rime 62.6, CyIME 65.1 |
| 병음 | 기술 문서 | 78.3 | Rime 49.7, CyIME 61.3 |
| 주음 | 대만 자막 | 82.4 | Rime 62.0, CyIME 54.6 |
| 주음 | Python 문서 | 81.2 | Rime 61.4, CyIME 37.8 |
| Wubi 86, 스마트 정렬: 선택 불필요 | 위키백과 | 81.4 | Rime 70.2 |
| Wubi 86, 스마트 정렬: 선택 불필요 | 자막 | 87.6 | Rime 85.0 |
| Wubi 86, 스마트 정렬: 선택 불필요 | 기술 문서 | 91.9 | Rime 88.8 |
| 일본어 | ITA 코퍼스 | 66.5 | Mozc 58.9, CyIME 24.8 |
| 일본어 | 위키백과 | 79.0 | Mozc 59.5, CyIME 33.1 |
| 일본어 | 자막 | 83.8 | Mozc 74.3, CyIME 35.1 |

기술 세트의 바탕이 된 Vue와 Python 문서는 학습에 전혀 쓰지 않았습니다. Rime은 병음에서 rime-ice, 주음에서 공식 bopomofo 스키마입니다. CyIME의 수치는 스키마와 가중치에 Wanxiang 문법 모델을 더한 기본 librime 1.16.1의 결과입니다. CyIME가 자체 수정한 librime과 리랭커는 실행하지 않았으며, 결과가 더 좋을 수 있습니다. 일본어 위키백과와 자막의 읽기는 Mozc의 사전으로 생성했으므로, 사람이 읽기를 단 ITA가 셋 중 가장 공정합니다.

## 소스에서 빌드하기

소스는 [`plugins/examples/ime`](https://github.com/BreezellCode/BreezellCode/tree/main/plugins/examples/ime)에 있습니다: `src`(플러그인), `engine`(입력기 엔진), `system`(Windows 텍스트 서비스와 호스트), `tools`(모델을 빌드하는 도구).

```bash
npm install
npm test                 # 로직 테스트
npm run package:open     # .vsix, 소스와 소스 맵 포함
```

텍스트 서비스 DLL은 Windows에서 `system/windows/build.bat`로 빌드합니다.
