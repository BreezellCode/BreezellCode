# Breezell IME

コードと会話を理解する入力方式です：ピンイン、注音、双拼、五筆 86、日本語、韓国語を、Breezell のエディターとチャットで、Windows ではすべてのプログラムで使えます。

## できること

- **文をまるごと入力。** 節を一気に入力すると、言語モデルが文脈の中で読み取り、辞書だけの場合よりはるかに高い確率で正しい文字が最初の候補になります。
- **コードとコメントを区別。** コードでは英語を入力します。コメントや文字列の中、または行の `///` の後では、切り替えなしで自分の言語を入力します。
- **カーソルの周囲を活用。** 編集中のコードとチャットの会話が単語選びを助け、`useState` のような名前はそこでの書き方のまま候補になります。
- **打ち間違いに寛容。** ピンインでは、キーの順序の間違い、隣のキーの押し間違い、キーの打ちすぎや打ち漏れがあっても単語を見つけます（`jain` で 简 が見つかります）。
- **英語を混ぜられます。** ピンインで `hello` と入力すると候補に出ます。
- **次の単語を提示します**（中国語を確定した後）。
- **あなたから学習します。** 一度きりの選択がほかのすべてに波及することはありません。

## はじめに

1. **Breezell Console › プラグイン** からインストールします。
2. サイドバーの「**プラグイン**」で「**Breezell IME**」を開きます。初回はページが自動的に開きます。
3. 「**言語**」で必要なものをダウンロードします：

   | 言語 | 入力方式 | ダウンロード |
   |---|---|---|
   | 中国語 | ピンイン、注音、双拼（小鶴、Microsoft、自然碼、搜狗、ABC、紫光、拼音加加）、五筆 86 | 374 MB |
   | 日本語 | ローマ字からかな・漢字へ | 189 MB |
   | 韓国語 | 単語候補つきの 2ボル式ハングル | 128 MB |

4. ページで入力方式を選び、エディターで **Ctrl+Alt+Space** を押して入力を始めます。

言語はこのプラグインの GitHub リリースから取得し、接続が切れてもダウンロードは止まったところから続きます。すべてのファイルは使用前に SHA-256 で確認されます。入力に使う言語ごとにモデルがメモリーに保持されます：中国語で約 400 MB です。

## キー

| キー | 機能 |
|---|---|
| **Ctrl+Alt+Space**（macOS：**Ctrl+Option+Shift+Space**） | オン／オフ |
| **Ctrl+Alt+K** またはステータスバー | 入力方式を選択 |
| **Space** または数字（注音：**Shift+数字**） | 候補を選ぶ |
| 矢印キー、**Page Up**、**Page Down** | 候補を移動する |
| **Enter** | 入力したとおりに確定する |
| **Esc** | 取り消す |
| **Backspace** | キーを 1 つ戻す |
| **Tab** | 次に提示された最初の単語を選ぶ |
| **Shift** 単独（Windows の入力方式で） | 自分の言語と英語を切り替える |

## Windows のすべてのプログラムで

プラグインのページの「**Windows にインストール…**」で Windows の入力方式として追加されます。エンジンも学習した単語も Breezell と同じです。テキストサービスの登録のため、Windows が一度だけ管理者権限を求めます。その後は既定の入力方式になります。**Win+Space** でほかの入力方式に切り替えられ、「**Windows から削除…**」で取り除けます。

テキストサービスを `Program Files\BreezellIME` に、エンジンのホストを `%LOCALAPPDATA%\BreezellIME` にインストールします。すべてこのプラグインのパッケージに含まれており、コードはダウンロードしません。インストール時にすでに開いているプログラムでは、**Win+Space** を押して切り替えてください。

Linux と macOS では Breezell のエディターで動作します。システムの入力方式はまだ利用できません。

## 古いバージョンの Breezell では

エディターの候補パネルとチャットボックスでの入力には、最近の Breezell が必要です。古いバージョンでは、候補はエディターのカーソルの後にテキストとして表示され、チャットボックスではシステムの入力方式を使います。

## データについて

- **入力した内容がコンピューターの外に出ることはありません。** 変換中の内容、カーソル周囲の文脈、学習した内容はすべてコンピューターの中にとどまります。プラグインが接続するのは、選択した言語をダウンロードするときだけです。
- **権限：** Breezell のプラグイン権限は何も求めません。入力方式として、単語を選ぶために Breezell のチャットボックスで押したキーと最近の会話を受け取ります。Breezell はこれらをこのプラグインにだけ渡します。
- 学習した内容は `%APPDATA%\BreezellIME`（Windows）、`~/Library/Application Support/BreezellIME`（macOS）、`~/.config/breezell-ime`（Linux）にあります。ページの「**学習した単語を消去**」で忘れさせられます。
- ほかの Breezell プラグインと同様、サインインが必要です。Windows の入力方式はインストール後、サインアウトしても動き続けるので、入力できなくなることはありません。

## 精度

最初の候補が完全に正しかった節の割合です。学習に使っていないセットごとに 1,000 節で、学習機能はオフです。パラメーターは別の文で調整し、これらのセットは最後に実行しました。

| 入力方式 | テキスト | Breezell IME | その他 |
|---|---|---|---|
| ピンイン | Wikipedia | 66.4 | Rime 33.1, CyIME 38.2 |
| ピンイン | 字幕 | 85.1 | Rime 62.6, CyIME 65.1 |
| ピンイン | 技術文書 | 78.3 | Rime 49.7, CyIME 61.3 |
| 注音 | 台湾の字幕 | 82.4 | Rime 62.0, CyIME 54.6 |
| 注音 | Python ドキュメント | 81.2 | Rime 61.4, CyIME 37.8 |
| 五筆 86、スマート順序：選択不要 | Wikipedia | 81.4 | Rime 70.2 |
| 五筆 86、スマート順序：選択不要 | 字幕 | 87.6 | Rime 85.0 |
| 五筆 86、スマート順序：選択不要 | 技術文書 | 91.9 | Rime 88.8 |
| 日本語 | ITA コーパス | 66.5 | Mozc 58.9, CyIME 24.8 |
| 日本語 | Wikipedia | 79.0 | Mozc 59.5, CyIME 33.1 |
| 日本語 | 字幕 | 83.8 | Mozc 74.3, CyIME 35.1 |

技術セットのもとになった Vue と Python のドキュメントは、学習に一度も使っていません。Rime は、ピンインでは rime-ice、注音では公式の bopomofo スキーマです。CyIME の数値は、そのスキーマと重みに Wanxiang 文法モデルを加えた標準の librime 1.16.1 によるものです。CyIME 独自の改変版 librime とリランカーは実行しておらず、より良い結果になる可能性があります。日本語の Wikipedia と字幕の読みは Mozc の辞書から生成したものなので、人が読みを付けた ITA が 3 つの中で最も公平です。

## ソースからのビルド

ソースは [`plugins/examples/ime`](https://github.com/BreezellCode/BreezellCode/tree/main/plugins/examples/ime) にあります：`src`（プラグイン）、`engine`（入力方式のエンジン）、`system`（Windows のテキストサービスとホスト）、`tools`（モデルをビルドするもの）。

```bash
npm install
npm test                 # ロジックのテスト
npm run package:open     # .vsix（ソースとソースマップ付き）
```

テキストサービスの DLL は Windows で `system/windows/build.bat` を使ってビルドします。
