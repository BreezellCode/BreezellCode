# Chat Mirror

Ваши разговоры в Breezell в отдельном окне: выберите разговор, читайте его вместе с вызовами инструментов и извлечёнными записями памяти, отвечайте, одобряйте вызовы инструментов и меняйте модель чата.

Официальный пример плагина Breezell, который читает разговоры и участвует в них. Исходный код: [`plugins/examples/chat-mirror`](https://github.com/BreezellCode/BreezellCode/tree/main/plugins/examples/chat-mirror).

## Как пользоваться

- Откройте его из раздела **Плагины** на боковой панели Box или кнопкой **Открыть** в Breezell Console › Плагины.
- Слева — разговоры этого рабочего пространства, новые сверху. Точка отмечает разговор, который сейчас идёт (жёлтая: ждёт вашего одобрения).
- Выберите разговор, чтобы прочитать его: ваши сообщения с использованными для них записями памяти (с подсчётом, как в чате Breezell: постоянные и релевантные), ответы с рассуждениями и каждый вызов инструмента с параметрами и результатом.
- Пока Breezell готовит ответ, последний пузырь показывает, что он делает и сколько времени (думает, выполняет инструмент, ждёт вашего одобрения), его рассуждения и текст по мере написания.
- Напишите сообщение и нажмите **Send** (Ctrl+Enter), чтобы ответить, или **New conversation**, чтобы начать новый разговор. ИИ отвечает так, будто вы набрали это в Breezell.
- Когда вызов инструмента ждёт одобрения, нажмите здесь **Approve** (одобрить) или **Reject** (отклонить).
- **Open in Breezell** показывает разговор в чате Breezell.
- **Model** рядом с **Send** меняет модель чата Breezell. Это та же настройка, что и выбор модели в чате Breezell, поэтому изменение с одной стороны видно на другой (здесь — когда окно получает фокус).
- **Pinned notes** (закреплённые заметки) под списком бесед: заметки, которые Agent в Breezell закрепил инструментом Chat Mirror `pin_note`, новые сверху. **Unpin** снимает заметку.
- Вызов инструмента плагина показывает имя плагина и метку **Plugin tool** (так же и собственный `pin_note` Chat Mirror); у инструмента MCP — его сервер.

Интерфейс самого окна — на английском.

## Инструменты Agent

Chat Mirror даёт Agent в Breezell два собственных инструмента (`agent.tools`, «Регистрация инструментов Agent»). Для каждого указаны режимы, в которых он доступен; в других режимах Agent его не видит и не может вызвать.

| Инструмент | Режимы | Что делает |
|---|---|---|
| `pin_note` | Чат, Агент, Запутанность | Закрепляет заметку (заголовок и текст) в этом окне |
| `list_notes` | Чат, Агент, Запутанность, Анализ, Команды | Читает закреплённые заметки, новые первыми |

Попробуйте в режиме Чат: «Закрепи заметку в Chat Mirror: выпустить 1.4.42 в понедельник». Заметки хранятся на вашем компьютере вместе с данными плагина, даже когда окно закрыто. Их вызовы, как и у любого инструмента MCP, следуют настройке **Автоодобрение инструментов MCP**.

## Разрешения

| Разрешение | Для чего |
|---|---|
| `chat.read` | Список, разговор и его изменения, Open in Breezell |
| `chat.send` | Send и New conversation |
| `chat.approve` | Approve и Reject |
| `models.select` | Model (список моделей и переключение) |
| `agent.tools` | Инструменты `pin_note` и `list_notes` для Agent |

Breezell спрашивает о каждом разрешении `chat.*`, когда Chat Mirror впервые его использует; `models.select` ничем не рискует и включено, пока вы его не выключите. Если отказать в одном, Chat Mirror сообщит, чего не может сделать, а остальное продолжит работать. Каждое разрешение можно включать и выключать — по одному или все сразу — в Breezell Console › Плагины › Установленные › Chat Mirror. Отправленные им сообщения оплачиваются так же, как ваши.

Разрешение `agent.tools` запрашивается один раз — при первом запуске Chat Mirror. Если отказать, оба инструмента останутся выключенными, пока вы не включите разрешение, а окно работает как прежде.

## Как это устроено

- `window/` — страница. Она только рисует и показывает весь текст через `textContent`, а не как HTML: в сообщении может быть что угодно.
- `src/extension.ts` открывает окно и передаёт данные между ним и `vscode.breezell.chat`: `listConversations`, `getConversation`, `onDidChangeConversation`, `send`, `approve`/`reject` и `show`.
- Model использует `vscode.breezell.models`: `list` — когда окно открывается или получает фокус, `select` — при переключении.
- Пока пишется ответ, изменения приходят не чаще нескольких раз в секунду; каждый раз, когда Breezell переходит к другому делу (думает, пишет, вызывает инструмент, закончил), плагин перечитывает разговор. Записи памяти берутся из `recalledMemories` и `memoryUse` каждого сообщения.
- Вызов, для которого нет разрешения, завершается ошибкой `BreezellPermissionDenied`, и страница превращает её в понятное предложение.
- Инструменты объявлены в `package.json` (`contributes.breezell.tools`: имя, описание, `inputSchema`, `modes`) и выполняются в `src/extension.ts` через `vscode.breezell.tools.register`. Они регистрируются при запуске (`onStartupFinished`), так что Agent получает их ещё до открытия окна.
- В беседе, прочитанной через `chat.read`, вызов инструмента плагина несёт `plugin` (`{ id, name }`): страница показывает это имя вместо сервера `plugin:<id>`.
