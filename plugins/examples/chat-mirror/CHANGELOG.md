# Changelog

## 1.0.2

- While Breezell works on a reply, the last bubble shows what it is doing and for how long, its reasoning and the text as it comes; before, nothing showed until the text started.
- Each of your messages shows the memories used for it the way Breezell's chat does: "Injected 5 memories (3 resident · 2 relevant)", "No memories used this turn", each memory marked Resident or Relevant. It appears as soon as Breezell has picked them, not only when the reply ends.

## 1.0.1

- **Model**, beside **Send**: switch Breezell's chat model. Uses the `models.select` permission, which is on without asking.

## 1.0.0

- Pick a conversation, read it with its tool calls and recalled memories as it updates, reply or start one, and approve or reject the tool call it waits for.
