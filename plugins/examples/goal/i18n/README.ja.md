# ゴール

会話にゴールを与えると、AI は達成するまで作業を続けます。

ふだん AI は答え終えたと判断すると止まります。ゴールがあると、止まるたびに成果を依頼内容と照らし合わせて確認します。未達成なら、足りない点を添えて次のメッセージを自動で送ります。達成したとき、あなたなしでは進めないとき、設定した上限に達したときに終わります。

```
/goal parser パッケージのテストがすべて通り、lint もクリーンであること
```

## 使い方

`/goal` に続けて完了時に成り立つ条件を入力するか、`/` で開くメニューから選ぶか、チャット欄の横の**ゴール**を押します。チャット欄の上の帯に状況が表示され、ゴールがないときは場所を取りません。

| コマンド | 動作 |
| --- | --- |
| `/goal <成り立つべき条件>` | この会話のゴールを設定して開始します。新しいゴールは古いものを置き換えます。 |
| `/goal status` | 状況を表示します。 |
| `/goal pause` | 現在のターンの後で止まり、以後は何も送りません。 |
| `/goal resume` | 再開します。 |
| `/goal clear` | 削除します。 |

ゴールは会話ごとに持て、複数を同時に進められます。

## 上限

自動送信できるメッセージ数には必ず上限があります（既定 20、変更可）。トークンと時間も制限できます。既定値は**機能オプション › ゴール**で設定でき、メッセージの先頭か末尾でゴールごとにも指定できます。

```
/goal --rounds 10 --tokens 200k --minutes 30 サイトのビルドで警告が出ないこと
```

上限に達すると止まって知らせます。`/goal resume` でその上限を同じ分だけ追加するか、`/goal resume --rounds 40` のように指定します。

トークンはゴール開始後の**新規トークン**で、プロバイダーの報告によります。キャッシュから読まれなかった入力、出力、成果の確認に使った分の合計です。状況把握のためのもので、請求額ではありません。サブエージェントと Cross-Check の分は含まれず、報告のないプロバイダーの分も数えられません（その場合は帯に表示されます）。

## 止まるとき

- **ゴール達成。** 各ターンの後、チャットモデルが成果を確認します。根拠は AI の説明ではなく、実行したコマンド、その結果、実際の変更です。
- **進めない。** あなたにしか進められない（判断や認証情報が必要）か、実現できないと判断されたとき。
- **進展なし。** ツールを使わないターンが 3 回続いたとき。
- **上限。**
- **あなた。** 返信で停止を押すと一時停止し、再開するか新しいゴールを設定するまで何も送りません。

開始したコマンドがバックグラウンドで動いている間は、終了を待ちます。サーバーや監視プロセスは待つ対象ではありません。

完了音と通知はゴールが本当に終わったときに 1 回だけ鳴ります。エラーはすぐに知らせます。

## しないこと

- ツール呼び出しを承認しません。承認が必要なコマンドでは、ゴールはあなたを待ちます。
- 勝手に始めません。再起動やサインアウトの後、実行中のゴールは再開するまで一時停止します。
- メッセージをあなたのものに見せかけません。チャットでは名前付きで表示され、AI にはあなたの入力ではないと伝わり、メモリーにも入りません。

## 権限

最初に必要になったときに確認されます。「プラグイン › インストール済み」で個別にオフにできます。

| 権限 | 理由 |
| --- | --- |
| `chat.events` | ターンの終わりを知るため。 |
| `chat.read` | ゴールのある会話を読み、成果を確認するため。 |
| `chat.send` | 次のメッセージを送り、完了音を最後まで保留するため。 |
| `models.request` | チャットモデルで成果を確認するため。通常のリクエストと同じく課金されます。 |
| `ui.contribute` | ボタン、帯、設定。 |
| `chat.intercept`（任意） | チャット欄で `/goal` を認識するため。`/goal` で始まるメッセージにだけ反応し、他はそのまま通して保存しません。なければボタンを使います。 |
| `agent.tools`（任意） | AI が完了や行き詰まりを報告するため。なくても各ターン後の確認で判断します。 |

読むのはゴールを設定した会話だけで、読んだ内容はあなたのチャットモデルにだけ送ります。

## 必要なもの

1.4.41 より新しい Breezell。古いバージョンではインストールはできますが動作せず、コマンドを押すと理由を表示します。
