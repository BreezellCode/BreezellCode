# 목표

대화에 목표를 주면 AI가 달성할 때까지 계속 작업합니다.

평소 AI는 답을 마쳤다고 판단하면 멈춥니다. 목표가 있으면 멈출 때마다 요청한 내용과 결과를 대조해 확인합니다. 아직 달성하지 못했으면 부족한 점을 담아 다음 메시지를 직접 보냅니다. 목표를 달성하거나, 사용자 없이는 진행할 수 없거나, 설정한 한도에 도달하면 끝납니다.

```
/goal parser 패키지의 모든 테스트가 통과하고 lint 문제가 없음
```

## 사용법

`/goal` 뒤에 완료 시 성립해야 할 조건을 입력하거나, `/`를 입력하면 열리는 메뉴에서 고르거나, 채팅 입력창 옆의 **목표**를 누릅니다. 입력창 위의 띠에 상태가 표시되며, 목표가 없으면 자리를 차지하지 않습니다.

| 명령 | 동작 |
| --- | --- |
| `/goal <성립해야 할 조건>` | 이 대화의 목표를 설정하고 시작합니다. 새 목표는 이전 목표를 대체합니다. |
| `/goal status` | 상태를 알려 줍니다. |
| `/goal pause` | 현재 턴이 끝나면 멈추고 더 보내지 않습니다. |
| `/goal resume` | 계속합니다. |
| `/goal clear` | 지웁니다. |

대화마다 목표를 가질 수 있고 여러 개를 동시에 진행할 수 있습니다.

## 한도

자동으로 보낼 수 있는 메시지 수에는 항상 한도가 있습니다(기본 20, 변경 가능). 토큰과 시간도 제한할 수 있습니다. 기본값은 **기능 옵션 › 목표**에서 정하고, 메시지 앞이나 뒤에서 목표별로 지정할 수도 있습니다.

```
/goal --rounds 10 --tokens 200k --minutes 30 사이트 빌드에 경고가 없음
```

한도에 도달하면 멈추고 알려 줍니다. `/goal resume`은 그 한도를 같은 만큼 더 허용하고, `/goal resume --rounds 40`처럼 직접 지정할 수도 있습니다.

토큰은 목표 시작 후의 **새 토큰**이며 제공업체의 보고를 따릅니다. 캐시에서 읽지 않은 입력, 출력, 결과 확인에 쓴 양을 더한 값입니다. 진행 파악용이며 청구서가 아닙니다. 서브에이전트와 Cross-Check 사용량은 포함되지 않고, 보고하지 않는 제공업체는 집계되지 않습니다(그 경우 띠에 표시됩니다).

## 멈추는 경우

- **목표 달성.** 턴이 끝날 때마다 채팅 모델이 AI의 말이 아니라 실행한 명령, 그 결과, 실제 변경을 근거로 확인합니다.
- **진행 불가.** 사용자만 진행할 수 있거나(결정, 자격 증명), 불가능하다고 판단될 때.
- **진전 없음.** 도구를 쓰지 않은 턴이 세 번 이어질 때.
- **한도.**
- **사용자.** 답변에서 중지를 누르면 일시 중지되고, 재개하거나 새 목표를 설정할 때까지 아무것도 보내지 않습니다.

시작한 명령이 백그라운드에서 실행 중이면 끝날 때까지 기다립니다. 서버와 감시 프로세스는 기다릴 대상이 아닙니다.

완료 소리와 알림은 목표가 정말 끝났을 때 한 번만 울립니다. 오류는 바로 알립니다.

## 하지 않는 일

- 도구 호출을 승인하지 않습니다. 명령에 승인이 필요하면 목표는 사용자를 기다립니다.
- 저절로 시작하지 않습니다. 다시 시작하거나 로그아웃하면 실행 중인 목표는 재개할 때까지 일시 중지됩니다.
- 메시지를 사용자가 쓴 것처럼 꾸미지 않습니다. 채팅에 이름이 표시되고, AI에게 사용자가 입력한 것이 아니라고 알리며, 메모리에도 들어가지 않습니다.

## 권한

처음 필요할 때 묻습니다. 플러그인 › 설치됨에서 각각 끌 수 있습니다.

| 권한 | 이유 |
| --- | --- |
| `chat.events` | 턴이 끝나는 때를 알기 위해. |
| `chat.read` | 목표가 있는 대화를 읽어 결과를 확인하기 위해. |
| `chat.send` | 다음 메시지를 보내고 완료 소리를 끝까지 보류하기 위해. |
| `models.request` | 채팅 모델로 결과를 확인하기 위해. 일반 요청과 똑같이 요금이 부과됩니다. |
| `ui.contribute` | 버튼, 띠, 설정. |
| `chat.intercept`(선택) | 입력창에서 `/goal`을 알아보기 위해. `/goal`로 시작하는 메시지에만 반응하고 나머지는 그대로 통과시키며 저장하지 않습니다. 없으면 버튼을 쓰세요. |
| `agent.tools`(선택) | AI가 완료나 막힘을 보고하기 위해. 없어도 턴 후 확인으로 판단합니다. |

목표를 설정한 대화만 읽으며, 읽은 내용은 사용자의 채팅 모델로만 보냅니다.
