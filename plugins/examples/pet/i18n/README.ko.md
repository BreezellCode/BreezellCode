# 데스크 펫

채팅 입력창에 앉아 AI가 일하는 동안 곁에 있어 주는 애니메이션풍의 작은 바람 정령입니다.

메시지는 절대 읽지 않습니다. Breezell은 채팅이 무엇을 하는지(생각, 작성, 도구 실행, 응답 대기)와 턴의 결과만 알려 주며, 어떤 텍스트도 넘기지 않습니다.

## 하는 일

- **채팅을 따라 움직입니다.** AI가 생각하는 동안 생각 풍선이, 응답을 기다리면 팻말이, 턴이 끝나면 색종이가, 실패하면 한마디가 나옵니다. 곁눈질만으로 상황을 알 수 있습니다.
- **함께 자랍니다.** 턴을 마칠 때마다 경험치를 얻습니다. 12단계는 보퍼트 풍력 계급을 따라 실바람에서 싹쓸바람까지 올라갑니다.
- **관심을 좋아합니다.** 클릭하거나 쓰다듬고, 카드에서 먹이를 주고 놀아 줄 수 있습니다. 오른쪽 클릭하면 카드가 열립니다.
- **어디든 놓을 수 있습니다.** 입력창을 따라 어디로든, 채팅 위로도 옮길 수 있고 놓으면 천천히 내려옵니다. 가끔 혼자 돌아다니고, 할 일이 없으면 졸기도 합니다. 머리카락이 바람에 흔들리고 눈도 깜빡입니다.

## 필요한 권한

- **Breezell 화면 변경**(`ui.modify`): 채팅 입력창 위에 떠 있습니다. 추가될 때 Breezell이 물어봅니다.
- **턴의 시작과 끝 알기**(`chat.events`): 채팅 상태만 알 수 있고 내용은 알 수 없습니다.

그리는 모든 것은 작은 틀 안에 머뭅니다. 사용자의 처리를 기다리는 것이 있으면 작아져서 자리를 비켜 줍니다.

## 설정

| 설정 | 내용 |
|---|---|
| `deskPet.visible` | 펫을 표시합니다. 카드의 **숨기기**로 꺼집니다 |
| `deskPet.size` | `small`, `medium`, `large` |
| `deskPet.speech` | 말풍선으로 말합니다 |

이 설정은 Box > 기능 옵션에도 있습니다. 숨긴 뒤에는 명령 팔레트의 **데스크 펫: 표시/숨기기**로 다시 불러올 수 있습니다.

채팅 입력창 동반자를 지원하는 Breezell이 필요합니다. 이전 버전에서는 설치되지만 아무 동작도 하지 않습니다.
