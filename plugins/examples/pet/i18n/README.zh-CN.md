# 桌面宠物

一位日本二次元风格的小风精灵，坐在聊天框上，在 AI 工作时陪着你。

它从不读取你的消息。Breezell 只告诉它聊天正在做什么（思考、撰写、运行工具、等你回应）以及这一轮是否顺利，不会给它任何文字。

## 它会做什么

- **跟着聊天动。** AI 思考时冒出思考泡泡；AI 等你回应时举起牌子；一轮完成时撒彩带，失败时说一句话。眼角瞄一下就知道现在的状况。
- **陪你一起长大。** 每完成一轮都会获得经验。十二个等级按蒲福风级排列，从软风到飓风。
- **喜欢被关注。** 点它、摸它，在卡片上喂食和陪它玩。点右键就能看到卡片。
- **放哪里都行。** 可以沿着聊天框拖到任何位置，也能拖到聊天内容上方，松开后它会飘回来。它偶尔会自己走动，没事时会打瞌睡。头发会随风摆动，也会眨眼。

## 它需要的权限

- **修改 Breezell 的界面**（`ui.modify`）：它浮在聊天框上方。安装时 Breezell 会询问你。
- **知道一轮何时开始和结束**（`chat.events`）：只有聊天的状态，没有内容。

它画的一切都留在一个小框内。有事情等你处理时，它会缩小并让开。

## 设置

| 设置 | 作用 |
|---|---|
| `deskPet.visible` | 显示宠物。卡片上的**隐藏**会关闭这一项 |
| `deskPet.size` | `small`、`medium` 或 `large` |
| `deskPet.speech` | 让它用对话气泡说话 |

这些设置也在 Box > 功能选项里。隐藏之后，在命令面板运行**桌面宠物: 显示或隐藏**就能叫它回来。

需要支持聊天框伙伴的 Breezell 版本。在旧版上可以安装，但不会有任何动作。
