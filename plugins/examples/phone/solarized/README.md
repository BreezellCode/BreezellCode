# Solarized

Ethan Schoonover's Solarized palette for the Breezell phone app, in two themes:

- **Solarized dark**: the deep blue-green ground, its text a little lighter than the original so it reads well on a phone.
- **Solarized light**: the warm paper ground with dark blue-green text.

Both keep cyan as the accent, and code is coloured in Solarized's own hues.

Install it from **Plugins › Market › For this phone**, then choose a theme with **Use this theme** or among the appearance cards (**Settings**).

It runs no code: the app draws the colours it names, and checks they read well before it uses them.
