# Table

A CSV or TSV file opened in the phone app's code view gets a **Preview** button: its rows as cards, each value under its column, nothing to scroll sideways. A row opened is edited field by field and saved back to the computer as the same kind of file.

It shows `.csv` (separated by commas) and `.tsv` (separated by tabs) files. Built into the Breezell phone app (**Plugins › Installed › On this phone**).

It runs no code: the app draws the files it names with its own table viewer.
