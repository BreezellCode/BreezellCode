# Changelog

## 1.0.1

- Runs on the local side of a remote (WSL, SSH) window, where Breezell's plugin API is always current; the music folder is chosen on this computer.

## 1.0.0

- Rain, deep focus and soft pad sounds, synthesized with Web Audio.
- Play your own music folder.
- A chime when a Breezell conversation turn finishes; optional play while the agent works.
