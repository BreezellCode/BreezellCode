# Changelog

## 1.0.4

- Write Doc Comment shows the comment as the model writes it, in its progress notification. It still goes into the code only once it is complete and checked.

## 1.0.3

- Write Doc Comment inserts only a comment. Given part of a file, some models answered like a chat ("this looks cut off, here is the rest") and that text went into the code. The request now says what to do next to the code, and an answer that is not a comment in the file's language is not inserted: Doc Writer says so and can show it beside the code. A comment followed by the selected code keeps the comment.

## 1.0.2

- Description, commands and settings in Simplified and Traditional Chinese, Japanese, Korean, Russian, Spanish and Portuguese (Brazil).

## 1.0.1

- README in Simplified and Traditional Chinese, Japanese, Korean, Russian, Spanish and Portuguese (Brazil).

## 1.0.0

- Write Doc Comment and Explain Selection, using the Breezell chat model.
