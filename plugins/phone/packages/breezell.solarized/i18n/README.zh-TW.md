# Solarized

把 Ethan Schoonover 的 Solarized 配色帶到 Breezell 手機 App，共有兩個主題：

- **Solarized 深色**：深藍綠色的底，文字比原版稍亮一些，在手機上也容易閱讀。
- **Solarized 淺色**：溫暖紙色的底，搭配深藍綠色的文字。

兩個主題都以青色作為強調色，程式碼也用 Solarized 自己的色調上色。

在「**插件 › 市場 › 給這支手機**」安裝後，按「**使用這個主題**」，或在外觀卡片（**設定**）中選用。

它不執行任何程式碼：由 App 依照它列出的顏色來顯示，並在使用前確認文字清楚可讀。
