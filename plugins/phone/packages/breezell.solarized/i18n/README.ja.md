# Solarized

Ethan Schoonover の Solarized 配色を Breezell スマートフォンアプリに。2 つのテーマがあります：

- **Solarized ダーク**：深い青緑の地。スマートフォンでも読みやすいよう、文字は原版より少し明るくしています。
- **Solarized ライト**：温かい紙色の地に、濃い青緑の文字。

どちらもシアンをアクセントにし、コードも Solarized 本来の色で表示します。

**プラグイン › マーケット › このスマートフォン向け** からインストールし、**このテーマを使う** または外観のカード（**設定**）でテーマを選びます。

コードは実行しません：書かれた色をアプリが描き、使う前に読みやすさを確かめます。
