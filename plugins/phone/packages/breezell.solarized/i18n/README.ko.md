# Solarized

Ethan Schoonover의 Solarized 색 조합을 Breezell 휴대폰 앱에. 두 가지 테마가 있습니다:

- **Solarized 다크**: 깊은 청록색 바탕. 휴대폰에서도 읽기 쉽도록 글자를 원래보다 조금 밝게 했습니다.
- **Solarized 라이트**: 따뜻한 종이색 바탕에 짙은 청록색 글자.

두 테마 모두 청록(시안)을 강조색으로 쓰고, 코드도 Solarized 고유의 색으로 칠합니다.

**플러그인 › 마켓 › 이 휴대폰용**에서 설치한 뒤 **이 테마 사용**을 누르거나 모양 카드(**설정**)에서 고릅니다.

코드를 실행하지 않습니다: 적힌 색을 앱이 그리며, 쓰기 전에 잘 읽히는지 확인합니다.
