# Markdown preview

A Markdown file opened in the phone app's code view gets a **Preview** button: the file as the page it makes, with headings, lists, tables and code, drawn like the Agent's answers.

It shows `.md`, `.markdown` and `.mdx` files. Built into the Breezell phone app (**Plugins › Installed › On this phone**).

It runs no code: the app draws the files it names with its own Markdown viewer.
