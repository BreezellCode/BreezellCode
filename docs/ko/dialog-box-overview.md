# 대화 상자 개요

Breezell 대화 상자는 프롬프트를 작성하고, 작업 모드를 선택하고, 모델을 선택하고, 컨텍스트를 첨부하고, Agent가 현재 요청을 처리하는 방식을 제어하는 기본 공간입니다.

이 페이지에서는 대화 상자 스크린샷에 표시된 주요 컨트롤을 설명합니다.

## 기본 입력 상태

기본 입력 상태는 새 메시지를 작성할 때의 일반적인 시작 상태입니다. 프롬프트 필드와 필수 컨트롤이 계속 표시됩니다.

![기본 입력 상태](/dialog-box/input-default.png)

요청을 입력하고 필요한 경우 모드와 모델을 선택한 다음 Breezell에 메시지를 보냅니다.

## 모드 선택기 메뉴

포인터가 모드 선택기 메뉴를 강조 표시합니다. 이 메뉴에는 사용 가능한 작업 모드가 표시됩니다.

![모드 선택기 메뉴](/dialog-box/mode-selector.png)

사용 가능한 모드는 다음과 같습니다.

- [**Chat**](/ko/mode-selection#chat): 빠른 질문과 답변
- [**Plan**](/ko/mode-selection#plan): 편집 전 구현 계획 수립
- [**Analyze**](/ko/mode-selection#analyze): 읽기 전용 조사
- [**Entanglement**](/ko/mode-selection#entanglement): 더 깊은 인과 추론
- [**Agent**](/ko/mode-selection#agent): 자율적인 파일 편집과 도구 사용
- [**Teams**](/ko/mode-selection#teams): 복잡한 작업을 위한 병렬 AI 팀원

자세한 내용은 [모드 선택](/ko/mode-selection)을 참조하세요. 필요한 자율성과 깊이에 맞는 모드를 선택합니다.

## 모델 선택기

포인터가 모델 선택기를 강조 표시합니다. 선택기에는 현재 모델이 표시되며 메시지를 보내기 전에 다른 사용 가능한 모델로 전환할 수 있습니다.

![모델 선택기](/dialog-box/input-compact-controls.png)

속도, 추론 또는 기능 특성이 다른 모델을 선택하려는 경우 사용합니다.

## 파일 업로드

포인터가 파일 업로드 컨트롤을 강조 표시합니다.

![파일 업로드 컨트롤](/dialog-box/input-model-controls.png)

이 컨트롤을 클릭하여 현재 메시지를 Breezell에 보내기 전에 로컬 파일을 첨부합니다. 업로드한 파일은 요청 컨텍스트의 일부가 되므로 Breezell이 답변할 때 파일을 검사하거나 참조할 수 있습니다.

## ~~고급 탐색~~

> **버전 1.2.5 이후 사용 중단됨.** 전용 고급 탐색 컨트롤은 더 이상 사용할 수 없습니다. 요청에 더 깊은 조사가 필요한 경우 Breezell이 관련 기능을 자동으로 호출하여 능동적 학습, 폭넓은 조사 및 더욱 철저한 탐색을 수행합니다.

![고급 탐색 컨트롤](/dialog-box/input-tools-expanded.png)

## Breezell 브라우저

포인터가 **Breezell Browser** 컨트롤을 강조 표시합니다.

![Breezell Browser 컨트롤](/dialog-box/input-agent-basic.png)

Breezell Browser는 Breezell에 내장된 브라우저 도구입니다. 대화 상자를 벗어나지 않고 웹페이지를 열고, 온라인 콘텐츠를 보고, 정보를 검색하고, AI가 웹 콘텐츠를 가져와 분석하도록 도울 수 있습니다.

## 컨텍스트 사용량 분석

포인터가 컨텍스트 사용량 표시기를 강조 표시합니다. 열면 현재 컨텍스트 창이 어떻게 사용되고 있는지 자세히 확인할 수 있습니다.

![컨텍스트 사용량 분석](/dialog-box/context-usage-breakdown.png)

분석 정보는 시스템 프롬프트, 도구, 규칙, 메모리, Skills, MCP, 하위 에이전트 및 대화 콘텐츠와 같은 범주로 사용량을 나눕니다. 이를 통해 세션에서 어떤 부분이 가장 많은 토큰을 사용하는지 확인할 수 있습니다.

## 컨텍스트 수동 압축

포인터가 컨텍스트 패널의 **Manual compress** 컨트롤을 강조 표시합니다. 이 작업은 이전 대화 콘텐츠를 요약하여 컨텍스트 사용량을 줄이면서 세션에 유용한 정보를 유지합니다.

![수동 압축이 표시된 컨텍스트 패널](/dialog-box/context-manual-compress.png)

수동 압축은 긴 대화에서 유용하며, 특히 컨텍스트 창이 커지고 있지만 같은 세션을 계속 사용하려는 경우에 적합합니다.

## 멘션 메뉴

포인터가 멘션 메뉴를 여는 데 사용되는 빠른 컨텍스트 영역을 강조 표시합니다. 멘션 메뉴를 통해 현재 메시지에 파일, 폴더, MCP 도구 및 Skills를 추가할 수 있습니다.

![Breezell 대화 상자의 멘션 메뉴](/dialog-box/mention-menu.png)

요청이 특정 워크스페이스 콘텐츠나 외부 기능에 의존할 때 사용합니다. 올바른 컨텍스트를 추가하면 Breezell이 답변하기 전에 무엇을 검사하거나 사용해야 하는지 이해하는 데 도움이 됩니다.

## 사용 팁

- 요청이 특정 프로젝트 콘텐츠에 의존하는 경우 파일 또는 폴더 컨텍스트를 추가합니다.
- Agent는 기본 모드이며 대부분의 작업에 권장되는 자동 워크플로입니다.
- 먼저 계획하거나 편집 없이 분석하는 등 특정 워크플로가 필요할 때만 모드를 변경합니다.
- 컨텍스트 압축은 자동으로 실행됩니다. 엄격한 수동 제어를 선호하거나 특별한 요구 사항이 있을 때만 수동 압축을 사용합니다.
- 정확성, 속도 또는 추론 깊이가 중요한 경우 선택한 모델을 검토합니다.
