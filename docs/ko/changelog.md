# 변경 사항

## 1.2.7 · 2026-07-29

### 새 기능

- 대규모 코드베이스의 이해와 탐색 효율을 개선했습니다.
- 이번 응답의 품질, 요구 사항 이해도 및 검증 신뢰도를 평가하는 선택형 답변 품질 인사이트를 추가했습니다.
- 캐시 통계 상세 정보에서 페이지 매김, 연동 필터 및 다국어 표시를 지원합니다.

### 수정

#### 소스 제어 및 Agent 런타임

- 소스 제어 저장소를 새로 고치거나 보기를 전환하거나 구성 요소를 다시 빌드한 후 커밋 메시지 입력란이 비거나 유효하지 않게 되는 문제를 수정했습니다.
- Agent 추론 중단, 터미널 상태 오판, 백그라운드 명령의 종료 코드 손실 및 작업 조기 종료 문제를 수정했습니다.
- 대기열 메시지 편집, 도구 호출 피드백, 작업 목록 복원 및 연속 턴 상태와 관련된 문제를 수정했습니다.

#### 채팅 및 원격 환경

- 메시지를 편집하고 다시 전송할 때 원래 대화가 너무 일찍 잘리는 문제를 수정했습니다. 이제 검증이 완료된 후 메시지를 원자적으로 교체합니다.
- WSL 및 Remote SSH 환경의 원격 경로 문제를 수정하고 호스트 시작, 비밀번호 재시도 및 서버 캐싱을 개선했습니다.

#### 렌더링, 모델 및 상태

- KaTeX 블록 수식 분석, 코드 블록 테마, 중국어 글꼴 렌더링 및 파일 아이콘 정렬 문제를 수정했습니다.
- 일부 모델이 빈 응답을 표시하거나 오류 스택을 노출하거나 비정상적인 공급자 네트워크 요청을 보내는 문제를 수정했습니다.
- Super Memory에서 삭제된 콘텐츠가 다시 나타나는 문제와 브라우저 패널 상태가 예기치 않게 되돌아가는 문제를 수정했습니다.

### 개선

#### Agent 검색 및 실행

- Agent 검색, 도구 호출, 작업 실행 및 종료 로직을 최적화하여 중복 결론, 불필요한 대기 및 비정상적인 중단을 줄였습니다.
- 대규모 코드 검색의 결과 제한, 실행 시간 제한 및 스트리밍 상태를 최적화하여 지나치게 큰 결과 집합으로 인한 리소스 사용량을 줄였습니다.

#### 채팅 경험

- 채팅 완료 상태, 하단 도구 모음, 스크롤 위치 및 긴 대화 로딩을 개선했습니다.

#### 설정 및 사용량

- 모델 계정 및 OAuth 로그인 카드를 재설계하여 설정 페이지 전반의 시각적 계층과 상호 작용 패턴을 통일했습니다.
- Codex 사용량, 모델 메타데이터 및 관련 상태 표시를 개선했습니다.

## 1.2.6 · 2026-07-27

### 추가

#### 세션 수준 Chat Git

- 이제 같은 세션에서 AI가 생성한 코드 변경 사항을 함께 제출할 수 있습니다.
- 여러 Git 저장소를 동시에 감지하고 처리하는 기능을 추가했습니다.
- 제출 후 채팅 작업과 코드 리뷰 상태가 자동으로 동기화됩니다.

#### 공급자, 모델 및 기능

- OpenAI 호환 설정을 통해 **Poolside Laguna**에 액세스할 수 있는 **Poolside Platform** 공급자를 추가했습니다.
- **Qwen3.8**, **Opus 5** 및 **Pangu** 모델 설정을 추가했습니다.
- **LongCat**에 추론 재생 기능을 추가하여 도구 호출 후에도 추론 컨텍스트를 유지합니다.

#### 원격 워크스페이스 보안

- 원격 환경에서 Linux 루트 디렉터리 `/`에 접근할 때 보안 경고를 추가했습니다.
- `/proc`, `/sys`, `/dev`와 같은 Linux 가상 파일 시스템 경로를 이제 자동으로 제외합니다.

### 개선

#### 코드 리뷰

- 개별 코드 블록의 **수락/거부** 작업 표시줄을 새롭게 설계했습니다.
- **모두 유지**가 현재 테마의 강조 색상을 따르도록 업데이트했습니다.
- 인라인 작업 표시줄의 높이를 줄여 코드 영역을 더 컴팩트하게 만들었습니다.
- Git 커밋이 성공하면 리뷰 작업 표시줄이 자동으로 접히고 초기화됩니다.

#### 모델 선택기

- 키를 처음 입력한 후 목록 중복을 줄이기 위해 추천 모델 5개만 기본으로 활성화됩니다.
- OpenAI 호환 공급자의 기능이 이제 선택한 API 형식에 맞게 조정됩니다.

#### 코드 제출 및 SCM 새로 고침

- 파일을 저장하면 이제 활동 표시줄의 Git 상태가 자동으로 새로 고쳐집니다.
- Chat Git 제출은 이제 일관되게 **모든 변경 사항 유지**로 처리되며 해당 코드 리뷰 단계가 자동으로 완료됩니다.

#### 인터페이스

- 알림 제목에서 읽지 않음 표시를 제거했습니다.
- OpenAI 호환 모델 그룹의 호버 메뉴 전환을 개선했습니다.
- 도구 수 텍스트의 세로 정렬 문제를 수정했습니다.
- 밝은 테마에서 Kimi Mono 아이콘 스타일을 활성화했습니다.

### 수정

#### WSL 및 원격 Git

- WSL 확장 호스트가 시작될 때 충돌하는 문제를 수정했습니다.
- WSL 서버 프록시 설정이 일관되지 않은 문제를 수정했습니다.
- WSL 및 SSH 환경의 Git 상태 확인과 AI 생성 커밋 메시지가 이제 원격 환경을 인식하는 실행 채널을 통해 실행됩니다.
- 원격 워크스페이스의 Git 명령이 로컬 경로에서 실행되지 않도록 했습니다.
- Agent가 파일을 수정한 후 Git 저장소를 자동으로 닫는 문제를 수정했습니다.
- 원격 URI에서 상대 경로가 잘못 표시되는 문제를 수정했습니다.

#### 원격 SSH

- Remote SSH의 비밀번호 만료 처리를 수정했습니다. 서버가 저장된 비밀번호를 거부하면 해당 비밀번호를 삭제하고 같은 연결 시도 중에 다시 입력하도록 요청합니다.
- 커밋 해시가 일치하지 않는 REH 서버 패키지를 Remote SSH가 다운로드하지 않도록 하여 버전 불일치 오류와 원격 호스트 시작 실패를 방지했습니다.

#### 채팅 렌더링

- Mermaid 차트에 Trusted Types 지원을 추가했습니다.
- 안전하지 않거나 잘못된 Mermaid 태그로 인해 렌더링이 실패하지 않도록 태그 정제를 개선했습니다.

#### 규칙 및 메모리

- 편집기가 포커스를 잃은 후 빈 콘텐츠가 저장되는 문제를 수정했습니다.
- `.breezell` 설정을 변경한 후 리소스 관리자가 즉시 새로 고쳐지지 않는 문제를 수정했습니다.

#### 원격 트리 보기

- SSH Hosts 설정이 없을 때 의미 없는 트리 보기 오류가 반복해서 발생하지 않도록 했습니다.

## 1.2.5 · 2026-07-22

### 추가

- **Tencent Hunyuan HY3** 및 **TokenHub** 공급자와 모델 통합을 추가했습니다.
- **Gemini 3.6 Flash** 및 **Gemini 3.5 Flash-Lite**를 추가했으며, 두 모델 모두 공식적으로 일반 제공됩니다.
- 다중 루트 워크스페이스의 채팅 기록에 프로젝트 배지를 추가했습니다.
- 호환 공급자 채널의 기능 지원을 확장했습니다.
- 일본어, 스페인어, 포르투갈어 및 추가 언어의 인터페이스 번역을 추가했습니다.
- OpenAI 프로토콜 가이드를 업데이트하고 다음 두 가지 권장 사항을 더 명확하게 제시했습니다.
  - OpenAI 호환 엔드포인트는 기본적으로 OpenAI 프로토콜을 사용합니다.
  - GPT 모델에는 Responses API를 권장합니다.

### 수정

- 새로 만든 할 일이 **확인 대기 중** 상태에 계속 머무는 문제를 수정했습니다.
- 다단계 계획에서 각 배치 후 사용자가 수동으로 **계속**을 클릭해야 하는 문제를 수정했습니다.
- 체크포인트로 되돌린 후에도 시간, 리뷰, Git 및 도구 작업 표시줄이 강조되고 클릭 가능한 상태로 남는 문제를 수정했습니다.
- 그리기 패널의 권한 제한이 올바르게 동기화되지 않는 문제를 수정하고 불명확한 제한 메시지를 개선했습니다.
- 빈 캔버스를 처음 열 때 기본 노드가 추가되지 않는 문제를 수정했습니다.
- 여러 창에서 Chat 모드 세션이 유출되거나 섞이는 문제를 수정했습니다.
- 현재 선택한 모델을 삭제한 후 사용할 수 없는 모델로 되돌아가는 문제를 수정했습니다.
- Chat Git에서 단일 파일 스테이징이 제대로 작동하지 않는 문제를 수정했습니다.
- 여러 저장소 워크스페이스의 커밋 및 새로 고침 문제를 수정했습니다.
- 폴더를 워크스페이스에 추가한 후 채팅 기록이 사라지는 문제를 수정했습니다.
- WSL 및 SSH 환경에서 활동 표시줄 아이콘이 누락되는 문제를 수정했습니다.
- 탐색기의 프로젝트 목록이 깜박이는 문제를 수정했습니다.
- 저장소 보기에서 Git 상태를 동시에 확인할 때 확장 호스트가 과부하되는 문제를 수정했습니다.
- 잘못된 `****` 출력이 OpenAI 추론 스트림을 방해하는 문제를 수정했습니다.
- 편집 버블의 닫기 버튼 스타일을 수정했습니다.

### 개선

- 대시 타일로 시작 카드를 단순화하고 코드 리뷰 아이콘을 통일했습니다.
- Super Memory의 보조 텍스트를 기울임꼴로 변경했습니다.
- 설정 페이지의 공급자 카드를 통합했습니다.
- 네트워크 설정 대화 상자의 제목 레이아웃을 개선했습니다.
- 빈 모델 선택기의 현지화를 개선하고 선택기에서 설정을 바로 열 수 있도록 했습니다.
- 백그라운드 디렉터리의 `supportsFast` 기능이 요청 파이프라인을 올바르게 통과하도록 했습니다.
- **Qwen 3.7** 가격 정보를 수정했습니다.

## 1.2.4 · 2026-07-20

### 새 기능

#### 모델 및 공급자

- 조정 가능한 추론 강도와 Fast 채널을 포함한 **Grok 4.5**를 통합했습니다. **Claude Sonnet 5**는 **200K** 및 **1M** 컨텍스트 옵션을 제공합니다.
- Moonshot API와 Kimi Code 채널을 통해 **Kimi K3**를 추가했습니다. **256K** 및 **1M** 컨텍스트 옵션과 **Kimi K2.7 Code** 전체 지원을 제공합니다.
- Kuaishou의 전체 KAT-Coder 모델 제품군, 내장 Coding Plan 프리셋 및 종량제 엔드포인트 프리셋을 제공하는 **StreamLake** 공급자를 추가했습니다.
- Grok 계정의 OAuth 로그인을 추가했습니다.
- Fast 채널을 전역 토글에서 독립적인 **공급자 + 모델** 구성으로 재설계하여 Copilot, Codex, Claude 및 기타 공급자가 공식 채널 의미 체계를 사용하도록 했습니다.
- OpenAI 호환 구성을 고정하여 자주 사용하는 채널을 상단에 유지할 수 있습니다.
- 기간 한정 모델 체험 및 할인 지원을 추가하고 모델 선택기에 프로모션 배지를 표시합니다.
- 모델 디렉터리를 최신 플래그십 모델로 업데이트했습니다. Claude Fable 5, Claude Sonnet 5, Nemotron 3 Ultra, DeepSeek V4, GLM-5.2 및 MiniMax M3를 포함하며 오래된 항목은 제거했습니다.

#### 사용량, 모양 및 인터페이스

- Codex, Kimi 및 Copilot의 사용량과 재설정 시간을 중국어 간체, 중국어 번체, 한국어 및 러시아어로 표시하도록 사용량 센터를 업그레이드했습니다. 설정과 채팅 사이드바의 데이터가 실시간으로 동기화되며 Copilot 사용량은 Chat, Completions 및 Premium Requests를 별도로 표시합니다.
- 시작 페이지 제목을 전체 또는 모드별로 사용자 지정할 수 있으며 글꼴 크기와 굵기도 설정할 수 있습니다. 빠른 액세스 바로 가기에 **Elegant** 스타일을 추가했습니다.
- 일본어, 스페인어 및 브라질 포르투갈어 인터페이스 언어를 추가했습니다.
- 알림 센터가 제품 언어를 따르도록 재설계하고 Super Memory 카드 레이아웃을 새로 고쳤으며 채팅 입력란과 메시지 버블의 시각적 표현을 부드럽게 했습니다.

#### 브라우저, 채팅 및 워크스페이스

- 내장 브라우저에서 모든 탭 또는 개별 탭을 음소거할 수 있으며 패널 탭 목록과 브라우저가 실시간으로 동기화됩니다.
- 채팅 메시지에 최대 **10개의 이미지**를 포함할 수 있습니다. 이미지는 자동으로 크기가 조정되고 컨텍스트 계산에 포함됩니다. 턴 소요 시간 표시, 메시지 내 원클릭 롤백, 외부 또는 내장 브라우저에서 링크를 여는 옵션을 추가했습니다.
- 채팅 커밋 대화 상자가 여러 저장소 워크스페이스를 지원합니다. 저장소별 커밋 정보 생성, 독립 제출, 대화 상자에서 직접 저장소 초기화, 재시작 후 커밋/푸시 진행 상태 보존을 지원합니다.
- 리소스 관리자에 프로젝트 그룹화를 추가하고 여러 창 간 협업 상태 업데이트를 더 신속하게 했습니다.
- 대화 기록을 재사용 가능한 경험으로 자동 정제하고 다국어 중복 제거를 지원하는 영구 메모리를 추가했습니다.

- **작업 목록 최적화**: 작업 병합, 우선순위 정렬 및 새로운 전환 애니메이션을 지원합니다.
- **팀 대시보드 재설계**: 새로운 어두운 테마 디자인과 더 빠른 페이지 로딩을 제공합니다.
- **대화 메시지 지연 로딩**: 긴 기록을 한 번에 모두 로드하지 않아 더 빠르게 열립니다.
- **API 캐시 메커니즘**: Responses API 캐시를 추가하여 중복 요청을 줄이고 토큰을 절약합니다.

### 개선

- 편집기 백엔드를 업그레이드했습니다. Electron은 41.2.0으로, TypeScript는 6.0으로 업그레이드하여 더 안정적이고 원활하게 작동합니다.
- 파일 작업, MCP 도구 등의 카드 스타일을 통일하도록 AI 도구 호출 인터페이스를 재설계했습니다.
- 코드 diff를 최적화하여 접힌 상태의 스크롤, 가로 스크롤바 및 배경색 표시를 수정했습니다.
- 시스템 알림을 최적화하여 중복 푸시를 방지하고 최소화할 때 연결 해제 보고를 하지 않습니다.
- 터미널 명령 감지를 최적화하여 명령 실행 여부를 더 정확히 식별합니다.
- 시작 흐름과 대화 목록 렌더링을 최적화하여 시작 성능을 개선했습니다.
- 장시간 실행 중 누적된 메모리를 자동으로 정리하여 백그라운드 메모리 오버플로를 방지합니다.

### 수정

- 대화 스레드 사이를 전환할 때 대기 중인 메시지가 잘못된 스레드로 전송될 수 있는 문제를 수정했습니다.
- 이미지 첨부 파일을 삭제할 때 다른 파일 첨부 파일이 삭제될 수 있는 문제를 수정했습니다.
- AI 응답 시간 초과 후에도 백그라운드 프로세스가 계속 실행되는 문제를 수정했습니다.
- TrustedHTML 호환성 문제로 인해 빈 페이지가 표시되는 문제를 수정했습니다.
- 내장 브라우저에서 링크를 클릭해도 새 페이지가 올바르게 열리지 않는 문제를 수정했습니다.
- AI에 질문할 때 옵션 버튼이 가끔 표시되지 않는 문제를 수정했습니다.
- 편집기 탭 아이콘이 정렬되지 않는 문제를 수정했습니다.
