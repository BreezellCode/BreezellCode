# 변경 사항

## 1.2.7 · 2026-07-29

### 새 기능

- 대규모 코드베이스의 이해와 탐색 효율을 개선했습니다.
- 답변 품질, 요구 사항 이해, 검증 신뢰도를 평가하는 선택형 인사이트를 추가했습니다.
- 캐시 통계 상세 화면에서 페이지 나누기, 연동 필터링 및 다국어 표시를 지원합니다.

### 수정 및 개선

- 소스 제어 새로 고침 후 커밋 메시지 입력이 비거나 무효화되는 문제를 수정했습니다.
- Agent 추론 중단, 터미널 상태 오판, 백그라운드 명령 종료 코드 손실 및 작업 조기 종료를 수정했습니다.
- 메시지 편집 및 재전송 시 대화가 조기에 잘리는 문제를 수정했습니다.
- WSL 및 Remote SSH 환경의 경로, 호스트 시작, 비밀번호 재시도 및 서버 캐싱을 개선했습니다.
- KaTeX, 코드 블록 테마, 중국어 글꼴, 파일 아이콘 정렬 문제를 수정했습니다.
- Agent 검색, 도구 호출, 작업 실행 및 종료 로직을 최적화했습니다.
- 긴 대화의 완료 상태, 하단 도구 모음, 스크롤 및 로딩 경험을 개선했습니다.
- 모델 계정과 OAuth 로그인 카드를 재설계하고 Codex 사용량 및 모델 메타데이터 표시를 개선했습니다.
