# 소개

Breezell은 VS Code(Code – OSS)를 기반으로 하는 AI 코드 편집기입니다. AI 에이전트, 다중 모델 지원, 깊은 코드베이스 이해를 하나의 도구에 결합하여 품질을 유지하면서 개발 속도를 높입니다.

## 주요 기능

- **여러 AI 모델** — Claude, GPT, Gemini, Grok, DeepSeek 등을 자유롭게 전환합니다.
- **여러 작업 모드** — Chat, Agent, Analyze, Plan, Entanglement, Teams를 제공합니다.
- **깊은 코드베이스 이해** — 코드 인덱싱, 정의로 이동, 순환 감지와 영향 추적을 포함한 의존성 분석을 제공합니다.
- **규칙, 메모리, 스킬** — 영구 규칙, 프로젝트 메모리, 재사용 가능한 스킬 라이브러리로 AI 동작을 조정합니다.
- **내장 데이터베이스 작업** — 편집기 안에서 SQLite, MongoDB, Oracle, Redis, MariaDB 등을 연결하고 관리합니다.
- **내장 브라우저** — 스크린샷, 클릭, 탐색, DOM 스냅샷 자동화와 기기 뷰포트 시뮬레이션을 제공합니다.
- **MCP 지원** — Model Context Protocol을 통해 외부 도구와 서비스에 연결합니다.
- **풍부한 워크스페이스** — 라이브 테마 미리보기, 아이콘 라이브러리, SSH 원격 개발을 제공합니다.

## 주요 내용

최신 Breezell 릴리스는 더 똑똑한 에이전트, 더 깊은 코드 이해 및 강력한 올인원 워크스페이스에 집중합니다.

- **Code Review Panel** — 줄 번호 diff, 대용량 파일 Myers diff, 원클릭 롤백, AI 검토용 채팅 전송을 제공합니다.
- **Entanglement 모드** — 의도 인식 응답을 위한 감정 인식 인과 추론을 제공합니다.
- **Parallel AI Teammates** — 복잡한 작업을 위해 여러 AI 팀원을 병렬로 실행합니다.
- **Super Memory** — 세션 간 컨텍스트를 기억하는 시간 인식 장기 메모리입니다.
- **리치 렌더링** — LaTeX, Mermaid, 확장 가능한 도구 카드, 내장 웹 검색을 채팅에서 제공합니다.

## 시작하기

1. 플랫폼용 Breezell을 다운로드하여 설치합니다.
2. API 키, 체험판 또는 구독 플랜을 선택합니다.
3. 프로젝트를 열고 AI 모델을 선택합니다.
4. Chat, Agent, Plan 등의 모드를 선택하고 개발을 시작합니다.
