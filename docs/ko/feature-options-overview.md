# 기능 옵션 개요

이 페이지에서는 Breezell 설정에서 사용할 수 있는 주요 기능 옵션을 요약합니다. 이러한 옵션은 자동 완성, 알림, 도구 권한, 편집기 동작, 지능형 기능 및 시스템 액세스를 제어합니다.

## 도움말

### 자동 완성 및 알림

| 기능 | 설명 |
| --- | --- |
| 자동 완성 | BreezellTab은 AI 기반 코드 완성을 제공합니다. `Tab`을 눌러 제안을 적용합니다. |
| 시스템 알림 | 시스템 알림 동작을 구성합니다. 편집기가 최소화되거나 포커스를 잃으면 Breezell이 시스템 알림을 표시할 수 있습니다. |

## 실행

### 도구 권한

이 옵션은 특정 도구 작업을 수동 확인 없이 자동으로 실행할 수 있는지 제어합니다.

| 기능 | 설명 |
| --- | --- |
| 편집 자동 승인 | 확인 없이 편집 작업을 자동으로 실행할 수 있습니다. |
| 터미널 자동 승인 | 확인 없이 터미널 작업을 자동으로 실행할 수 있습니다. |
| 데이터베이스 작업 자동 승인 | 확인 없이 데이터베이스 작업을 자동으로 실행할 수 있습니다. |
| 미디어 생성 자동 승인 | 확인 없이 미디어 생성 작업을 자동으로 실행할 수 있습니다. |
| MCP 도구 자동 승인 | 확인 없이 MCP 도구 작업을 자동으로 실행할 수 있습니다. |
| Teams 자동 승인 | 수동 확인 없이 팀 생성을 자동으로 승인합니다. |

## 편집기

### 코드 동작

| 기능 | 설명 |
| --- | --- |
| Lint 오류 자동 수정 | 지원되는 경우 Lint 오류를 자동으로 수정합니다. |
| 코드 변경 자동 수락 | 생성되거나 수정된 코드 변경을 자동으로 수락합니다. |
| 편집 중 파일 자동 열기 | 편집하는 동안 파일을 자동으로 엽니다. |
| 선택 시 인라인 제안 표시 | 텍스트나 코드를 선택하면 인라인 제안을 표시합니다. |

### Git 커밋 메시지

이 옵션을 사용하면 Breezell이 현재 코드 변경 사항을 바탕으로 Git 커밋 메시지를 생성합니다. 커밋 요약을 직접 작성하지 않고 명확한 요약을 얻고 싶을 때 유용합니다.

![채팅 모델로 커밋 메시지 생성](/feature-options/git-commit-message.png)

| 기능 | 설명 |
| --- | --- |
| 채팅 모델로 커밋 메시지 생성 | 현재 코드 변경 사항을 바탕으로 Git 커밋 메시지를 자동으로 생성합니다. |

이 옵션을 활성화하면 Breezell이 현재 변경 집합을 검토하고 선택한 채팅 모델로 커밋 메시지를 만들 수 있습니다. 프로젝트에 특정 커밋 형식이 필요하다면 커밋 전에 생성된 메시지를 검토합니다.

## 시스템

### 네트워크 설정

| 기능 | 설명 |
| --- | --- |
| 시스템 프록시 사용 | API 요청을 보낼 때 시스템 프록시를 사용합니다. 프록시가 필요하지 않거나 불안정한 경우 응답 속도를 높이기 위해 이 옵션을 비활성화하는 것이 좋습니다. |

| 기능 | 설명 |
| --- | --- |

| 외부 파일에 대한 쓰기 액세스 허용 | 도구가 워크스페이스 외부의 파일을 수정할 수 있도록 합니다. 두 외부 파일 액세스 옵션은 기본적으로 활성화되어 있습니다. |

## 참고

자동 승인 및 외부 액세스 옵션은 워크플로 속도를 높일 수 있지만 수동 검토도 줄입니다. 워크스페이스 정책과 신뢰 수준에 맞는 경우에만 활성화하세요.
