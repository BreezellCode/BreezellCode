# 모드 선택

Breezell은 다양한 자율성, 깊이 및 워크플로 제어 수준에 맞는 여러 작업 모드를 제공합니다. Agent는 기본 모드이며 대부분의 작업에 권장되는 자동 워크플로입니다.

빠른 대화, 읽기 전용 분석, 편집 전 계획, 더 깊은 인과 추론 또는 병렬 AI 팀원과 같이 더 구체적인 상호 작용 방식이 필요할 때 다른 모드를 사용합니다.

## Chat

Chat은 빠른 질문과 답변을 위한 모드입니다.

코드에 대해 질문하거나 아이디어를 설명하거나 옵션을 비교하거나 빠른 응답을 받고 싶지만 Breezell이 자율적으로 파일을 편집하거나 도구를 실행하기를 원하지 않을 때 Chat을 사용합니다.

Chat 모드에서는 모델이 파일을 편집할 수 없습니다.

## Agent

Agent를 사용하면 Breezell이 프로젝트를 검사하고, 파일을 편집하고, 도구를 사용하고, 명령을 실행하고, 코딩 작업을 완료할 수 있습니다.

대부분의 개발 작업에는 Agent를 사용합니다. 합리적인 워크플로를 자동으로 선택하고 필요한 컨텍스트를 수집하며 변경 사항을 만들고 전달 전에 결과를 검증할 수 있기 때문에 기본 모드입니다.

## Analyze

Analyze는 읽기 전용 조사에 사용합니다.

파일을 변경하지 않고 Breezell이 코드를 검사하고, 문제를 진단하고, 아키텍처를 검토하거나 동작을 감사하도록 하려면 Analyze를 사용합니다. 수정할 내용을 결정하기 전에 기술적인 분석 결과가 필요할 때 유용합니다.

## Plan

Plan은 편집 전에 구조화된 구현 경로를 만듭니다.

복잡한 기능, 대규모 리팩터링, 명확하지 않은 요구 사항 또는 코드 변경을 시작하기 전에 설계 결정이 필요한 작업에는 Plan을 사용합니다.

팁: Agent 모드에서 작업에 구조화된 구현 경로가 필요하면 Breezell이 Plan으로 전환할 수 있습니다. 전환을 허용하거나 거부할 수 있습니다. 전체 자동 모드가 활성화되어 있으면 적절한 경우 Breezell이 전환을 자동으로 확인할 수 있습니다.

## Entanglement

Entanglement는 더 깊은 제품 및 코드 결정을 위해 인과 추론과 컨텍스트 인식을 사용합니다.

Entanglement는 Breezell이 독립적으로 연구하고 출시한 모드입니다. Breezell 전용 모드이며 웹 전체에서 고유합니다.

인과 상태 추적과 검증 루프에 대한 기술 개요는 [Entanglement 모드 개요](/ko/entanglement-mode-overview)를 참조하세요.

요청이 의도, 트레이드오프, 숨은 원인, 감정적 뉘앙스 또는 직접적인 답변 이상의 다단계 추론에 의존할 때 Entanglement를 사용합니다.

팁: 이 모드는 모델 기능을 크게 향상할 수 있지만 표준 워크플로보다 더 많은 리소스를 사용합니다. 부작용은 알려지지 않았습니다.

팁: Entanglement 컨텍스트가 이미 주입되어 있으므로 같은 대화에서 Entanglement에서 Agent로 전환해도 Entanglement 동작이 완전히 비활성화되지 않습니다. 대화는 Entanglement 기능과 리소스 사용을 계속 유지합니다. 일반 Agent 워크플로로 돌아가려면 새 대화를 시작합니다.

## Teams

Teams는 대규모 기능과 병렬 워크플로를 위해 여러 AI 팀원을 조정합니다.

여러 영역을 조사하거나 구현을 비교하거나 더 큰 프로젝트의 여러 부분을 동시에 진행하는 것처럼 작업을 독립적인 워크스트림으로 나눌 수 있을 때 Teams를 사용합니다.

팁: 이 모드는 모델 기능을 크게 향상할 수 있지만 표준 워크플로보다 더 많은 리소스를 사용합니다.

제한 사항: 병렬 팀원 간 읽기 및 쓰기 충돌로 인해 Teams가 제한될 수 있습니다. Breezell은 이러한 충돌을 줄이기 위해 노력하지만 대규모 병렬 작업은 여전히 조정하기 어려울 수 있으며 여러 팀원이 겹치는 영역을 수정하면 혼란이 발생할 수 있습니다.

## 모드 선택하기

대부분의 작업에서는 기본 Agent 모드를 유지합니다. 작업에 다른 워크플로가 분명히 필요할 때만 모드를 변경합니다.

| 모드 | 적합한 작업 |
| --- | --- |
| Chat | 빠른 대화와 간단한 설명 |
| Agent | 기본 코딩 워크플로, 파일 편집, 도구 및 검증 |
| Analyze | 읽기 전용 진단, 리뷰 및 아키텍처 조사 |
| Plan | 변경 전 구조화된 구현 계획 |
| Entanglement | 깊은 인과 추론과 컨텍스트 기반 의사 결정 |
| Teams | 대규모 또는 독립적인 워크스트림을 위한 병렬 AI 팀원 |
