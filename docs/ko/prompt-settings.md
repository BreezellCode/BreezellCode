# 프롬프트 설정

## 프롬프트 설정 열기

이미지의 화살표는 대화 상자 오른쪽 상단 도구 모음의 프롬프트 설정 버튼을 가리킵니다. 이 버튼은 **New Chat**(`+`) 버튼 바로 오른쪽에 있습니다.

![대화 상자에서 강조 표시된 프롬프트 설정 버튼](/custom-api/prompt-settings.png)

이 버튼을 클릭하면 프롬프트 설정이 열립니다. 여기에서 대화 중 Breezell이 따라야 할 지침을 설정할 수 있습니다.

## 명확한 지침 작성하기

Breezell이 수행할 역할, 목표, 출력 형식 및 제약 조건을 설명하세요. 지침을 구체적이고 집중해서 작성하면 대화의 방향을 명확히 할 수 있습니다.
