# Entanglement 모드

> 복잡하고 불확실한 문제를 구조화된 조사 방식으로 해결하도록 돕는 모드입니다.

## Entanglement가 돕는 작업

Entanglement는 원인이 명확하지 않고 여러 확인이 필요할 수 있는 작업을 위한 모드입니다. 작업하는 동안 Breezell이 조사 흐름을 명확하게 유지하도록 돕습니다.

- 알려지지 않은 버그와 회귀를 조사합니다.
- 여러 파일이나 모듈의 단서를 연결합니다.
- 가설, 유용한 증거, 다음 단계 및 결론을 정리합니다.
- 도구를 사용한 확인과 후속 검증을 지원합니다.
- 구조화된 패널에 조사 진행 상황을 표시합니다.
- 유사한 문제를 다시 검토할 수 있도록 유용한 결론을 보존합니다.

## 표시되는 정보

모드 선택기에서 Entanglement를 선택하면 Breezell이 다음 정보를 표시할 수 있습니다.

- 현재 조사 단계
- 진행 중인 가설과 이를 뒷받침하는 증거
- 예정된 확인 작업과 검증 결과
- 현재 신뢰도와 확인된 결론
- 이전 방향을 다시 검토해야 할 때의 보정 내용

## 사용 시기

다음과 같은 경우 Entanglement를 사용합니다.

- 근본 원인을 알 수 없는 경우
- 여러 파일, 모듈 또는 시스템에 걸친 문제인 경우
- 코드를 변경하기 전에 가능한 설명을 비교해야 하는 경우
- 후속 테스트나 관찰로 결과를 확인해야 하는 경우

명확하고 범위가 제한된 변경이나 일반적인 코딩 작업에는 기본 Agent 모드가 더 적합합니다.

## 시작 방법

1. 모드 선택기에서 Entanglement를 선택합니다.
2. 증상, 목표 및 관련 제약 조건을 설명합니다.
3. Breezell이 조사에 필요한 컨텍스트를 확인하도록 합니다.
4. 패널에 표시되는 가설, 확인 작업 및 결론을 검토합니다.
5. 추가 증거나 검증이 필요하면 대화를 계속합니다.

## Entanglement와 Agent

Agent는 일반적인 개발 작업을 위한 기본 모드입니다. Entanglement는 더 신중한 추론과 후속 확인이 필요한 문제에 초점을 둔 선택지입니다.

작업에 맞는 모드를 선택하세요. 직접 구현에는 Agent를 사용하고, 불확실하거나 여러 단계가 필요한 조사에는 Entanglement를 사용할 수 있습니다.

## 중요 참고 사항

Entanglement 패널은 의사 결정을 돕는 기능입니다. 중요한 변경 사항을 적용하기 전에 표시된 결론과 검증 결과를 검토하세요.
