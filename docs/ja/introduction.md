# はじめに

Breezell は VS Code（Code – OSS）を基盤とした AI コードエディターです。AI エージェント、複数モデルのサポート、深いコードベース理解を一つのツールに統合し、品質を損なわずに開発を加速します。

## 主な機能

- **複数の AI モデル** — Claude、GPT、Gemini、Grok、DeepSeek などを自由に切り替えられます。
- **複数の作業モード** — Chat、Agent、Analyze、Plan、Entanglement、Teams を用途に応じて利用できます。
- **深いコードベース理解** — インテリジェントなコードインデックス、定義へのジャンプ、循環検出と影響追跡を含む依存関係分析を提供します。
- **ルール、メモリー、スキル** — 永続ルール、プロジェクトメモリー、再利用可能なスキルライブラリで AI の振る舞いを調整できます。
- **組み込みデータベース操作** — SQLite、MongoDB、Oracle、Redis、MariaDB などにエディター内から接続し管理できます。
- **組み込みブラウザー** — スクリーンショット、クリック、ナビゲーション、DOM スナップショット、自動化、デバイスビューポートシミュレーションを備えます。
- **MCP サポート** — Model Context Protocol を通じて外部ツールやサービスに接続できます。
- **充実したワークスペース** — ライブテーマプレビュー、組み込みアイコンライブラリ、完全な SSH リモート開発を提供します。

## ハイライト

最新の Breezell リリースは、より賢いエージェント、より深いコード理解、強力なオールインワンワークスペースに重点を置いています。

- **Code Review Panel** — 行番号付き差分、大きなファイルの Myers diff、ワンクリックロールバック、AI レビュー用のチャット送信を備えた独立レビュー画面です。
- **Entanglement モード** — 感情認識を伴う因果推論により、意図を理解した高品質な回答を提供します。
- **Parallel AI Teammates** — 複数の AI チームメイトを並列に実行して、複雑なタスクに取り組めます。
- **Super Memory** — セッションをまたいで文脈を記憶する、時間認識型の長期メモリーです。
- **最新のコードベースツール** — ディスクとの同期を維持するコードシンボルインデックスと依存関係分析を提供します。
- **幅広いモデルとプロバイダーのサポート** — Claude、GPT、Gemini、DeepSeek、Kimi、MiniMax、GLM、GitHub Copilot、OpenAI 互換プロバイダーを利用できます。
- **リッチレンダリング** — LaTeX、Mermaid、展開可能なツールカード、組み込み Web 検索をチャット内で利用できます。
- **完全な SSH リモート開発** — リモート SSH ホスト上で完全なツールチェーンを実行できます。

## はじめる

1. 利用するプラットフォーム向けに Breezell をダウンロードしてインストールします。
2. 自分の API キー、トライアル、サブスクリプションからプランを選択します。
3. プロジェクトを開き、AI モデルを選択します。
4. Chat、Agent、Plan などのモードを選び、よりスマートにコーディングを始めます。
