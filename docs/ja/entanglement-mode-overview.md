# Entanglement モード

> 複雑で不確実な問題に、構造化された調査支援を提供するモードです。

## Entanglement でできること

Entanglement は、原因が明確でなく、複数の確認が必要になる可能性があるタスク向けです。作業中も Breezell が調査の流れを整理して保持できるようにします。

- 未知のバグやリグレッションを調査する。
- 複数のファイルやモジュールにある手がかりを結び付ける。
- 仮説、役立つ証拠、次の手順、結論を整理して保持する。
- ツールを使った確認と追加の検証を支援する。
- 構造化されたパネルで調査の進捗を表示する。
- 類似した問題を後から見直せるよう、有用な結論を保持する。

## 表示される情報

モードセレクターから Entanglement を選択すると、Breezell は次の情報を表示できます。

- 現在の調査段階。
- 作業中の仮説と、それを支える証拠。
- 予定している確認と検証結果。
- 現在の確信度と特定された結論。
- 以前の方向性を見直す必要がある場合の修正。

## 使用する場面

次のような場合に Entanglement を使用します。

- 根本原因が不明な場合。
- 複数のファイル、モジュール、システムにまたがる問題の場合。
- コードを変更する前に、考えられる説明を比較したい場合。
- 追加のテストや観察によって結果を確認する必要がある場合。

明確で限定的な変更や通常のコーディングタスクには、デフォルトの Agent モードの方が適しています。

## 開始方法

1. モードセレクターから Entanglement を選択します。
2. 症状、目的、関連する制約を説明します。
3. 調査に必要なコンテキストを Breezell が確認できるようにします。
4. パネルに表示される仮説、確認内容、結論を確認します。
5. 追加の証拠や検証が必要な場合は、会話を続けます。

## Entanglement と Agent

Agent は一般的な開発作業のデフォルトモードです。Entanglement は、より慎重な推論と追加確認が必要な問題に焦点を当てた選択肢です。

タスクに合ったモードを選択してください。直接実装には Agent、不確実または複数段階の調査には Entanglement を使用できます。

## 重要な注意

Entanglement パネルは意思決定を支援するためのものです。重要な変更を適用する前に、表示された結論と検証結果を確認してください。
