# 更新履歴

## 1.2.7 · 2026-07-29

### 新機能

- 大規模コードベースの理解とナビゲーション効率を改善しました。
- 回答品質、要件理解、検証の確信度を評価する任意の回答品質インサイトを追加しました。
- キャッシュ統計の詳細画面で、ページネーション、連動フィルタリング、多言語表示をサポートしました。

### 修正

#### ソース管理と Agent ランタイム

- ソース管理リポジトリの更新、ビュー切替、コンポーネント再構築後にコミットメッセージ入力欄が空または無効になる問題を修正しました。
- Agent の推論停止、誤ったターミナル状態判定、バックグラウンドコマンドの終了コード消失、タスクの早期終了を修正しました。
- キューメッセージ編集、ツール呼び出しのフィードバック、タスクリスト復元、連続ターンの状態に関する問題を修正しました。

#### チャットとリモート環境

- メッセージの編集・再送信時に元の会話が早期に切り詰められる問題を修正しました。検証完了後にメッセージをアトミックに置換します。
- WSL および Remote SSH のリモートパス問題を修正し、ホスト起動、パスワード再試行、サーバーキャッシュを改善しました。

#### レンダリング、モデル、状態

- KaTeX のブロック数式解析、コードブロックテーマ、中国語フォント描画、ファイルアイコン配置を修正しました。
- 一部モデルで空の応答が表示される、エラースタックが露出する、異常なプロバイダーネットワークリクエストが発生する問題を修正しました。
- Super Memory で削除済みコンテンツが再表示される問題と、ブラウザーパネル状態が予期せず戻る問題を修正しました。

### 改善

#### Agent の検索と実行

- Agent の検索、ツール呼び出し、タスク実行、終了ロジックを最適化し、冗長な結論、不要な待機、異常な中断を減らしました。
- 大規模コード検索の結果件数、実行タイムアウト、ストリーミング状態を最適化し、巨大な結果セットによるリソース消費を削減しました。

#### チャット体験

- チャット完了状態、下部ツールバー、スクロール位置、長い会話の読み込みを改善しました。

#### 設定と使用状況

- モデルアカウントおよび OAuth サインインカードを再設計し、設定ページ全体で視覚階層と操作パターンを統一しました。
- Codex の使用状況、モデルメタデータ、関連する状態表示を改善しました。
