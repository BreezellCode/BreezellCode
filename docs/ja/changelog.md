# 更新履歴

## 1.2.7 · 2026-07-29

### 新機能

- 大規模コードベースの理解とナビゲーション効率を改善しました。
- 今回の回答品質、要件理解、検証の確信度を評価する、任意の回答品質インサイトを追加しました。
- キャッシュ統計の詳細画面で、ページネーション、連動フィルタリング、多言語表示をサポートしました。

### 修正

#### ソース管理と Agent ランタイム

- ソース管理リポジトリの更新、ビュー切り替え、コンポーネント再構築後にコミットメッセージ入力欄が空または無効になる問題を修正しました。
- Agent の推論停止、誤ったターミナル状態判定、バックグラウンドコマンドの終了コード消失、タスクの早期終了を修正しました。
- キューメッセージ編集、ツール呼び出しのフィードバック、タスクリスト復元、連続ターンの状態に関する問題を修正しました。

#### チャットとリモート環境

- メッセージの編集・再送信時に元の会話が早期に切り詰められる問題を修正しました。検証完了後にメッセージをアトミックに置換します。
- WSL および Remote SSH のリモートパス問題を修正し、ホスト起動、パスワード再試行、サーバーキャッシュを改善しました。

#### レンダリング、モデル、状態

- KaTeX のブロック数式解析、コードブロックテーマ、中国語フォント描画、ファイルアイコン配置を修正しました。
- 一部モデルで空の応答が表示される、エラースタックが露出する、異常なプロバイダーネットワークリクエストが発生する問題を修正しました。
- Super Memory で削除済みコンテンツが再表示される問題と、ブラウザーパネルの状態が予期せず戻る問題を修正しました。

### 改善

#### Agent の検索と実行

- Agent の検索、ツール呼び出し、タスク実行、終了ロジックを最適化し、冗長な結論、不要な待機、異常な中断を減らしました。
- 大規模コード検索の結果件数、実行タイムアウト、ストリーミング状態を最適化し、巨大な結果セットによるリソース消費を削減しました。

#### チャット体験

- チャット完了状態、下部ツールバー、スクロール位置、長い会話の読み込みを改善しました。

#### 設定と使用状況

- モデルアカウントおよび OAuth サインインカードを再設計し、設定ページ全体で視覚階層と操作パターンを統一しました。
- Codex の使用状況、モデルメタデータ、関連する状態表示を改善しました。

## 1.2.6 · 2026-07-27

### 追加

#### セッション単位の Chat Git

- 同じセッションで AI が生成したコード変更をまとめて送信できるようになりました。
- 複数の Git リポジトリを同時に検出・処理できるようになりました。
- チャットタスクとコードレビューの状態が、送信後に自動的に同期されるようになりました。

#### プロバイダー、モデル、機能

- OpenAI 互換設定から **Poolside Laguna** にアクセスできる **Poolside Platform** プロバイダーを追加しました。
- **Qwen3.8**、**Opus 5**、**Pangu** のモデル設定を追加しました。
- **LongCat** に推論リプレイを追加し、ツール呼び出し後も推論コンテキストを保持するようにしました。

#### リモートワークスペースのセキュリティ

- リモート環境で Linux のルートディレクトリ `/` にアクセスするときにセキュリティ警告を表示するようにしました。
- `/proc`、`/sys`、`/dev` などの Linux 仮想ファイルシステムパスを自動的に除外するようにしました。

### 改善

#### コードレビュー

- 個々のコードブロック用の **承認/却下** アクションバーを再設計しました。
- **すべて保持** が現在のテーマのアクセントカラーに従うように更新しました。
- インラインアクションバーの高さを低くし、コード領域をよりコンパクトにしました。
- Git コミットが成功すると、レビューアクションバーが自動的に折りたたまれてリセットされるようになりました。

#### モデルセレクター

- 初めてキーを入力した後は、リストの重複を減らすため、推奨モデル5件だけがデフォルトで有効になります。
- OpenAI 互換プロバイダーの機能が、選択した API 形式に合わせて適応するようになりました。

#### コード送信と SCM 更新

- ファイルを保存すると、アクティビティバーの Git 状態が自動的に更新されるようになりました。
- Chat Git の送信は一律 **すべての変更を保持** として扱われ、対応するコードレビュー手順が自動的に完了するようになりました。

#### インターフェース

- 通知タイトルから未読インジケーターを削除しました。
- OpenAI 互換モデルグループのホバーメニュー切り替えを改善しました。
- ツール数テキストの垂直位置を修正しました。
- ライトテーマで Kimi Mono のアイコンスタイルを有効にしました。

### 修正

#### WSL とリモート Git

- WSL 拡張ホストの起動時にクラッシュする問題を修正しました。
- WSL サーバーのプロキシ設定が一致しない問題を修正しました。
- WSL および SSH 環境での Git 状態チェックと AI 生成コミットメッセージが、リモート環境対応の実行チャネルを通じて実行されるようになりました。
- リモートワークスペースの Git コマンドがローカルパスに対して実行されないようにしました。
- ファイル変更後に Agent が Git リポジトリを自動的に閉じる問題を修正しました。
- リモート URI で相対パスが誤って表示される問題を修正しました。

#### Remote SSH

- Remote SSH のパスワード有効期限処理を修正しました。サーバーに拒否された保存済みパスワードを消去し、同じ接続試行中に再入力を求めるようになりました。
- コミットハッシュが一致しない REH サーバーパッケージを Remote SSH がダウンロードしないようにし、バージョン不一致エラーとリモートホスト起動失敗を防止しました。

#### チャットのレンダリング

- Mermaid チャートに Trusted Types のサポートを追加しました。
- 安全でないタグや不正な形式のタグによってレンダリングが失敗しないよう、Mermaid タグのサニタイズを改善しました。

#### ルールとメモリ

- エディターがフォーカスを失った後に空の内容が保存される問題を修正しました。
- `.breezell` 設定の変更後にリソースマネージャーがすぐに更新されない問題を修正しました。

#### リモートツリービュー

- SSH Hosts の設定がない場合に、意味のないツリービューエラーが繰り返し出力されないようにしました。

## 1.2.4 · 2026-07-20

### 新機能

#### モデルとプロバイダー

- 推論強度を調整できる Fast チャネルを含む **Grok 4.5** を統合しました。**Claude Sonnet 5** では **200K** と **1M** のコンテキストを選択できます。
- Moonshot API と Kimi Code チャネルに **Kimi K3** を追加しました。**256K** と **1M** のコンテキスト、さらに **Kimi K2.7 Code** の完全サポートを提供します。
- Kuaishou の KAT-Coder モデルファミリー全体、組み込み Coding Plan プリセット、従量課金エンドポイントプリセットを備えた **StreamLake** プロバイダーを追加しました。
- Grok アカウントの OAuth サインインを追加しました。
- Fast チャネルをグローバルなトグルから独立した **プロバイダー + モデル** 設定へ再設計し、Copilot、Codex、Claude などが公式チャネルのセマンティクスを使用するようにしました。
- OpenAI 互換設定をピン留めし、よく使うチャネルを上部に固定できるようになりました。
- 期間限定のモデル試用と割引をサポートし、モデルセレクターにプロモーションバッジを表示するようにしました。
- モデルディレクトリを最新のフラグシップモデルで更新しました。Claude Fable 5、Claude Sonnet 5、Nemotron 3 Ultra、DeepSeek V4、GLM-5.2、MiniMax M3 などを追加し、古い項目を削除しました。

#### 使用状況、外観、インターフェース

- 使用状況センターをアップグレードし、Codex、Kimi、Copilot の使用量とリセット時刻を簡体字中国語、繁体字中国語、韓国語、ロシア語で表示できるようにしました。設定とチャットサイドバーのデータはリアルタイムに同期され、Copilot の使用量は Chat、Completions、Premium Requests を個別に表示します。
- 歓迎ページのタイトルを全体またはモードごとにカスタマイズできるようになりました。フォントサイズと太さにも対応し、クイックアクセスショートカット用に **Elegant** スタイルを追加しました。
- 日本語、スペイン語、ブラジルポルトガル語のインターフェース言語を追加しました。
- 通知センターを製品の言語に合わせて再設計し、Super Memory カードのレイアウトを更新するとともに、チャット入力欄とメッセージバブルの表示を柔らかくしました。

#### ブラウザー、チャット、ワークスペース

- 内蔵ブラウザーで、すべてのタブまたは個別のタブをミュートできるようになりました。パネルのタブリストとブラウザーの間もリアルタイムに同期されます。
- チャットメッセージに最大 **10枚の画像** を含められるようになりました。画像は自動的にリサイズされ、コンテキスト計算に含まれます。ターンの所要時間表示、メッセージ内のワンクリックロールバック、外部または内蔵ブラウザーでリンクを開くオプションを追加しました。
- チャットのコミットダイアログがマルチリポジトリワークスペースに対応しました。リポジトリごとのコミット情報生成、個別送信、ダイアログからの直接初期化、再起動後のコミット/プッシュ進捗の保持が可能です。
- リソースマネージャーにプロジェクトグループを追加し、複数ウィンドウ間のコラボレーション状態をより速く更新するようにしました。
- 会話履歴を再利用可能な経験へ自動的に抽出し、多言語の重複除去に対応する永続メモリを追加しました。

#### 診断と生産性

- ターンごとのキャッシュ通知と、今日と昨日を比較するワークスペース日次レポートを含むキャッシュ可視化を追加しました。セッション/ワークスペースフィルター、推定節約量、キャッシュミス分析を利用できます。
- チャットで HTML デザイン案を直接生成し、確認後に適用できるインタラクティブデザインカードを追加しました。
- プロバイダーネットワーク設定で、直接接続、システムプロキシ、グローバルプロキシ、カスタムルートの速度テストをワンクリックで並列実行できるようになりました。推奨ルートは自動的に表示され、ルーティングバッジは設定ページでリアルタイムに更新されます。
- PDF ビューアーのコアをアップグレードし、新しいツールバーを追加しました。添付ファイルはページ単位で計測され、コンテキストが制限されると自動的に非表示になり、各モデルの容量・ページ数制限に従います。

### 改善

- バックグラウンドコマンドの操作を再設計しました。ステータスバーの項目はコマンドが実際に完了するまで表示され、同時実行コマンドは展開可能な概要に折りたたまれます。
- 高度な機能の認可と Python、Pylance など主要な拡張機能との互換性を拡張し、リモート開発の互換性も改善しました。
- 国内ネットワークでのインストールと更新の信頼性を改善しました。
- 利用可能なコンテキストに応じて動的に実行することで、自動コンテキスト圧縮をよりスマートにし、不要な圧縮を減らしました。
- 組み込みスキルはオンデマンドで有効になり、デフォルトでは軽量モードを使用します。
- Agent が途中で確認のために停止せず、複数段階のプランを完了するようになりました。結果に集中した、より控えめな応答を返します。
- リクエストパイプラインを大幅に最適化し、長い会話のコストを削減しました。
- より控えめなバナー、詳細ドロワー、明瞭な中国語と英語の混在表示を備えたエラープロンプトに再設計しました。
- タイトルバーのレイアウト切り替えを復元し、空のチャットページのクイックアクセスを再編成し、プロバイダーアイコンがシステムアラートを発生させないようにしました。

### 修正

- 長い会話での遅延と異常なメモリ使用量を解消し、過去のセッションを開く速度を大幅に向上させ、長い応答をよりスムーズにしました。
- 無効またはオフラインの MCP サーバーがモデルにツールを公開しないようにし、誤った呼び出しを防止しました。MCP の切り替え後も接続が安定し、設定読み込みエラーで保存済み設定が消去されることもなくなりました。
- 設定ナビゲーションアイコンが誤って太字になる問題、特定の Linux 環境でのクラッシュ、その他のインターフェース問題を修正しました。
- 過去セッションの読み込み問題を修正し、インターフェースのクラッシュやストレージの無制限な増加を防ぎました。
- 「コンテキストが圧縮されました」と誤表示される状態を修正しました。実際の圧縮が明示され、長い会話での理解のずれとセッション間のメモリ干渉も解消されました。
- アクティブなモデルまたはチャネル設定を削除すると、空の選択ボックスを残さず利用可能な項目を自動的に選択するようになりました。
- Plan と Analysis のタブを切り替えても、内容を再読み込みせず状態を保持するようになりました。
- 描画パネルの断続的な白画面、バックグラウンドコマンド終了後の古い項目、設定ページのスクロールバー問題など、その他の細部を修正しました。
- 命令編集、ストリーミング中断検出、思考予算の制限、ドキュメントの整列など、モデル間のパラメーター互換性を改善しました。
