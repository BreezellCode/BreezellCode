# モードの選択

Breezell には、自律性、深さ、ワークフロー制御のレベルに応じた複数の作業モードがあります。Agent はデフォルトモードであり、ほとんどのタスクに推奨される自動ワークフローです。

すばやい会話、読み取り専用の分析、編集前の計画、より深い因果推論、並列 AI チームメイトなど、より具体的な対話スタイルが必要な場合は別のモードを使用します。

## Chat

Chat は、すばやい質問と回答のためのモードです。

コードについて質問したり、アイデアを説明したり、選択肢を比較したり、Breezell にファイル編集やツールの自律実行を依頼せずに素早い回答を得たりするときに Chat を使用します。

Chat モードでは、モデルはファイルを編集できません。

## Agent

Agent では、Breezell がプロジェクトを調査し、ファイルを編集し、ツールを使用し、コマンドを実行して、コーディングタスクを完了できます。

ほとんどの開発作業には Agent を使用します。合理的なワークフローを自動的に選択し、必要なコンテキストを集め、変更を加え、提供前に結果を検証できるため、デフォルトモードになっています。

## Analyze

Analyze は読み取り専用の調査用です。

ファイルを変更せずに Breezell にコードの調査、問題の診断、アーキテクチャのレビュー、動作の監査をさせたい場合に Analyze を使用します。変更内容を決める前に技術的な見解が必要なときに便利です。

## Plan

Plan は編集前に構造化された実装手順を作成します。

複雑な機能、大規模なリファクタリング、不明確な要件、コード変更を始める前に設計上の判断が必要な作業には Plan を使用します。

ヒント：Agent モードでは、タスクに構造化された実装手順が必要な場合、Breezell が Plan への切り替えを提案することがあります。切り替えを許可または拒否できます。完全自動モードが有効な場合、適切なタイミングで Breezell が切り替えを自動的に確認できます。

## Entanglement

Entanglement は、因果推論とコンテキスト認識を使って、より深いプロダクトやコードの判断を行います。

Entanglement は Breezell が独自に研究・公開しているモードです。Breezell 専用のモードであり、ウェブ上でも独自のものです。

因果状態の追跡と検証ループの技術概要については、[Entanglement モードの概要](/ja/entanglement-mode-overview)を参照してください。

意図、トレードオフ、隠れた原因、感情的なニュアンス、直接的な回答以上の多段階推論に依存するリクエストでは Entanglement を使用します。

ヒント：このモードはモデルの能力を大きく高められますが、標準ワークフローより多くのリソースを消費します。副作用は不明です。

ヒント：Entanglement のコンテキストはすでに注入されているため、同じ会話内で Entanglement から Agent に切り替えても Entanglement の動作を完全には無効化できません。会話には Entanglement の機能とリソース消費が残ります。通常の Agent ワークフローに戻したい場合は、新しい会話を開始してください。

## Teams

Teams は複数の AI チームメイトを調整し、大規模な機能や並列ワークフローに対応します。

複数の領域の調査、実装の比較、大規模プロジェクトの複数部分の同時推進など、タスクを独立した作業ストリームに分割できる場合は Teams を使用します。

ヒント：このモードはモデルの能力を大きく高められますが、標準ワークフローより多くのリソースを消費します。

制限：並列チームメイト間の読み取り・書き込み競合によって Teams が制約される場合があります。Breezell は競合の削減に努めていますが、大規模な並列タスクは調整が難しくなることがあり、複数のチームメイトが重複する領域を変更すると混乱が生じる可能性があります。

## モードの選択

ほとんどのタスクではデフォルトの Agent モードを維持してください。タスクに明らかに別のワークフローが必要な場合のみモードを切り替えます。

| モード | 適した用途 |
| --- | --- |
| Chat | すばやい会話と簡単な説明 |
| Agent | デフォルトのコーディングワークフロー、ファイル編集、ツール、検証 |
| Analyze | 読み取り専用の診断、レビュー、アーキテクチャ調査 |
| Plan | 変更前の構造化された実装計画 |
| Entanglement | 深い因果推論とコンテキストを踏まえた判断 |
| Teams | 大規模または独立した作業ストリーム向けの並列 AI チームメイト |
