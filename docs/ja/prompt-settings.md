# プロンプト設定

## プロンプト設定を開く

画像の矢印は、ダイアログボックス右上のツールバーにあるプロンプト設定ボタンを指しています。これは **New Chat**（`+`）ボタンのすぐ右側にあります。

![ダイアログボックスで強調表示されたプロンプト設定ボタン](/custom-api/prompt-settings.png)

このボタンをクリックすると、プロンプト設定が開きます。ここで、会話中に Breezell に従わせる指示を設定できます。

## 明確な指示を書く

Breezell に求める役割、目的、出力形式、制約を説明してください。具体的で焦点を絞った指示にすると、会話の方向性が明確になります。
