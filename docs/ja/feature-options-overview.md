# 機能オプションの概要

このページでは、Breezell の設定で利用できる主な機能オプションをまとめています。これらのオプションは、自動補完、通知、ツール権限、エディターの動作、インテリジェント機能、システムアクセスを制御します。

## ヘルプ

### 自動補完と通知

| 機能 | 説明 |
| --- | --- |
| 自動補完 | BreezellTab は AI によるコード補完を提供します。`Tab` を押して候補を受け入れます。 |
| システム通知 | システム通知の動作を設定します。エディターが最小化されたりフォーカスを失ったりすると、Breezell はシステム通知を表示できます。 |

## 実行

### ツール権限

これらのオプションは、特定のツール操作を手動確認なしで自動実行できるかどうかを制御します。

| 機能 | 説明 |
| --- | --- |
| 編集を自動承認 | 編集操作を確認なしで自動実行できるようにします。 |
| ターミナルを自動承認 | ターミナル操作を確認なしで自動実行できるようにします。 |
| データベース操作を自動承認 | データベース操作を確認なしで自動実行できるようにします。 |
| メディア生成を自動承認 | メディア生成操作を確認なしで自動実行できるようにします。 |
| MCP ツールを自動承認 | MCP ツール操作を確認なしで自動実行できるようにします。 |
| Teams を自動承認 | 手動確認なしでチーム作成を自動承認します。 |

## エディター

### コードの動作

| 機能 | 説明 |
| --- | --- |
| Lint エラーを自動修正 | 対応している場合に Lint エラーを自動修正します。 |
| コード変更を自動承認 | 生成または変更されたコードを自動的に受け入れます。 |
| 編集中にファイルを自動で開く | 編集中にファイルを自動で開きます。 |
| 選択時にインライン候補を表示 | テキストまたはコードを選択するとインライン候補を表示します。 |

### Git コミットメッセージ

このオプションを使用すると、Breezell は現在のコード変更から Git コミットメッセージを生成できます。手動で書かずに明確なコミット概要を作成したい場合に便利です。

![チャットモデルでコミットメッセージを生成](/feature-options/git-commit-message.png)

| 機能 | 説明 |
| --- | --- |
| チャットモデルでコミットメッセージを生成 | 現在のコード変更に基づいて Git コミットメッセージを自動生成します。 |

このオプションを有効にすると、Breezell は現在の変更セットを確認し、選択したチャットモデルでコミットメッセージを作成できます。プロジェクトで特定のコミット形式が必要な場合は、コミット前に生成されたメッセージを確認してください。

## インテリジェンス

### コンテキスト管理

| 機能 | 説明 |
| --- | --- |
| プランカードを自動実行 | 有効にすると、新しいプランカードが手動クリックなしで自動実行されます。 |

### Superpowers Skills

| 機能 | 説明 |
| --- | --- |
| Superpowers Skills を有効化 | AI がブレインストーミング、計画、TDD、コードレビューなどの構造化された開発ワークフローを使用できるようにします。完全な内容はオンデマンドで読み込まれます。 |

### ~~Agent の高度な探索~~

> **バージョン 1.2.5 以降は非推奨です。** このオプションは削除されました。リクエストに複数ソースによる詳細な調査が必要な場合、Breezell は関連する機能を自動的に呼び出し、結果を引用付きの調査レポートにまとめます。

| 機能 | 説明 |
| --- | --- |
| ~~高度な探索を有効化~~ | バージョン 1.2.5 以降は非推奨です。必要に応じて関連する調査機能が自動的に呼び出されます。 |

### Entanglement モードパネル

| 機能 | 説明 |
| --- | --- |
| Entanglement モードでパネルを表示 | Entanglement モード用のリアルタイム構造化パネルを表示します。現在の段階、確信度の履歴、有効・解決済みの仮説、評価済み証拠ログ、因果グラフを含みます。 |

## システム

### ネットワーク設定

| 機能 | 説明 |
| --- | --- |
| システムプロキシを使用 | API リクエストの送信にシステムプロキシを使用します。プロキシが不要または不安定な場合は、応答速度を高めるためこのオプションを無効にすることをおすすめします。 |

### 外部ファイルへのアクセス

| 機能 | 説明 |
| --- | --- |
| 外部ファイルへの読み取り専用アクセスを許可 | ツールがワークスペース外のファイルを読み取れるようにします。 |
| 外部ファイルへの書き込みアクセスを許可 | ツールがワークスペース外のファイルを変更できるようにします。2つの外部ファイルアクセスオプションはデフォルトで有効です。 |

## 注意

自動承認と外部アクセスのオプションはワークフローを高速化できますが、手動レビューも減少します。ワークスペースのポリシーと信頼レベルに合う場合にのみ有効にしてください。
