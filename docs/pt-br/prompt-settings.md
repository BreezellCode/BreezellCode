# Configurações de prompt

## Abrir as configurações de prompt

A seta na imagem aponta para o botão de configurações de prompt na barra de ferramentas do canto superior direito da caixa de diálogo. Ele fica imediatamente à direita do botão **New Chat** (`+`).

![Botão de configurações de prompt destacado na caixa de diálogo](/custom-api/prompt-settings.png)

Clique neste botão para abrir as configurações de prompt e definir as instruções que você deseja que o Breezell siga durante a conversa.

## Escreva instruções claras

Descreva a função, o objetivo, o formato de saída e as restrições que você deseja que o Breezell siga. Mantenha as instruções específicas e objetivas para que a conversa tenha uma direção clara.
