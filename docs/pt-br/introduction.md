# Introdução

O Breezell é um editor de código com IA baseado no VS Code (Code – OSS). Ele combina agentes de IA, suporte a vários modelos e compreensão profunda da base de código para acelerar o desenvolvimento sem perder qualidade.

## Recursos principais

- **Vários modelos de IA** — Alterne livremente entre Claude, GPT, Gemini, Grok, DeepSeek e outros.
- **Vários modos de trabalho** — Chat, Agent, Analyze, Plan, Entanglement e Teams.
- **Compreensão profunda da base de código** — Indexação inteligente, salto para definição e análise de dependências com detecção de ciclos e rastreamento de impacto.
- **Regras, memórias e habilidades** — Personalize o comportamento da IA com regras persistentes, memórias do projeto e uma biblioteca reutilizável de habilidades.
- **Operações de banco de dados integradas** — Conecte e administre SQLite, MongoDB, Oracle, Redis, MariaDB e mais dentro do editor.
- **Navegador integrado** — Automação de capturas, cliques, navegação, instantâneos do DOM e simulação de dispositivos.
- **Suporte a MCP** — Conecte ferramentas e serviços externos pelo Model Context Protocol.
- **Espaço de trabalho completo** — Prévia de temas, biblioteca de ícones e desenvolvimento remoto por SSH.

## Destaques

As versões recentes do Breezell se concentram em agentes mais inteligentes, compreensão mais profunda de código e um espaço de trabalho tudo em um mais poderoso.

- **Code Review Panel** — Visualização de revisão com diferenças numeradas, Myers diff para arquivos grandes, reversão com um clique e envio ao chat.
- **Modo Entanglement** — Raciocínio causal com consciência emocional para respostas orientadas pela intenção.
- **Companheiros de IA em paralelo** — Execute vários companheiros de IA para tarefas complexas.
- **Super Memory** — Memória de longo prazo com reconhecimento temporal que preserva o contexto entre sessões.
- **Renderização avançada** — LaTeX, Mermaid, cartões de ferramentas expansíveis e pesquisa web no chat.

## Primeiros passos

1. Baixe e instale o Breezell para sua plataforma.
2. Escolha um plano: sua própria chave de API, teste ou assinatura.
3. Abra um projeto e escolha um modelo de IA.
4. Selecione um modo, como Chat, Agent ou Plan, e comece a programar.
