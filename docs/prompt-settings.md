# Prompt Settings

## Open prompt settings

The arrow in the image points to the prompt settings button in the upper-right toolbar of the dialog box. It is immediately to the right of the **New Chat** (`+`) button.

![Prompt settings button highlighted in the dialog box](/custom-api/prompt-settings.png)

Click this button to open prompt settings and set the instructions you want Breezell to follow during the conversation.

## Write clear instructions

Describe the role, goal, output format, and constraints you want Breezell to follow. Keep the instructions specific and focused so the conversation has a clear direction.
