# Entanglement Mode

> A mode for working through complex and uncertain problems with structured investigation support.

## What Entanglement Helps With

Entanglement is designed for tasks where the cause is not obvious and several checks may be needed. It helps Breezell keep a clear investigation thread while it works.

- Explore unknown bugs and regressions.
- Connect clues from multiple files or modules.
- Keep hypotheses, useful evidence, next steps, and conclusions organized.
- Support tool-assisted checks and follow-up validation.
- Show investigation progress in a structured panel.
- Preserve useful conclusions so similar problems are easier to revisit.

## What You Can See

When Entanglement is selected from the mode selector, Breezell can show:

- The current investigation stage.
- Working hypotheses and supporting evidence.
- Planned checks and validation results.
- Current confidence and identified conclusions.
- Corrections when an earlier direction needs review.

## When to Use It

Use Entanglement when:

- The root cause is unknown.
- A problem crosses several files, modules, or systems.
- You need to compare possible explanations before changing code.
- The result should be checked through follow-up tests or observations.

For clear, limited edits or routine coding tasks, the default Agent mode is usually a better fit.

## How to Start

1. Select Entanglement from the mode selector.
2. Describe the symptoms, goal, and relevant constraints.
3. Let Breezell inspect the context needed for the investigation.
4. Review the hypotheses, checks, and conclusions shown in the panel.
5. Continue the conversation when more evidence or validation is needed.

## Entanglement and Agent

Agent is the default mode for general development work. Entanglement is an investigation-focused option for problems that need more deliberate reasoning and follow-up checks.

Choose the mode that matches the task. You can use Agent for direct implementation and Entanglement for uncertain or multi-step investigations.

## Important Note

The Entanglement panel is a decision-support aid. Review its conclusions and validation results before applying important changes.
