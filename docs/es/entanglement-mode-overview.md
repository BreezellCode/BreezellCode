# Modo Entanglement

> Un modo para trabajar con problemas complejos e inciertos mediante apoyo estructurado a la investigación.

## Para qué sirve Entanglement

Entanglement está pensado para tareas cuya causa no es evidente y que pueden requerir varias comprobaciones. Ayuda a Breezell a mantener un hilo claro de investigación mientras trabaja.

- Explorar errores desconocidos y regresiones.
- Relacionar indicios de varios archivos o módulos.
- Mantener organizadas las hipótesis, las evidencias útiles, los siguientes pasos y las conclusiones.
- Facilitar comprobaciones con herramientas y validaciones posteriores.
- Mostrar el progreso de la investigación en un panel estructurado.
- Conservar conclusiones útiles para revisar problemas similares más adelante.

## Qué puedes ver

Cuando seleccionas Entanglement en el selector de modos, Breezell puede mostrar:

- La etapa actual de la investigación.
- Las hipótesis de trabajo y las evidencias que las apoyan.
- Las comprobaciones previstas y sus resultados de validación.
- La confianza actual y las conclusiones identificadas.
- Correcciones cuando sea necesario revisar una dirección anterior.

## Cuándo usarlo

Usa Entanglement cuando:

- Se desconoce la causa raíz.
- El problema afecta a varios archivos, módulos o sistemas.
- Necesitas comparar posibles explicaciones antes de cambiar el código.
- El resultado debe comprobarse mediante pruebas u observaciones posteriores.

Para cambios claros y limitados o tareas de programación rutinarias, el modo Agent predeterminado suele ser más adecuado.

## Cómo empezar

1. Selecciona Entanglement en el selector de modos.
2. Describe los síntomas, el objetivo y las restricciones relevantes.
3. Permite que Breezell inspeccione el contexto necesario para la investigación.
4. Revisa las hipótesis, comprobaciones y conclusiones mostradas en el panel.
5. Continúa la conversación cuando se necesiten más evidencias o validaciones.

## Entanglement y Agent

Agent es el modo predeterminado para el trabajo general de desarrollo. Entanglement es una opción centrada en la investigación para problemas que necesitan un razonamiento más deliberado y comprobaciones posteriores.

Elige el modo que corresponda a la tarea. Puedes usar Agent para la implementación directa y Entanglement para investigaciones inciertas o de varios pasos.

## Nota importante

El panel de Entanglement es una ayuda para tomar decisiones. Revisa sus conclusiones y resultados de validación antes de aplicar cambios importantes.
