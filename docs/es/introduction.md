# Introducción

Breezell es un editor de código con IA basado en VS Code (Code – OSS). Combina agentes de IA, compatibilidad con varios modelos y comprensión profunda del código para acelerar el desarrollo sin sacrificar calidad.

## Funciones principales

- **Varios modelos de IA** — Alterna libremente entre Claude, GPT, Gemini, Grok, DeepSeek y otros.
- **Varios modos de trabajo** — Chat, Agent, Analyze, Plan, Entanglement y Teams.
- **Comprensión profunda del código** — Indexación inteligente, salto a definición y análisis de dependencias con detección de ciclos y seguimiento de impacto.
- **Reglas, memorias y habilidades** — Personaliza el comportamiento de la IA con reglas persistentes, memorias del proyecto y una biblioteca de habilidades reutilizable.
- **Operaciones de base de datos integradas** — Conecta y administra SQLite, MongoDB, Oracle, Redis, MariaDB y más desde el editor.
- **Navegador integrado** — Automatización de capturas, clics, navegación, instantáneas DOM y simulación de dispositivos.
- **Compatibilidad con MCP** — Conecta herramientas y servicios externos mediante Model Context Protocol.
- **Espacio de trabajo completo** — Vista previa de temas, biblioteca de iconos y desarrollo remoto SSH.

## Aspectos destacados

Las versiones recientes de Breezell se centran en agentes más inteligentes, comprensión de código más profunda y un espacio de trabajo integral más potente.

- **Code Review Panel** — Vista de revisión independiente con diferencias numeradas, Myers diff para archivos grandes, reversión con un clic y envío al chat.
- **Modo Entanglement** — Razonamiento causal con conciencia emocional para respuestas que entienden la intención.
- **Compañeros de IA en paralelo** — Ejecuta varios compañeros de IA para tareas complejas.
- **Super Memory** — Memoria a largo plazo con reconocimiento temporal que conserva el contexto entre sesiones.
- **Representación enriquecida** — LaTeX, Mermaid, tarjetas de herramientas expandibles y búsqueda web integrada en el chat.

## Primeros pasos

1. Descarga e instala Breezell para tu plataforma.
2. Elige un plan: tu propia clave de API, una prueba o una suscripción.
3. Abre un proyecto y selecciona un modelo de IA.
4. Elige un modo, como Chat, Agent o Plan, y empieza a programar.
