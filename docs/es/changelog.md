# Registro de cambios

## 1.2.7 · 2026-07-29

### Nuevas funciones

- Se mejoró la comprensión y la navegación en bases de código grandes.
- Se añadieron indicadores opcionales de calidad de respuesta para evaluar la calidad, la comprensión de requisitos y la confianza de verificación.
- Los detalles de estadísticas de caché ahora admiten paginación, filtros vinculados y varios idiomas.

### Correcciones y mejoras

- Se corrigió el campo de mensaje de confirmación que quedaba vacío o no era válido tras actualizar el control de código fuente.
- Se corrigieron bloqueos de razonamiento del Agent, detección incorrecta del estado de terminal, pérdida de códigos de salida y finalización prematura de tareas.
- Se corrigió el truncamiento prematuro de conversaciones al editar y reenviar mensajes.
- Se mejoraron las rutas, el inicio de host, los reintentos de contraseña y la caché de servidor en WSL y Remote SSH.
- Se corrigieron problemas de KaTeX, temas de bloques de código, fuentes chinas y alineación de iconos.
- Se optimizaron la búsqueda, las llamadas de herramientas, la ejecución y la finalización de tareas del Agent.
- Se mejoraron el estado de finalización del chat, la barra inferior, el desplazamiento y la carga de conversaciones largas.
- Se rediseñaron las tarjetas de cuentas de modelos e inicio de sesión OAuth, y se mejoraron los indicadores de uso de Codex y metadatos de modelos.
