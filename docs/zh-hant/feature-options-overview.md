# 功能選項總覽

本頁面概述 Breezell 設定中提供的主要功能選項。這些選項控制自動補全、通知、工具權限、編輯器行為、智慧功能和系統存取權限。

## 說明

### 自動補全與通知

| 功能 | 說明 |
| --- | --- |
| 自動補全 | BreezellTab 提供 AI 程式碼補全。按下 `Tab` 接受建議。 |
| 系統通知 | 設定系統通知行為。當編輯器最小化或失去焦點時，Breezell 可以顯示系統通知。 |

## 執行

### 工具權限

這些選項控制特定工具操作是否可以在沒有手動確認的情況下自動執行。

| 功能 | 說明 |
| --- | --- |
| 自動核准編輯 | 允許編輯操作在無需確認的情況下自動執行。 |
| 自動核准終端機 | 允許終端機操作在無需確認的情況下自動執行。 |
| 自動核准資料庫操作 | 允許資料庫操作在無需確認的情況下自動執行。 |
| 自動核准媒體產生 | 允許媒體產生操作在無需確認的情況下自動執行。 |
| 自動核准 MCP 工具 | 允許 MCP 工具操作在無需確認的情況下自動執行。 |
| 自動核准 Teams | 自動核准建立團隊，無需手動確認。 |

## 編輯器

### 程式碼行為

| 功能 | 說明 |
| --- | --- |
| 自動修正 Lint 錯誤 | 在支援的情況下自動修正 Lint 錯誤。 |
| 自動接受程式碼變更 | 自動接受產生或修改的程式碼變更。 |
| 編輯時自動開啟檔案 | 編輯期間自動開啟檔案。 |
| 選取內容時顯示行內建議 | 選取文字或程式碼時顯示行內建議。 |

### Git 提交訊息

使用此選項可以讓 Breezell 根據目前的程式碼變更產生 Git 提交訊息。當你想要清晰的提交摘要而不想手動撰寫時，此選項非常有用。

![使用聊天模型產生提交訊息](/feature-options/git-commit-message.png)

| 功能 | 說明 |
| --- | --- |
| 使用聊天模型產生提交訊息 | 根據目前的程式碼變更自動產生 Git 提交訊息。 |

啟用此選項後，Breezell 可以審查目前的變更集，並使用所選聊天模型建立提交訊息。如果專案要求特定的提交格式，請在提交前檢查產生的訊息。

## 智慧功能

### 內容管理

| 功能 | 說明 |
| --- | --- |
| 自動執行計畫卡片 | 啟用後，新的計畫卡片會自動執行，無需手動點選。 |

### Superpowers 技能

| 功能 | 說明 |
| --- | --- |
| 啟用 Superpowers 技能 | 允許 AI 使用腦力激盪、規劃、TDD 和程式碼審查等結構化開發工作流程。完整內容會按需載入。 |

### ~~Agent 進階探索~~

> **1.2.5 版本後已棄用。** 此選項已移除。當請求需要深入的多來源研究時，Breezell 會自動呼叫相關功能，並將結果彙整為附有引用的研究報告。

| 功能 | 說明 |
| --- | --- |
| ~~啟用進階探索~~ | 1.2.5 版本後已棄用；需要時會自動呼叫相關研究功能。 |

### Entanglement 模式面板

| 功能 | 說明 |
| --- | --- |
| 在 Entanglement 模式中顯示面板 | 為 Entanglement 模式顯示即時結構化面板，包括目前階段、信心度歷史、作用中和已解決的假設、分級證據記錄以及因果圖。 |

## 系統

### 網路設定

| 功能 | 說明 |
| --- | --- |
| 使用系統 Proxy | 使用系統 Proxy 傳送 API 請求。如果不需要 Proxy 或 Proxy 不穩定，建議停用此選項以提高回應速度。 |

### 外部檔案存取

| 功能 | 說明 |
| --- | --- |
| 允許唯讀存取外部檔案 | 允許工具讀取工作區之外的檔案。 |
| 允許寫入外部檔案 | 允許工具修改工作區之外的檔案。兩個外部檔案存取選項預設為啟用。 |

## 注意事項

自動核准和外部存取選項可以提高工作流程速度，但也會減少人工審查。只有在符合工作區政策和信任等級時才啟用它們。
