# 聯絡我們

本頁面提供 Breezell 支援、產品問題和文件回饋的官方聯絡方式。

## 電子郵件

如有問題、支援請求或文件回饋，請透過電子郵件聯絡 Breezell：

[email@breezell.com](mailto:email@breezell.com)

傳送訊息時，請清楚描述你的請求，提供相關設定詳細資料以及已經嘗試過的步驟。這有助於團隊更有效率地處理你的問題。

::: tip
我們會在 16–24 小時內回覆你的電子郵件。
:::
