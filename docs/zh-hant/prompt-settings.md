# 提示詞設定

## 開啟提示詞設定

圖片中的箭頭指向對話方塊右上角工具列中的提示詞設定按鈕。它緊鄰在 **New Chat**（`+`）按鈕的右側。

![對話方塊中醒目顯示的提示詞設定按鈕](/custom-api/prompt-settings.png)

點擊此按鈕即可開啟提示詞設定，並設定希望 Breezell 在對話中遵循的指令。

## 撰寫清楚的指令

請描述希望 Breezell 遵循的角色、目標、輸出格式與限制條件。保持指令具體且聚焦，能讓對話擁有清楚的方向。
