# 介紹

Breezell 是基於 VS Code（Code – OSS）建構的 AI 程式碼編輯器。它將 AI 代理、多模型支援和深度程式碼庫理解整合到一個工具中，在不犧牲品質的前提下加快開發速度。

## 核心功能

- **多種 AI 模型** — 可在 Claude、GPT、Gemini、Grok、DeepSeek 等模型間自由切換。
- **多種工作模式** — 提供 Chat、Agent、Analyze、Plan、Entanglement 和 Teams。
- **深度程式碼庫理解** — 提供智慧程式碼索引、跳至定義，以及包含循環偵測和影響追蹤的相依性分析。
- **規則、記憶與技能** — 使用持久規則、專案記憶和可重複使用的技能庫自訂 AI 行為。
- **內建資料庫操作** — 可直接在編輯器中連接和管理 SQLite、MongoDB、Oracle、Redis、MariaDB 等。
- **內建瀏覽器** — 提供螢幕截圖、點擊、導覽、DOM 快照自動化和裝置視窗模擬。
- **MCP 支援** — 可透過 Model Context Protocol 連接外部工具和服務。
- **豐富的工作空間** — 提供即時主題預覽、內建圖示庫和完整的 SSH 遠端開發支援。

## 重點

最新 Breezell 版本著重於更智慧的代理、更深的程式碼理解和更強大的一體化工作空間。

- **Code Review Panel** — 提供獨立審查檢視、行號差異、大型檔案 Myers diff、一鍵回復和傳送至聊天進行 AI 輔助審查。
- **Entanglement 模式** — 透過具情緒感知的因果推理提供更能理解意圖的回應。
- **平行 AI 隊友** — 可平行執行多位 AI 隊友來處理複雜任務。
- **Super Memory** — 具時間感知能力的長期記憶，可跨工作階段保留上下文。
- **豐富轉譯** — 在聊天中提供 LaTeX、Mermaid、可展開工具卡片和內建網頁搜尋。

## 快速開始

1. 下載並安裝適用於你平台的 Breezell。
2. 選擇方案：使用自己的 API 金鑰、試用或訂閱。
3. 開啟專案並選擇 AI 模型。
4. 選擇 Chat、Agent 或 Plan 等模式，然後開始更聰明地程式設計。
