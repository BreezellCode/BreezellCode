# 更新日誌

## 1.2.7 · 2026-07-29

### 新功能

- 提升大型程式碼庫的理解與導覽效率。
- 新增可選的回答品質洞察，可呈現回答品質、需求理解與驗證信心的評估結果。
- 快取統計詳細資料現已支援分頁、連動篩選與多語言顯示。

### 修正與最佳化

- 修正重新整理原始碼管理、切換檢視或重建元件後，提交訊息輸入欄遺失或失效的問題。
- 修正 Agent 推理停滯、終端機狀態誤判、背景命令結束代碼遺失和工作過早結束的問題。
- 修正編輯並重新傳送訊息時，對話會過早截斷的問題。
- 改善 WSL 與 Remote SSH 環境中的路徑、主機啟動、密碼重試與伺服器快取。
- 修正 KaTeX、程式碼區塊主題、中文字型與檔案圖示對齊問題。
- 最佳化 Agent 搜尋、工具呼叫、工作執行和終止邏輯。
- 最佳化聊天完成狀態、底部工具列、捲動定位與長對話載入體驗。
- 重構模型帳戶與 OAuth 登入卡片，並改善 Codex 用量及模型中繼資料顯示。
