# 更新日誌

## 1.2.7 · 2026-07-29

### 新功能

- 提升大型程式碼庫的理解與導覽效率。
- 新增可選的回答品質洞察，可呈現本輪回答品質、需求理解與驗證信心的評估結果。
- 快取統計詳細資料現已支援分頁、連動篩選與多語言顯示。

### 修正

#### 原始碼管理與 Agent 執行階段

- 修正重新整理原始碼管理儲存庫、切換檢視或重建元件後，提交訊息輸入欄變空或失效的問題。
- 修正 Agent 推理停滯、終端機狀態誤判、背景命令結束代碼遺失和工作過早結束的問題。
- 修正佇列訊息編輯、工具呼叫回饋、工作清單還原和連續回合狀態相關的問題。

#### 聊天與遠端環境

- 修正編輯並重新傳送訊息時，原始對話會過早截斷的問題。現在會在驗證完成後以原子方式替換訊息。
- 修正 WSL 與 Remote SSH 環境中的遠端路徑問題，並改善主機啟動、密碼重試與伺服器快取。

#### 渲染、模型與狀態

- 修正 KaTeX 區塊公式解析、程式碼區塊主題、中文字型渲染與檔案圖示對齊問題。
- 修正部分模型錯誤顯示空白回應、暴露錯誤堆疊或發出異常提供者網路請求的問題。
- 修正 Super Memory 中已刪除內容重新出現，以及瀏覽器面板狀態意外回復的問題。

### 改善

#### Agent 搜尋與執行

- 最佳化 Agent 搜尋、工具呼叫、工作執行和終止邏輯，減少重複結論、不必要的等待與異常中斷。
- 最佳化大型程式碼搜尋的結果數量限制、執行逾時與串流狀態，降低過大結果集造成的資源消耗。

#### 聊天體驗

- 改善聊天完成狀態、底部工具列、捲動定位與長對話載入體驗。

#### 設定與用量

- 重構模型帳戶與 OAuth 登入卡片，統一設定頁各處的視覺層級與互動模式。
- 改善 Codex 用量、模型中繼資料及相關狀態指示器。

## 1.2.6 · 2026-07-27

### 新增

#### 工作階段層級的 Chat Git

- 現在可以將同一工作階段產生的 AI 程式碼變更一起提交。
- 新增同時偵測和處理多個 Git 儲存庫的支援。
- Chat 工作與程式碼審查狀態現在會在提交後自動同步。

#### 提供者、模型與功能

- 新增 **Poolside Platform** 提供者，可透過 OpenAI 相容設定使用 **Poolside Laguna**。
- 新增 **Qwen3.8**、**Opus 5** 和 **Pangu** 的模型設定。
- 為 **LongCat** 增強推理重播功能，在工具呼叫後保留推理內容。

#### 遠端工作區安全性

- 在遠端環境存取 Linux 根目錄 `/` 時新增安全性警告。
- 現在會自動排除 `/proc`、`/sys` 和 `/dev` 等 Linux 虛擬檔案系統路徑。

### 改善

#### 程式碼審查

- 重新設計單一程式碼區塊的 **接受/拒絕** 操作列。
- 更新 **全部保留**，使其遵循目前主題的強調色。
- 降低行內操作列的高度，讓程式碼區域更加緊湊。
- 成功執行 Git 提交後，審查操作列現在會自動摺疊並重設。

#### 模型選取器

- 首次輸入金鑰後，預設只啟用五個推薦模型，以減少清單冗餘。
- OpenAI 相容提供者的功能現在會依據所選 API 格式自動調整。

#### 程式碼提交與 SCM 重新整理

- 儲存檔案後，活動列中的 Git 狀態現在會自動重新整理。
- Chat Git 提交現在統一按 **保留所有變更** 處理，並自動完成相應的程式碼審查步驟。

#### 介面

- 移除通知標題中的未讀指示器。
- 改善 OpenAI 相容模型群組的懸停選單切換體驗。
- 修正工具數量文字的垂直對齊問題。
- 在淺色主題中啟用 Kimi Mono 圖示樣式。

### 修正

#### WSL 與遠端 Git

- 修正 WSL 擴充功能主機啟動當機問題。
- 修正 WSL 伺服器 Proxy 設定不一致的問題。
- WSL 和 SSH 環境中的 Git 狀態檢查及 AI 產生的提交訊息現在會透過支援遠端環境的執行通道執行。
- 阻止遠端工作區的 Git 命令針對本機路徑執行。
- 修正 Agent 修改檔案後自動關閉 Git 儲存庫的問題。
- 修正遠端 URI 中相對路徑顯示錯誤的問題。

#### 遠端 SSH

- 修正遠端 SSH 密碼過期處理問題。伺服器拒絕已儲存的密碼後，現在會清除該密碼，並在同一次連線嘗試中提示使用者重新輸入。
- 阻止遠端 SSH 下載提交雜湊不相符的 REH 伺服器套件，避免版本不相符錯誤和遠端主機啟動失敗。

#### 聊天渲染

- 為 Mermaid 圖表新增 Trusted Types 支援。
- 改善 Mermaid 標籤清理，避免不安全或格式錯誤的標籤導致渲染失敗。

#### 規則與記憶

- 修正編輯器失去焦點後儲存空白內容的問題。
- 修正 `.breezell` 設定變更後資源管理器未及時重新整理的問題。

#### 遠端樹狀檢視

- SSH Hosts 設定缺失時，不再重複發出無意義的樹狀檢視錯誤。

## 1.2.4 · 2026-07-20

### 新功能

#### 模型與提供者

- 整合 **Grok 4.5**，支援可調整的推理強度和 Fast 通道；**Claude Sonnet 5** 提供 **200K** 和 **1M** 兩種內容長度選項。
- 透過 Moonshot API 和 Kimi Code 通道新增 **Kimi K3**，提供 **256K** 和 **1M** 內容長度選項，並完整支援 **Kimi K2.7 Code**。
- 新增 **StreamLake** 提供者，支援快手完整的 KAT-Coder 模型系列、內建 Coding Plan 預設值和按量付費端點預設值。
- 新增 Grok 帳戶 OAuth 登入。
- 將 Fast 通道從全域切換重構為獨立的 **提供者 + 模型** 設定，讓 Copilot、Codex、Claude 等提供者使用其官方通道語義。
- OpenAI 相容設定現在可以釘選，讓常用通道保持在清單頂端。
- 新增限時模型試用和折扣支援，並在模型選取器中顯示促銷徽章。
- 更新模型目錄，加入 Claude Fable 5、Claude Sonnet 5、Nemotron 3 Ultra、DeepSeek V4、GLM-5.2 和 MiniMax M3 等目前的旗艦模型，同時移除過時項目。

#### 用量、外觀與介面

- 升級用量中心，為 Codex、Kimi 和 Copilot 提供簡體中文、繁體中文、韓文和俄文的多語言用量與重設時間顯示。設定頁和聊天側欄資料現在會即時同步，Copilot 用量會分別顯示 Chat、Completions 和 Premium Requests。
- 歡迎頁標題現在可以全域或依模式自訂，包括字型大小和字重。新增 **Elegant** 快速存取樣式。
- 新增日文、西班牙文和巴西葡萄牙文介面語言。
- 重新設計通知中心，使其遵循產品語言；更新 Super Memory 卡片配置，並柔化聊天輸入框和訊息泡泡的視覺效果。

#### 瀏覽器、聊天與工作區

- 內建瀏覽器現在支援將所有分頁或個別分頁靜音，其面板分頁清單與瀏覽器之間會即時同步。
- 聊天訊息現在最多可包含 **10 張圖片**；圖片會自動調整大小並納入內容計算。新增回合持續時間顯示、訊息內一鍵回復，以及在外部或內建瀏覽器中開啟連結的選項。
- 聊天提交對話框現在支援多儲存庫工作區：按儲存庫產生提交資訊、獨立提交、直接從對話框初始化儲存庫，並在重新啟動後保留提交/推送進度。
- 資源管理器新增專案分組，並改善多視窗間協作狀態的即時更新。
- 新增持久化記憶，可將對話歷史自動提煉為可重複使用的經驗，並支援多語言去重。

#### 診斷與生產力

- 新增快取視覺化，提供每回合快取通知和工作區每日報告，可比較今天與昨天的資料，並支援工作階段/工作區篩選、預估節省量和快取未命中分析。
- 新增互動式設計卡片，可直接在聊天中產生 HTML 設計草稿，並在確認後套用。
- 提供者網路設定現在支援在直接連線、系統 Proxy、全域 Proxy 和自訂路由之間一鍵並行測速。系統會自動標示推薦路由，路由徽章會在設定頁即時更新。
- 升級 PDF 檢視器核心並新增工具列。附件按頁計量，在內容受限時自動隱藏，並受每個模型的數量和頁數限制約束。

### 改善

- 重新設計背景命令體驗：狀態列項目會一直顯示到命令真正完成，並將並行命令摺疊為可展開的摘要。
- 擴充進階功能授權及對 Python、Pylance 等主流擴充功能的相容性，並改善遠端開發相容性。
- 改善國內網路環境下的安裝和更新可靠性。
- 讓自動內容壓縮更智慧，依據可用內容動態觸發，減少不必要的壓縮。
- 內建技能現在會按需啟用，預設使用輕量模式。
- Agent 現在可以完成多階段計畫，不會在過程中暫停等待確認，並會以更克制的回覆聚焦結果。
- 深入最佳化請求流程，降低長對話成本。
- 重新設計錯誤提示，採用更低調的橫幅、詳細資料抽屜和更清晰的中英文混排。
- 還原標題列配置切換，重新組織空白聊天頁的快速存取，並避免提供者圖示觸發系統提醒。

### 修正

- 解決長對話中的延遲和異常記憶體用量問題，大幅加快歷史工作階段開啟速度並改善長回應流暢度。
- 已停用或離線的 MCP 伺服器不再向模型暴露工具，避免意外呼叫；切換 MCP 後連線也能保持穩定，設定讀取錯誤不再清除已儲存的設定。
- 修正設定導覽圖示被錯誤加粗、部分 Linux 環境當機等多個介面問題。
- 修正過去工作階段載入問題，避免介面當機或儲存無限制增長。
- 修正誤報「內容已壓縮」狀態：現在會明確顯示實際壓縮，並解決長對話理解偏移及跨工作階段記憶干擾問題。
- 刪除使用中的模型或通道設定後，現在會自動選取可用選項，不再留下空白選取框。
- 在 Plan 和 Analysis 分頁之間切換時，現在會保留狀態而不重新載入內容。
- 修正繪圖面板偶發白畫面、背景命令結束後的過期項目、設定頁捲軸等問題，並處理其他細節。
- 改善模型間參數相容性，包括指令編輯、串流中斷偵測、思考預算限制和文件對齊。
