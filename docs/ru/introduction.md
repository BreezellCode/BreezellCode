# Введение

Breezell — редактор кода с ИИ, созданный на основе VS Code (Code – OSS). Он объединяет ИИ-агентов, поддержку нескольких моделей и глубокое понимание кодовой базы, чтобы ускорять разработку без потери качества.

## Основные возможности

- **Несколько моделей ИИ** — свободно переключайтесь между Claude, GPT, Gemini, Grok, DeepSeek и другими.
- **Несколько режимов работы** — Chat, Agent, Analyze, Plan, Entanglement и Teams.
- **Глубокое понимание кода** — интеллектуальная индексация, переход к определению и анализ зависимостей с обнаружением циклов и отслеживанием влияния.
- **Правила, память и навыки** — настраивайте поведение ИИ с постоянными правилами, памятью проекта и библиотекой навыков.
- **Встроенные операции с базами данных** — подключайте и управляйте SQLite, MongoDB, Oracle, Redis, MariaDB и другими БД прямо в редакторе.
- **Встроенный браузер** — автоматизация снимков экрана, кликов, навигации, DOM-снимков и эмуляция устройств.
- **Поддержка MCP** — подключайте внешние инструменты и сервисы через Model Context Protocol.
- **Полноценное рабочее пространство** — предпросмотр тем, библиотека значков и удалённая разработка по SSH.

## Основные моменты

Последние версии Breezell сосредоточены на более умных агентах, глубоком понимании кода и мощном универсальном рабочем пространстве.

- **Code Review Panel** — отдельное представление ревью с нумерацией строк, Myers diff для больших файлов, откатом в один клик и отправкой в чат.
- **Режим Entanglement** — причинное мышление с эмоциональной осведомлённостью для ответов, учитывающих намерение.
- **Параллельные ИИ-напарники** — запускайте нескольких ИИ-напарников для сложных задач.
- **Super Memory** — долгосрочная память с учётом времени, сохраняющая контекст между сессиями.
- **Расширенный рендеринг** — LaTeX, Mermaid, разворачиваемые карточки инструментов и веб-поиск в чате.

## Начало работы

1. Скачайте и установите Breezell для вашей платформы.
2. Выберите план: собственный ключ API, пробный период или подписку.
3. Откройте проект и выберите модель ИИ.
4. Выберите режим, например Chat, Agent или Plan, и начните разработку.
