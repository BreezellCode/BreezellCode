# Обзор параметров функций

На этой странице приведены основные параметры функций, доступные в настройках Breezell. Эти параметры управляют автодополнением, уведомлениями, разрешениями инструментов, поведением редактора, интеллектуальными функциями и доступом к системе.

## Справка

### Автодополнение и уведомления

| Функция | Описание |
| --- | --- |
| Автодополнение | BreezellTab обеспечивает автодополнение кода с помощью ИИ. Нажмите `Tab`, чтобы принять предложение. |
| Системные уведомления | Настройте поведение системных уведомлений. Breezell может показывать системные уведомления, когда редактор свёрнут или теряет фокус. |

## Выполнение

### Разрешения инструментов

Эти параметры определяют, могут ли определённые операции инструментов выполняться автоматически без ручного подтверждения.

| Функция | Описание |
| --- | --- |
| Автоматически подтверждать изменения | Разрешает автоматически выполнять операции редактирования без подтверждения. |
| Автоматически подтверждать терминал | Разрешает автоматически выполнять операции терминала без подтверждения. |
| Автоматически подтверждать операции с базой данных | Разрешает автоматически выполнять операции с базой данных без подтверждения. |
| Автоматически подтверждать генерацию медиа | Разрешает автоматически выполнять операции генерации медиа без подтверждения. |
| Автоматически подтверждать инструменты MCP | Разрешает автоматически выполнять операции инструментов MCP без подтверждения. |
| Автоматически подтверждать Teams | Автоматически подтверждает создание команды без ручного подтверждения. |

## Редактор

### Поведение кода

| Функция | Описание |
| --- | --- |
| Автоматически исправлять ошибки Lint | Автоматически исправляет ошибки Lint, если это поддерживается. |
| Автоматически принимать изменения кода | Автоматически принимает созданные или изменённые фрагменты кода. |
| Автоматически открывать файлы при редактировании | Автоматически открывает файлы во время редактирования. |
| Показывать встроенные предложения при выборе | Показывает встроенные предложения, когда выбран текст или код. |

### Сообщение коммита Git

Используйте этот параметр, чтобы Breezell создавал сообщение коммита Git на основе текущих изменений кода. Это удобно, если вам нужна ясная сводка коммита без ручного написания.

![Создание сообщений коммита с помощью чат-модели](/feature-options/git-commit-message.png)

| Функция | Описание |
| --- | --- |
| Создавать сообщения коммита с помощью чат-модели | Автоматически создаёт сообщения коммита Git на основе текущих изменений кода. |

Если этот параметр включён, Breezell может проверить текущий набор изменений и создать сообщение коммита с выбранной чат-моделью. Если проект требует определённого формата коммитов, проверьте созданное сообщение перед коммитом.

## Интеллектуальные функции

### Управление контекстом

| Функция | Описание |
| --- | --- |
| Автоматически запускать карточки плана | После включения новые карточки плана запускаются автоматически без ручных нажатий. |

### Навыки Superpowers

| Функция | Описание |
| --- | --- |
| Включить навыки Superpowers | Разрешает ИИ использовать структурированные рабочие процессы разработки, такие как мозговой штурм, планирование, TDD и проверка кода. Полное содержимое загружается по требованию. |

### ~~Расширенное исследование Agent~~

> **Устарело после версии 1.2.5.** Этот параметр удалён. Когда запрос требует глубокого исследования по нескольким источникам, Breezell автоматически вызывает соответствующие возможности и обобщает результаты в исследовательском отчёте с цитатами.

| Функция | Описание |
| --- | --- |
| ~~Включить расширенное исследование~~ | Устарело после версии 1.2.5; соответствующие исследовательские возможности вызываются автоматически по мере необходимости. |

### Панель режима Entanglement

| Функция | Описание |
| --- | --- |
| Показывать панель в режиме Entanglement | Показывает структурированную панель режима Entanglement в реальном времени: текущий этап, историю уверенности, активные и разрешённые гипотезы, журналы оценённых доказательств и причинные графы. |

## Система

### Сетевые настройки

| Функция | Описание |
| --- | --- |
| Использовать системный прокси | Использует системный прокси для отправки запросов API. Если прокси не нужен или работает нестабильно, рекомендуется отключить этот параметр для повышения скорости ответа. |

### Доступ к внешним файлам

| Функция | Описание |
| --- | --- |
| Разрешить доступ к внешним файлам только для чтения | Разрешает инструментам читать файлы за пределами рабочего пространства. |
| Разрешить запись во внешние файлы | Разрешает инструментам изменять файлы за пределами рабочего пространства. Оба параметра доступа к внешним файлам включены по умолчанию. |

## Примечания

Параметры автоматического подтверждения и внешнего доступа могут ускорить рабочий процесс, но также сокращают ручную проверку. Включайте их только в том случае, если они соответствуют политике рабочего пространства и уровню доверия.
