# Настройки промпта

## Откройте настройки промпта

Стрелка на изображении указывает на кнопку настроек промпта на панели инструментов в правом верхнем углу диалогового окна. Она находится сразу справа от кнопки **New Chat** (`+`).

![Кнопка настроек промпта, выделенная в диалоговом окне](/custom-api/prompt-settings.png)

Нажмите эту кнопку, чтобы открыть настройки промпта и задать инструкции, которым Breezell должен следовать во время разговора.

## Пишите понятные инструкции

Опишите роль, цель, формат результата и ограничения, которым должен следовать Breezell. Формулируйте инструкции конкретно и по существу, чтобы задать разговору ясное направление.
