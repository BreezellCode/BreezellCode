# Настройки языка

Если английский не является вашим родным языком, установите соответствующее языковое расширение VS Code, а затем выберите наиболее подходящий язык на странице настроек Breezell.

Breezell сейчас поддерживает следующие языки интерфейса:

- English
- Korean
- Russian
- Simplified Chinese
- Traditional Chinese

## Откройте страницу настроек Breezell

Начните в главном окне редактора.

В правом верхнем углу редактора найдите **значок настроек**. Он выглядит как маленькая шестерёнка и расположен рядом с другими значками панели инструментов.

Нажмите значок настроек, чтобы открыть меню настроек.

В верхней части меню находится пункт **Breezell Settings**. Нажмите **Breezell Settings**.

![Меню настроек с выбранным Breezell Settings](/language-settings/settings-menu-current.png)

После этого откроется новая вкладка **Breezell Settings**.

![Страница Breezell Settings](/language-settings/breezell-settings-current.png)

## Найдите настройку языка

На странице **Breezell Settings** посмотрите на левую боковую панель.

Боковая панель содержит несколько разделов, например:

- Models
- Feature Options
- Appearance
- General
- Code Index
- MCP
- Privacy

Нажмите **General** в левой боковой панели.

После перехода на страницу **General** настройка языка будет находиться в верхней части страницы.

Параметр языка представлен раскрывающимся списком. По умолчанию в нём может быть указано **English**.

![Раскрывающийся список языка на странице General](/language-settings/language-dropdown-current.png)

Нажмите раскрывающийся список и выберите нужный язык.

## Примените нужный язык

После выбора предпочитаемого языка Breezell будет использовать его во всех частях интерфейса, где поддерживается локализация.

Если интерфейс не переключается на выбранный язык полностью, убедитесь, что соответствующее языковое расширение VS Code установлено и включено.

Например, чтобы использовать упрощённый китайский, сначала установите языковое расширение упрощённого китайского для VS Code. Затем вернитесь в настройки Breezell и выберите упрощённый китайский в раскрывающемся списке языков.

## Итог

Чтобы изменить язык Breezell:

1. Нажмите значок настроек в правом верхнем углу редактора.
2. Нажмите **Breezell Settings** в меню.
3. Откройте раздел **General** в левой боковой панели.
4. Найдите раскрывающийся список языков.
5. Выберите нужный язык.

Это позволяет пользователям, для которых английский не является родным, настроить Breezell на более подходящий язык интерфейса.
