# Журнал изменений

## 1.2.7 · 2026-07-29

### Новые возможности

- Улучшены понимание и навигация в крупных кодовых базах.
- Добавлены необязательные показатели качества ответа с оценкой качества текущего ответа, понимания требований и уверенности в проверке.
- Детальная статистика кэша теперь поддерживает пагинацию, связанные фильтры и несколько языков.

### Исправления

#### Управление исходным кодом и среда выполнения Agent

- Исправлено пустое или недействительное поле сообщения коммита после обновления репозитория системы управления исходным кодом, переключения представления или пересоздания компонентов.
- Исправлены остановки рассуждений Agent, неверное определение состояния терминала, потеря кодов завершения фоновых команд и преждевременное завершение задач.
- Исправлены проблемы редактирования сообщений в очереди, обратной связи вызовов инструментов, восстановления списка задач и состояния последовательных ходов.

#### Чат и удалённые среды

- Исправлено преждевременное обрезание исходной беседы при редактировании и повторной отправке сообщений. Теперь сообщения заменяются атомарно после завершения проверки.
- Исправлены проблемы удалённых путей в WSL и Remote SSH, улучшены запуск хоста, повторный ввод пароля и кэширование сервера.

#### Рендеринг, модели и состояние

- Исправлены разбор блочных формул KaTeX, темы блоков кода, отображение китайских шрифтов и выравнивание значков файлов.
- Исправлены случаи, когда некоторые модели показывали пустые ответы, раскрывали стеки ошибок или отправляли аномальные сетевые запросы провайдеру.
- Исправлено повторное появление удалённого содержимого в Super Memory и неожиданное восстановление состояния панели браузера.

### Улучшения

#### Поиск и выполнение Agent

- Оптимизированы поиск Agent, вызовы инструментов, выполнение задач и логика завершения, чтобы сократить повторяющиеся выводы, ненужное ожидание и аномальные прерывания.
- Оптимизированы ограничения результатов, тайм-ауты выполнения и состояние потоковой передачи при крупномасштабном поиске кода, что снижает расход ресурсов из-за чрезмерных наборов результатов.

#### Работа с чатом

- Улучшены состояние завершения чата, нижняя панель инструментов, положение прокрутки и загрузка длинных бесед.

#### Настройки и использование

- Переработаны карточки учётных записей моделей и входа OAuth, унифицированы визуальная иерархия и схемы взаимодействия на странице настроек.
- Улучшены показатели использования Codex, метаданные моделей и связанные индикаторы состояния.

## 1.2.6 · 2026-07-27

### Добавлено

#### Chat Git на уровне сеанса

- Теперь изменения кода, созданные ИИ в рамках одного сеанса, можно отправлять вместе.
- Добавлены одновременное обнаружение и обработка нескольких Git-репозиториев.
- Состояние задач чата и проверки кода теперь автоматически синхронизируется после отправки.

#### Провайдеры, модели и возможности

- Добавлен провайдер **Poolside Platform** с доступом к **Poolside Laguna** через конфигурацию, совместимую с OpenAI.
- Добавлены конфигурации моделей **Qwen3.8**, **Opus 5** и **Pangu**.
- Для **LongCat** добавлено воспроизведение вывода, сохраняющее контекст рассуждений после вызовов инструментов.

#### Безопасность удалённого рабочего пространства

- При обращении к корневому каталогу Linux `/` в удалённой среде теперь отображается предупреждение безопасности.
- Пути виртуальной файловой системы Linux, такие как `/proc`, `/sys` и `/dev`, теперь автоматически исключаются.

### Улучшения

#### Проверка кода

- Переработана панель действий **Принять/Отклонить** для отдельных блоков кода.
- **Сохранить всё** теперь использует акцентный цвет текущей темы.
- Уменьшена высота встроенных панелей действий, чтобы сделать область кода компактнее.
- После успешного коммита Git панели действий проверки теперь автоматически сворачиваются и сбрасываются.

#### Выбор модели

- После первого ввода ключа по умолчанию включаются только пять рекомендованных моделей, что уменьшает избыточность списка.
- Возможности провайдеров, совместимых с OpenAI, теперь адаптируются к выбранному формату API.

#### Отправка кода и обновление SCM

- Состояние Git на панели действий теперь автоматически обновляется после сохранения файлов.
- Отправка через Chat Git теперь единообразно обрабатывается как **Сохранить все изменения**, а соответствующие этапы проверки кода завершаются автоматически.

#### Интерфейс

- Удалён индикатор непрочитанных сообщений из заголовков уведомлений.
- Улучшено переключение всплывающих меню групп моделей, совместимых с OpenAI.
- Исправлено вертикальное выравнивание текста с количеством инструментов.
- В светлой теме включён стиль значков Kimi Mono.

### Исправления

#### WSL и удалённый Git

- Исправлен сбой при запуске хоста расширений WSL.
- Исправлена несогласованная конфигурация прокси-сервера WSL.
- Проверки состояния Git и созданные ИИ сообщения коммитов в средах WSL и SSH теперь выполняются через канал, учитывающий удалённую среду.
- Команды Git удалённых рабочих пространств больше не выполняются относительно локальных путей.
- Исправлена проблема, из-за которой Agent автоматически закрывал Git-репозитории после изменения файлов.
- Исправлено отображение относительных путей в удалённых URI.

#### Remote SSH

- Исправлена обработка истечения срока действия пароля в Remote SSH. Сохранённые пароли теперь удаляются после отклонения сервером, а повторный ввод запрашивается в рамках той же попытки подключения.
- Remote SSH больше не загружает пакеты сервера REH с несовпадающими хэшами коммитов, предотвращая ошибки несовместимости версий и сбои запуска удалённого хоста.

#### Рендеринг чата

- Добавлена поддержка Trusted Types для диаграмм Mermaid.
- Улучшена очистка тегов Mermaid, чтобы небезопасные или некорректные теги не приводили к сбоям рендеринга.

#### Правила и память

- Исправлено сохранение пустого содержимого после потери фокуса редактором.
- Исправлена задержка обновления менеджера ресурсов после изменения конфигурации `.breezell`.

#### Удалённое древовидное представление

- При отсутствии конфигурации SSH Hosts бессмысленные ошибки древовидного представления больше не выводятся повторно.

- Обновлено руководство по протоколу OpenAI с двумя более ясными рекомендациями:

- Исправлено сохранение подсветки и доступности панелей длительности, проверки, Git и действий инструментов после возврата к контрольной точке.
- Исправлена неправильная синхронизация ограничений доступа в панели рисования и улучшены неясные сообщения об ограничениях.
- Исправлено отсутствие узла по умолчанию при первом открытии пустого холста.
- Исправлена утечка или смешивание сеансов режима Chat между несколькими окнами.
- Исправлен возврат к недоступной модели после удаления выбранной модели.
- Исправлена некорректная подготовка одного файла в Chat Git.
- Исправлены проблемы коммита и обновления в рабочих пространствах с несколькими репозиториями.
- Исправлена потеря истории чата после добавления папки в рабочее пространство.
- Исправлено отсутствие значков панели действий в средах WSL и SSH.
- Исправлено мерцание списка проектов в проводнике.
- Исправлена перегрузка хоста расширений из-за параллельных проверок состояния Git в представлении репозитория.
- Исправлена проблема, из-за которой некорректный вывод `****` нарушал потоки рассуждений OpenAI.
- Исправлен стиль кнопки закрытия в пузырях редактирования.

### Улучшения

- Упрощены стартовые карточки страницы приветствия с помощью пунктирных плиток и унифицированы значки проверки кода.
- Вторичный текст Super Memory теперь отображается курсивом.
- Карточки провайдеров на странице настроек объединены.
- Улучшена компоновка заголовков диалогов сетевой конфигурации.
- Улучшена локализация пустого селектора моделей, а из селектора теперь можно напрямую открыть настройки.
- Обеспечена корректная передача возможности `supportsFast` фонового каталога через конвейер запросов.
- Исправлена информация о ценах **Qwen 3.7**.

## 1.2.4 · 2026-07-20

### Новые возможности

#### Модели и провайдеры

- Интегрирован **Grok 4.5** с регулируемой силой рассуждений и каналом Fast; **Claude Sonnet 5** доступен с контекстом **200K** и **1M**.
- Добавлен **Kimi K3** через каналы Moonshot API и Kimi Code с контекстом **256K** и **1M**, а также полной поддержкой **Kimi K2.7 Code**.
- Добавлен провайдер **StreamLake** с полным семейством моделей KAT-Coder от Kuaishou, встроенными пресетами Coding Plan и пресетами конечных точек с оплатой по мере использования.
- Добавлен вход в аккаунты Grok через OAuth.
- Каналы Fast переработаны из глобального переключателя в независимую конфигурацию **провайдер + модель**, поэтому Copilot, Codex, Claude и другие провайдеры используют семантику своих официальных каналов.
- Конфигурации, совместимые с OpenAI, теперь можно закреплять, чтобы часто используемые каналы оставались наверху.
- Добавлена поддержка временных пробных периодов и скидок на модели, а в селекторе моделей появились рекламные значки.
- Каталог моделей обновлён актуальными флагманскими моделями, включая Claude Fable 5, Claude Sonnet 5, Nemotron 3 Ultra, DeepSeek V4, GLM-5.2 и MiniMax M3; устаревшие записи удалены.

#### Использование, внешний вид и интерфейс

- Центр использования обновлён: для Codex, Kimi и Copilot добавлено многоязычное отображение использования и времени сброса на упрощённом и традиционном китайском, корейском и русском языках. Данные настроек и боковой панели чата синхронизируются в реальном времени, а использование Copilot отображается отдельно для Chat, Completions и Premium Requests.
- Заголовки страницы приветствия теперь можно настраивать глобально или отдельно для каждого режима, включая размер и насыщенность шрифта. Добавлен стиль **Elegant** для быстрых действий.
- Добавлены японский, испанский и бразильский португальский языки интерфейса.
- Центр уведомлений переработан в соответствии с языком продукта, обновлена компоновка карточек Super Memory, смягчено визуальное оформление поля ввода и пузырей сообщений.

#### Браузер, чат и рабочее пространство

- Встроенный браузер теперь позволяет отключать звук у всех вкладок или отдельных вкладок, а список вкладок панели синхронизируется с браузером в реальном времени.
- Сообщения чата теперь могут содержать до **10 изображений**; изображения автоматически изменяются и учитываются при расчёте контекста. Добавлены отображение длительности хода, откат сообщения одним нажатием и возможность открывать ссылки во внешнем или встроенном браузере.
- Диалог коммита чата теперь поддерживает рабочие пространства с несколькими репозиториями: создание информации о коммите для каждого репозитория, независимую отправку, инициализацию репозиториев из диалога и сохранение прогресса commit/push после перезапуска.
- В менеджер ресурсов добавлена группировка проектов, а обновление статуса совместной работы между окнами стало более своевременным.
- Добавлена постоянная память, автоматически преобразующая историю разговоров в повторно используемый опыт с многоязычным удалением дубликатов.

#### Диагностика и продуктивность

- Добавлена визуализация кэша с уведомлениями по ходам и ежедневными отчётами рабочего пространства, сравнивающими сегодня и вчера; доступны фильтры сеанса/рабочего пространства, оценка экономии и анализ промахов кэша.
- Добавлены интерактивные карточки дизайна, которые создают черновики HTML-дизайна прямо в чате и применяют их после подтверждения.
- Сетевые настройки провайдеров теперь поддерживают параллельные тесты скорости одним нажатием для прямого подключения, системного прокси, глобального прокси и пользовательских маршрутов. Рекомендуемые маршруты отмечаются автоматически, а значки маршрутизации обновляются в реальном времени на странице настроек.
- Обновлено ядро PDF-просмотрщика и добавлена новая панель инструментов. Вложения учитываются по страницам, автоматически скрываются при ограниченном контексте и ограничиваются объёмом и количеством страниц для каждой модели.

### Улучшения

- Переработана работа с фоновыми командами: элементы строки состояния остаются видимыми до фактического завершения команд, а параллельные команды сворачиваются в раскрываемую сводку.
- Расширены авторизация расширенных функций и совместимость с популярными расширениями, такими как Python и Pylance; улучшена совместимость с удалённой разработкой.
- Повышена надёжность установки и обновления в отечественных сетях.
- Автоматическое сжатие контекста стало умнее: оно запускается динамически в зависимости от доступного контекста, что уменьшает ненужное сжатие.
- Встроенные навыки теперь включаются по требованию и по умолчанию работают в облегчённом режиме.
- Agents теперь завершают многоэтапные планы без пауз для подтверждения, отвечая сдержаннее и сосредоточившись на результате.
- Глубоко оптимизирован конвейер запросов, что снижает стоимость длинных разговоров.
- Переработаны сообщения об ошибках: добавлены менее заметные баннеры, выдвижные панели деталей и более ясное смешанное отображение китайского и английского текста.
- Восстановлен переключатель компоновки строки заголовка, реорганизованы быстрые действия на пустых страницах чата, а значки провайдеров больше не вызывают системные предупреждения.

### Исправления

- Устранены задержки и аномальное использование памяти в длинных разговорах, значительно ускорено открытие исторических сеансов и улучшена плавность длинных ответов.
- Отключённые или находящиеся не в сети MCP-серверы больше не предоставляют инструменты моделям, предотвращая случайные вызовы; соединения MCP остаются стабильными после переключения, а ошибки чтения конфигурации больше не удаляют сохранённые настройки.
- Исправлены ошибочное выделение жирным значков навигации настроек, сбои в некоторых средах Linux и другие проблемы интерфейса.
- Исправлены проблемы загрузки прошлых сеансов, которые могли приводить к сбоям интерфейса или неограниченному росту хранилища.
- Исправлены ложные состояния «контекст сжат»: реальное сжатие теперь явно отображается, устранены дрейф понимания в длинных разговорах и помехи памяти между сеансами.
- При удалении активной модели или конфигурации канала автоматически выбирается доступный вариант вместо пустого поля выбора.
- Переключение между вкладками Plan и Analysis сохраняет состояние без повторной загрузки содержимого.
- Исправлены периодические белые экраны панели рисования, устаревшие записи после завершения фоновых команд, проблемы полосы прокрутки страницы настроек и другие мелкие детали.
- Улучшена совместимость параметров между моделями, включая редактирование инструкций, обнаружение прерывания потока, ограничения бюджета рассуждений и выравнивание документов.

Также добавлено множество исправлений стабильности потокового вывода, синхронизации состояния редактора, сохранения сеансов, работы нескольких окон и аутентификации.

- Производительность запуска: оптимизация O(n) чата и сохранение статистики diff.
- Интерфейс терминальных инструментов: оптимизированы внутренние отступы строки заголовка/нижней панели и исправлен радиус скругления кнопки «Открыть в браузере».
