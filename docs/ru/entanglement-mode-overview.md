# Режим Entanglement

> Режим для работы со сложными и неопределёнными задачами с поддержкой структурированного исследования.

## Чем помогает Entanglement

Entanglement предназначен для задач, в которых причина не очевидна и может потребоваться несколько проверок. Он помогает Breezell сохранять последовательный ход исследования во время работы.

- Исследовать неизвестные ошибки и регрессии.
- Связывать признаки из разных файлов или модулей.
- Организовывать гипотезы, полезные доказательства, следующие шаги и выводы.
- Поддерживать проверки с помощью инструментов и последующую валидацию.
- Показывать ход исследования на структурированной панели.
- Сохранять полезные выводы, чтобы к похожим проблемам было проще вернуться.

## Что можно увидеть

После выбора Entanglement в селекторе режимов Breezell может показывать:

- Текущий этап исследования.
- Рабочие гипотезы и подтверждающие их доказательства.
- Запланированные проверки и результаты валидации.
- Текущий уровень уверенности и выявленные выводы.
- Исправления, если предыдущее направление требует пересмотра.

## Когда использовать

Используйте Entanglement, если:

- Первопричина неизвестна.
- Проблема затрагивает несколько файлов, модулей или систем.
- Нужно сравнить возможные объяснения до изменения кода.
- Результат нужно подтвердить дополнительными тестами или наблюдениями.

Для ясных и ограниченных изменений или обычных задач программирования обычно лучше подходит режим Agent по умолчанию.

## Как начать

1. Выберите Entanglement в селекторе режимов.
2. Опишите симптомы, цель и важные ограничения.
3. Разрешите Breezell проверить контекст, необходимый для исследования.
4. Изучите гипотезы, проверки и выводы, показанные на панели.
5. Продолжите разговор, если нужны дополнительные доказательства или проверка.

## Entanglement и Agent

Agent — режим по умолчанию для общей разработки. Entanglement ориентирован на исследование задач, требующих более тщательного рассуждения и последующих проверок.

Выбирайте режим в соответствии с задачей. Для непосредственной реализации используйте Agent, а для неопределённых или многоэтапных исследований — Entanglement.

## Важное примечание

Панель Entanglement помогает принимать решения. Перед применением важных изменений проверьте её выводы и результаты валидации.
