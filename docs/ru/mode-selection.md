# Выбор режима

Breezell предоставляет несколько рабочих режимов для разных уровней автономности, глубины и управления рабочим процессом. Agent — режим по умолчанию и рекомендуемый автоматический рабочий процесс для большинства задач.

Используйте другой режим, если нужен более конкретный стиль взаимодействия: быстрый разговор, анализ только для чтения, планирование перед изменениями, более глубокое причинное рассуждение или параллельные ИИ-коллеги.

## Chat

Chat предназначен для быстрых вопросов и ответов.

Используйте Chat, если хотите спросить о коде, объяснить идею, сравнить варианты или быстро получить ответ, не поручая Breezell автономно редактировать файлы или запускать инструменты.

В режиме Chat модель не может редактировать файлы.

## Agent

Agent позволяет Breezell изучать проект, редактировать файлы, использовать инструменты, выполнять команды и завершать задачи программирования.

Используйте Agent для большинства задач разработки. Это режим по умолчанию, поскольку он может автоматически выбрать подходящий рабочий процесс, собрать необходимый контекст, внести изменения и проверить результат перед выдачей.

## Analyze

Analyze предназначен для исследования в режиме только чтения.

Используйте Analyze, если хотите, чтобы Breezell изучил код, диагностировал проблемы, проверил архитектуру или проанализировал поведение без изменения файлов. Он полезен, когда технический вывод нужен до принятия решения о внесении изменений.

## Plan

Plan создаёт структурированный путь реализации перед редактированием.

Используйте Plan для сложных функций, крупных рефакторингов, неясных требований или задач, требующих дизайнерского решения до начала изменений кода.

Совет: в режиме Agent Breezell может решить переключиться на Plan, если задаче требуется структурированный путь реализации. Переключение можно разрешить или отклонить. Если включён полностью автоматический режим, Breezell может автоматически подтвердить переключение, когда это уместно.

## Entanglement

Entanglement использует причинное рассуждение и понимание контекста для более глубоких решений о продукте и коде.

Entanglement независимо исследован и выпущен Breezell. Это эксклюзивный режим Breezell, уникальный во всём интернете.

Технический обзор отслеживания причинного состояния и цикла проверки см. в разделе [Обзор режима Entanglement](/ru/entanglement-mode-overview).

Используйте Entanglement, если запрос зависит от намерений, компромиссов, скрытых причин, эмоциональных нюансов или многоэтапного рассуждения, выходящего за рамки прямого ответа.

Совет: этот режим может значительно повысить возможности модели, но потребляет больше ресурсов, чем стандартные рабочие процессы. Его побочные эффекты неизвестны.

Совет: поскольку контекст Entanglement уже внедрён, переключение с Entanglement на Agent в рамках того же разговора не отключит поведение Entanglement полностью. Разговор сохранит возможности Entanglement и продолжит потреблять ресурсы. Если нужно вернуться к обычному рабочему процессу Agent, начните новый разговор.

## Teams

Teams координирует нескольких ИИ-коллег для крупных функций и параллельных рабочих процессов.

Используйте Teams, если задачу можно разделить на независимые рабочие потоки: например, исследовать несколько областей, сравнить реализации или одновременно продвигать разные части крупного проекта.

Совет: этот режим может значительно повысить возможности модели, но потребляет больше ресурсов, чем стандартные рабочие процессы.

Ограничение: Teams всё ещё может быть ограничен конфликтами чтения и записи между параллельными коллегами. Breezell старается уменьшить эти конфликты, однако крупные параллельные задачи могут оставаться сложными для координации и приводить к путанице, если несколько коллег изменяют пересекающиеся области.

## Выбор режима

Для большинства задач оставляйте режим Agent по умолчанию. Переключайтесь только тогда, когда задаче явно требуется другой рабочий процесс.

| Режим | Лучше всего подходит для |
| --- | --- |
| Chat | Быстрых разговоров и кратких объяснений |
| Agent | Рабочего процесса программирования по умолчанию, редактирования файлов, инструментов и проверки |
| Analyze | Диагностики, проверок и исследования архитектуры в режиме только чтения |
| Plan | Структурированного планирования реализации перед изменениями |
| Entanglement | Глубокого причинного рассуждения и решений с учётом контекста |
| Teams | Параллельных ИИ-коллег для крупных или независимых рабочих потоков |
