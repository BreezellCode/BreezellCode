# 更新日志

## 1.2.7 · 2026-07-29

### 新功能

- 提升了大型代码库的理解与导航效率。
- 新增可选的回答质量洞察，可展示本轮回答质量、需求理解和验证置信度的评估结果。
- 缓存统计详情现支持分页、联动筛选和多语言显示。

### 修复

#### 源代码管理与 Agent 运行时

- 修复了刷新源代码管理仓库、切换视图或重建组件后提交消息输入框变空或失效的问题。
- 修复了 Agent 推理停滞、终端状态误判、后台命令退出码丢失和任务过早结束的问题。
- 修复了队列消息编辑、工具调用反馈、任务列表恢复和连续轮次状态相关的问题。

#### 聊天与远程环境

- 修复了编辑并重新发送消息时原始会话被过早截断的问题。现在会在验证完成后原子替换消息。
- 修复了 WSL 和 Remote SSH 环境中的远程路径问题，并改进了主机启动、密码重试和服务器缓存。

#### 渲染、模型与状态

- 修复了 KaTeX 块级公式解析、代码块主题、中文字体渲染和文件图标对齐问题。
- 修复了部分模型错误显示空响应、暴露错误堆栈或发起异常提供商网络请求的问题。
- 修复了 Super Memory 中已删除内容重新出现，以及浏览器面板状态意外回退的问题。

### 改进

#### Agent 搜索与执行

- 优化了 Agent 搜索、工具调用、任务执行和终止逻辑，减少重复结论、不必要的等待和异常中断。
- 优化了大型代码搜索的结果数量限制、执行超时和流式状态，降低超大结果集带来的资源消耗。

#### 聊天体验

- 改进了聊天完成状态、底部工具栏、滚动定位和长会话加载体验。

#### 设置与用量

- 重构了模型账户和 OAuth 登录卡片，统一设置页面各处的视觉层级与交互模式。
- 改进了 Codex 用量、模型元数据和相关状态指示器。

## 1.2.6 · 2026-07-27

### 新增

#### 会话级 Chat Git

- 现在可以将同一会话产生的 AI 代码更改一起提交。
- 新增对多个 Git 仓库的同时检测和处理支持。
- Chat 任务和代码审查状态现在会在提交后自动同步。

#### 提供商、模型与能力

- 新增 **Poolside Platform** 提供商，可通过 OpenAI 兼容配置使用 **Poolside Laguna**。
- 新增 **Qwen3.8**、**Opus 5** 和 **Pangu** 的模型配置。
- 为 **LongCat** 增强推理回放功能，在工具调用后保留推理上下文。

#### 远程工作区安全

- 在远程环境访问 Linux 根目录 `/` 时新增安全警告。
- 现在会自动排除 `/proc`、`/sys` 和 `/dev` 等 Linux 虚拟文件系统路径。

### 改进

#### 代码审查

- 重新设计了单个代码块的 **接受/拒绝** 操作栏。
- 更新 **全部保留**，使其遵循当前主题的强调色。
- 降低了行内操作栏的高度，使代码区域更加紧凑。
- 成功执行 Git 提交后，审查操作栏现在会自动折叠并重置。

#### 模型选择器

- 首次输入密钥后，默认只启用五个推荐模型，以减少列表冗余。
- OpenAI 兼容提供商的能力现在会根据所选 API 格式自适应。

#### 代码提交与 SCM 刷新

- 文件保存后，活动栏中的 Git 状态现在会自动刷新。
- Chat Git 提交现在统一按 **保留全部更改** 处理，并自动完成对应的代码审查步骤。

#### 界面

- 移除了通知标题中的未读指示器。
- 改进了 OpenAI 兼容模型组的悬停菜单切换体验。
- 修复了工具数量文本的垂直对齐问题。
- 在浅色主题中启用了 Kimi Mono 图标样式。

### 修复

#### WSL 与远程 Git

- 修复了 WSL 扩展主机启动崩溃问题。
- 修复了 WSL 服务器代理配置不一致的问题。
- WSL 和 SSH 环境中的 Git 状态检查及 AI 生成提交消息现在会通过支持远程环境的执行通道运行。
- 阻止远程工作区的 Git 命令针对本地路径执行。
- 修复了 Agent 修改文件后自动关闭 Git 仓库的问题。
- 修复了远程 URI 中相对路径显示错误的问题。

#### 远程 SSH

- 修复了远程 SSH 密码过期处理问题。服务器拒绝已保存密码后，现在会清除该密码，并在同一次连接尝试中提示用户重新输入。
- 阻止远程 SSH 下载提交哈希不匹配的 REH 服务器包，避免版本不匹配错误和远程主机启动失败。

#### 聊天渲染

- 为 Mermaid 图表增加 Trusted Types 支持。
- 改进了 Mermaid 标签清理，避免不安全或格式错误的标签导致渲染失败。

#### 规则与记忆

- 修复了编辑器失去焦点后保存空内容的问题。
- 修复了 `.breezell` 配置变更后资源管理器未及时刷新的问题。

#### 远程树视图

- SSH Hosts 配置缺失时，不再重复发出无意义的树视图错误。

## 1.2.4 · 2026-07-20

### 新功能

#### 模型与提供商

- 集成 **Grok 4.5**，支持可调推理强度和 Fast 通道；**Claude Sonnet 5** 提供 **200K** 和 **1M** 两种上下文选项。
- 通过 Moonshot API 和 Kimi Code 通道新增 **Kimi K3**，提供 **256K** 和 **1M** 上下文选项，并完整支持 **Kimi K2.7 Code**。
- 新增 **StreamLake** 提供商，支持快手完整的 KAT-Coder 模型系列、内置 Coding Plan 预设和按量付费端点预设。
- 新增 Grok 账户 OAuth 登录。
- 将 Fast 通道从全局开关重构为独立的 **提供商 + 模型** 配置，使 Copilot、Codex、Claude 等提供商使用其官方通道语义。
- OpenAI 兼容配置现在可以置顶，让常用通道保持在列表顶部。
- 新增限时模型试用和折扣支持，并在模型选择器中显示促销徽章。
- 更新模型目录，加入 Claude Fable 5、Claude Sonnet 5、Nemotron 3 Ultra、DeepSeek V4、GLM-5.2 和 MiniMax M3 等当前旗舰模型，同时移除过时条目。

#### 用量、外观与界面

- 升级用量中心，为 Codex、Kimi 和 Copilot 提供简体中文、繁体中文、韩语和俄语的多语言用量与重置时间显示。设置页和聊天侧栏数据现在实时同步，Copilot 用量会分别显示 Chat、Completions 和 Premium Requests。
- 欢迎页标题现在可以全局或按模式自定义，包括字号和字重。新增 **Elegant** 快捷访问样式。
- 新增日语、西班牙语和巴西葡萄牙语界面语言。
- 重新设计通知中心，使其遵循产品语言；刷新 Super Memory 卡片布局，并柔化聊天输入框和消息气泡的视觉效果。

#### 浏览器、聊天与工作区

- 内置浏览器现在支持静音全部标签页或单个标签页，其面板标签列表与浏览器之间会实时同步。
- 聊天消息现在最多可包含 **10 张图片**；图片会自动调整大小并纳入上下文计算。新增轮次时长显示、消息内一键回滚，以及在外部或内置浏览器中打开链接的选项。
- 聊天提交对话框现在支持多仓库工作区：按仓库生成提交信息、独立提交、直接从对话框初始化仓库，并在重启后保留提交/推送进度。
- 资源管理器新增项目分组，并改进了多窗口间协作状态的及时更新。
- 新增持久化记忆，可将对话历史自动提炼为可复用经验，并支持多语言去重。

#### 诊断与效率

- 新增缓存可视化，提供按轮次的缓存通知和工作区每日报告，可比较今日与昨日数据，并支持会话/工作区筛选、预计节省量和缓存未命中分析。
- 新增交互式设计卡片，可直接在聊天中生成 HTML 设计草稿，并在确认后应用。
- 提供商网络设置现在支持在直连、系统代理、全局代理和自定义路由之间一键并行测速。系统会自动标记推荐路由，路由徽章会在设置页实时更新。
- 升级 PDF 查看器核心并新增工具栏。附件按页计量，在上下文受限时自动隐藏，并受每个模型的数量和页数限制约束。

### 改进

- 重新设计后台命令体验：状态栏条目会一直显示到命令真正结束，并将并发命令折叠为可展开的摘要。
- 扩展了高级功能授权及对 Python、Pylance 等主流扩展的兼容性，并改进远程开发兼容性。
- 改进了国内网络环境下的安装和更新可靠性。
- 让自动上下文压缩更智能，根据可用上下文动态触发，减少不必要的压缩。
- 内置技能现在按需启用，默认使用轻量模式。
- Agent 现在可以完成多阶段计划，不会在过程中暂停等待确认，并会以更克制的回复聚焦结果。
- 深度优化请求流程，降低长对话成本。
- 重新设计错误提示，采用更安静的横幅、详情抽屉和更清晰的中英文混排。
- 恢复标题栏布局切换，重新组织空聊天页的快捷访问，并避免提供商图标触发系统提醒。

### 修复

- 解决长对话中的卡顿和异常内存占用问题，大幅加快历史会话打开速度并改善长响应流畅度。
- 已禁用或离线的 MCP 服务器不再向模型暴露工具，避免意外调用；切换 MCP 后连接也能保持稳定，配置读取错误不再清除已保存设置。
- 修复设置导航图标被错误加粗、部分 Linux 环境崩溃等多个界面问题。
- 修复过去会话加载问题，避免界面崩溃或存储无限增长。
- 修复误报“上下文已压缩”的状态：现在会明确显示真实压缩，并解决长对话理解偏移及跨会话记忆干扰问题。
- 删除活动模型或通道配置后，现在会自动选择可用选项，不再留下空白选择框。
- 在 Plan 和 Analysis 标签页之间切换时，现在会保留状态而不重新加载内容。
- 修复绘图面板偶发白屏、后台命令结束后的过期条目、设置页滚动条等问题，并处理其他细节。
- 改进模型间参数兼容性，包括指令编辑、流式中断检测、思考预算限制和文档对齐。

## 1.2.0 · 2026-07-06

Breezell v1.2.0 引入了新的 AI 工具、更智能的 Agent 工作流、界面升级、稳定性修复和性能改进，覆盖长对话、工具执行、终端输出、记忆隔离和远程开发等方面。

### AI 工具与智能能力

- 新增 **Agent Research** 工具，支持实时进度跟踪和结果展示。
- 在 Code Mode 中新增批处理脚本执行，作为多步骤自动化支持的第一阶段。
- 新增统一的浏览器工具入口，将之前分开的浏览器操作整合为更简单的工作流。

### 对话与界面

- 在聊天区域新增 **消息导航栏**，更方便浏览和跳转到对话消息。
- 在聊天主页新增 **Super Memory** 和 **代码审查** 快捷访问卡片。
- 在输入区域新增 **MCP 服务器** 快速切换面板，无需打开设置即可启用或禁用 MCP。
- 引入全新的品牌标识，在启动页、欢迎页和 Teams Mode 中统一更新视觉效果。
- 重新设计设置中的提供商管理界面，支持基于列表浏览和深入查看详情。
- 新增自定义主题强调色，同时支持浅色和深色模式。
- 将图像设置升级到 v2，支持轮询和跟踪异步视频任务。
- 为 OpenAI 兼容提供商新增健康检查报告，便于诊断连接和配置问题。

### 稳定性

- 修复加载长会话历史时卡顿，以及粘贴大段内容时响应缓慢的问题。
- 修复 AI 流式输出期间偶发的界面冻结，尤其是终端产生大量输出时的问题。
- 修复 **全部保留/全部撤销** 操作栏意外消失的问题。
- 修复同时打开多个窗口时设置被覆盖的问题。
- 修复某些模式下 **Super Memory** 无法正常使用的问题。
- 修复 AI 生成期间超时中断错误的问题，慢但正常的生成不再过早停止。
- 修复刷新令牌失败导致用户反复登录的问题。
- 修复用户用新消息中断后工具执行结果配对错误的问题。
- 修复工具结果被静默压缩导致 AI 反复执行同一任务的问题。
- 修复终端退出码显示不准确，以及终端输出无法完整恢复的问题。
- 修复远程 SSH 连接丢失主机名大小写和端口信息的问题。
