# 更新日志

## 1.2.7 · 2026-07-29

### 新功能

- 提升了大型代码库的理解与导航效率。
- 新增可选的回答质量洞察，可展示回答质量、需求理解与验证置信度的评估结果。
- 缓存统计详情现支持分页、联动筛选和多语言显示。

### 修复与优化

- 修复了刷新源代码管理、切换视图或重建组件后提交消息输入框丢失或失效的问题。
- 修复了 Agent 推理停滞、终端状态误判、后台命令退出码丢失和任务过早结束的问题。
- 修复了编辑并重新发送消息时会话被过早截断的问题。
- 改进了 WSL 和 Remote SSH 环境中的路径、主机启动、密码重试和服务器缓存。
- 修复了 KaTeX、代码块主题、中文字体和文件图标对齐问题。
- 优化了 Agent 搜索、工具调用、任务执行和终止逻辑。
- 优化了聊天完成状态、底部工具栏、滚动定位和长会话加载体验。
- 重构了模型账户与 OAuth 登录卡片，并改进了 Codex 用量和模型元数据显示。
