# 介绍

Breezell 是基于 VS Code（Code – OSS）构建的 AI 代码编辑器。它将 AI 智能体、多模型支持和深度代码库理解整合到一个工具中，在不牺牲质量的前提下加快开发速度。

## 核心功能

- **多种 AI 模型** — 可在 Claude、GPT、Gemini、Grok、DeepSeek 等模型之间自由切换。
- **多种工作模式** — 提供 Chat、Agent、Analyze、Plan、Entanglement 和 Teams。
- **深度代码库理解** — 提供智能代码索引、跳转到定义，以及包含循环检测和影响跟踪的依赖分析。
- **规则、记忆与技能** — 使用持久规则、项目记忆和可复用技能库自定义 AI 行为。
- **内置数据库操作** — 可直接在编辑器中连接和管理 SQLite、MongoDB、Oracle、Redis、MariaDB 等。
- **内置浏览器** — 提供截图、点击、导航、DOM 快照自动化和设备视口模拟。
- **MCP 支持** — 可通过 Model Context Protocol 连接外部工具和服务。
- **丰富的工作空间** — 提供实时主题预览、内置图标库和完整的 SSH 远程开发支持。

## 亮点

最新 Breezell 版本聚焦于更智能的智能体、更深的代码理解和更强大的一体化工作空间。

- **Code Review Panel** — 提供独立评审视图、行号差异、大文件 Myers diff、一键回滚和发送至聊天进行 AI 辅助评审。
- **Entanglement 模式** — 通过具有情感感知的因果推理提供更理解意图的回答。
- **并行 AI 队友** — 可并行运行多个 AI 队友来处理复杂任务。
- **Super Memory** — 具有时间感知能力的长期记忆，可跨会话保留上下文。
- **富文本渲染** — 在聊天中提供 LaTeX、Mermaid、可展开工具卡片和内置网页搜索。

## 快速开始

1. 下载并安装适用于你平台的 Breezell。
2. 选择方案：使用自己的 API 密钥、试用或订阅。
3. 打开项目并选择 AI 模型。
4. 选择 Chat、Agent 或 Plan 等模式，然后开始更智能地编程。
