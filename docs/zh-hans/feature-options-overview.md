# 功能选项概览

本页面概述 Breezell 设置中提供的主要功能选项。这些选项控制自动补全、通知、工具权限、编辑器行为、智能功能和系统访问权限。

## 帮助

### 自动补全与通知

| 功能 | 说明 |
| --- | --- |
| 自动补全 | BreezellTab 提供 AI 代码补全。按下 `Tab` 接受建议。 |
| 系统通知 | 配置系统通知行为。当编辑器最小化或失去焦点时，Breezell 可以显示系统通知。 |

## 执行

### 工具权限

这些选项控制特定工具操作是否可以在没有手动确认的情况下自动运行。

| 功能 | 说明 |
| --- | --- |
| 自动批准编辑 | 允许编辑操作在无需确认的情况下自动运行。 |
| 自动批准终端 | 允许终端操作在无需确认的情况下自动运行。 |
| 自动批准数据库操作 | 允许数据库操作在无需确认的情况下自动运行。 |
| 自动批准媒体生成 | 允许媒体生成操作在无需确认的情况下自动运行。 |
| 自动批准 MCP 工具 | 允许 MCP 工具操作在无需确认的情况下自动运行。 |
| 自动批准 Teams | 自动批准创建团队，无需手动确认。 |

## 编辑器

### 代码行为

| 功能 | 说明 |
| --- | --- |
| 自动修复 Lint 错误 | 在支持的情况下自动修复 Lint 错误。 |
| 自动接受代码更改 | 自动接受生成或修改的代码更改。 |
| 编辑时自动打开文件 | 编辑期间自动打开文件。 |
| 在选中内容时显示行内建议 | 选中文本或代码时显示行内建议。 |

### Git 提交消息

使用此选项可以让 Breezell 根据当前代码更改生成 Git 提交消息。当你想要清晰的提交摘要而不想手动编写时，此选项非常有用。

![使用聊天模型生成提交消息](/feature-options/git-commit-message.png)

| 功能 | 说明 |
| --- | --- |
| 使用聊天模型生成提交消息 | 根据当前代码更改自动生成 Git 提交消息。 |

启用此选项后，Breezell 可以审查当前更改集，并使用所选聊天模型创建提交消息。如果项目要求特定的提交格式，请在提交前检查生成的消息。

## 智能

### 上下文管理

| 功能 | 说明 |
| --- | --- |
| 自动运行计划卡片 | 启用后，新的计划卡片会自动运行，无需手动点击。 |

### Superpowers 技能

| 功能 | 说明 |
| --- | --- |
| 启用 Superpowers 技能 | 允许 AI 使用头脑风暴、规划、TDD 和代码审查等结构化开发工作流。完整内容会按需加载。 |

### ~~Agent 高级探索~~

> **1.2.5 版本后已弃用。** 此选项已移除。当请求需要深入的多来源研究时，Breezell 会自动调用相关能力，并将结果汇总为带引用的研究报告。

| 功能 | 说明 |
| --- | --- |
| ~~启用高级探索~~ | 1.2.5 版本后已弃用；需要时会自动调用相关研究能力。 |

### Entanglement 模式面板

| 功能 | 说明 |
| --- | --- |
| 在 Entanglement 模式中显示面板 | 为 Entanglement 模式显示实时结构化面板，包括当前阶段、置信度历史、活动中和已解决的假设、分级证据日志以及因果图。 |

## 系统

### 网络设置

| 功能 | 说明 |
| --- | --- |
| 使用系统代理 | 使用系统代理发送 API 请求。如果不需要代理或代理不稳定，建议禁用此选项以提高响应速度。 |

### 外部文件访问

| 功能 | 说明 |
| --- | --- |
| 允许只读访问外部文件 | 允许工具读取工作区之外的文件。 |
| 允许写入外部文件 | 允许工具修改工作区之外的文件。默认启用两个外部文件访问选项。 |

## 注意事项

自动批准和外部访问选项可以提高工作流速度，但也会减少人工审查。只有在符合工作区策略和信任级别时才启用它们。
