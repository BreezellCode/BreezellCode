# 提示词设置

## 打开提示词设置

图片中的箭头指向对话框右上角工具栏里的提示词设置按钮。它紧挨在 **New Chat**（`+`）按钮右侧。

![对话框中高亮显示的提示词设置按钮](/custom-api/prompt-settings.png)

点击此按钮即可打开提示词设置，并设定希望 Breezell 在对话中遵循的指令。

## 编写清晰的指令

请描述希望 Breezell 遵循的角色、目标、输出格式和限制条件。保持指令具体、聚焦，能够让对话拥有清晰的方向。
